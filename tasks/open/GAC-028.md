## Task

Build GAC-023 §6's design on current `upstream/main`, fork branch **`fix/recompiler-plan-phi-descriptor-pointer`**:

1. **Walk through the read.** `CollectDescriptorPhis` (ResourceTracker.cpp ~765), `SubstituteEdge` and `Rematerialize` (~810) stop at the `LoadAddressU32` that reads the T# through the phi'd pointer. Let them look through a scalar-address read and its `GetAddressResource`, and re-emit that read once per arm.
2. **Poison the arm that can't be rebuilt.**
   - Where `SplitDescriptorEdges` (~913) gives up on an arm (the ballot arm), make it a poisoned copy with image-table poison semantics. It returns zero and faults only if a lane takes it.
   - `EdgeSelector` picks it only when control arrives along that edge.
   - The entry arm reads the real T#, so `ValidateSource` sees only valid sources.
3. **The materializer:** the new reads appear after the SRT plan is built (Recompiler.cpp ~293 before ~298). Make the materializer evaluate them, or plan them before.
4. **The disk-cache format:** if any plan or IR encoding changes, take the next unused `FormatVersion`.
   - Known claims: main 36, #6243's follow-up 37, PM-038 v3 38. GAC-023 changes no encoding.
   - Check main and the open PRs at build time, and say which number you took.
5. **Tests**, red on main and green with the fix:
   - a recompiler case with a valid/valid phi (both arms read a real T#): the plan and the result are correct;
   - a valid/poisoned phi, Village's chain shape (GAC-023's pixel test has the gfx1030 words): the plan succeeds;
   - a draw that renders the entry arm's texture correctly;
   - a lane that takes the poisoned arm faults, or reads zero, as a poisoned table entry does.
   - Run GAC-023's four `agc_driver_prepared_shaders_abi_deferred_*` modes on a merge with 24bbcad810. The pixel mode then prepares at the ABI call instead of deferring, so say what changes in its expectations.
6. **Cost:** every program with a non-invariant phi behind a scalar-address descriptor read changes its IR.
   - Measure the recompile time of the affected shaders against main.
   - Measure any draw-time cost (one extra read per arm).
   - Count how many shaders in the repo's shader tests or corpora change.
7. **Overlaps:** #6243 (selected image-table records), #1184 (bindless tables up to the device limit) and anything touching ResourceTracker's descriptor-phi split. Use merge-tree and say what the overlap means.
8. **Adversarial review:**
   - Is zero a safe stand-in on every path the arm can take?
   - Can a structurizer artifact edge be taken at run time?
   - What do hardware semantics say about the back-edge T#?

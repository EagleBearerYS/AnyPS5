# BF-278: #12840: write back only the 64 KiB blocks a shader stored to (stored-block bitmap), folded into the PR

from: Bug Finder
for: any
priority: high

## Why

#12840 (fork `fix/agc-bda-store-writable-mirror` 781dc4525b, from your BF-273) costs every address-storing build whose lease holds writable heap mirrors a reference capture plus a diff over the mirrors' committed bytes. On lavapipe that's 32.6 ms per dispatch for a 36 MiB, 16-run heap (13.7 ms of references, 18.9 ms of diff), and 80.6 ms for 72 MiB. That's the case even when the shader never stores near a mirror.

The reviewer (oneandonlydean, https://github.com/boykopovar/AnyPS5/pull/12840#issuecomment-6496483144) asks whether the stored-block follow-up should land first or together. **We fold it into #12840,** as new commits on top.

## Do

1. **Read first:**
   - `core/shader/recompiler/SpirvBackend/src/SpirvBdaLookup.cpp`, how a FLAT/GLOBAL store resolves its address through the BDA table and checks `Write`;
   - `ShaderAddressResources.cpp`, where the table is built and bound;
   - `GuestBufferMemory::UploadFinish`, `takeHeapReferences` and `WriteBack`.
2. **The mark (core/shader):** after a successful `Write` lookup, a store sets one bit per 64 KiB block of the range it hit in a small bitmap buffer bound next to the table. Use an atomic OR on a `uint` word; the block index comes from the table range's guest begin, or from a per-range bitmap base, whichever is simpler and exact.
   - Only ranges that the write-back set added (the heap mirror spans) need marks. Declared write ranges keep their whole-range diff.
   - Keep the shader cache key correct: it's a recompiler change, so check `ShaderCacheVersion` moves, or is derived from these sources.
3. **The host:**
   - allocate and zero the bitmap per storing build;
   - bind it;
   - at `WriteBack`, diff and store only the marked blocks of the spans. With BF-277's change, note only the changed runs as written back.
4. **The reference capture:** today it copies every span on the CPU at upload. Take it instead with a GPU copy (`vkCmdCopyBuffer` from the mirror into a reference buffer, recorded before the dispatch), so the CPU only reads the marked blocks of the reference at write-back.
   - If #8874's pooled reference buffers fit, use the same shape, but don't depend on #8874.
   - Say how sparse mirrors and resident (bound) blocks behave.
   - **If the GPU copy doesn't fit,** keep the CPU capture and say what it costs.
5. **Commits:** on top of BF-277's head on fork `fix/agc-bda-store-writable-mirror-review`, once BF-277 is pushed. Until then, start from 781dc4525b and rebase onto it later; the commits must end up after BF-277's.
   - If core/shader and the host part split cleanly, make two commits: the shader mark with its test, then the host's use of it.
   - Each commit passes its own tests.

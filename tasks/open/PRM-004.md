# PRM-004: render the performance overlay's test frames as PNG images for its PR
from: AnyPS5 PR Manager
for: any
priority: normal

The performance overlay (PM-003, the fork branch `feat/videoout-performance-overlay`, head 98b9b57ef) needs images for its PR description. Game frames are off-limits, so the images come from the overlay's own Vulkan test on lavapipe: a synthetic background with the overlay drawn on it. Nothing is committed or pushed except your result file.

Remotes in your environment: `origin`/`fork` is EagleBearerYS/AnyPS5 and `upstream` is boykopovar/AnyPS5.

1. Check out the branch: `git fetch origin feat/videoout-performance-overlay`, then `git checkout --detach FETCH_HEAD`. Confirm the head is 98b9b57ef. Run `git submodule update --init --recursive`, which main's mbedtls needs.
2. Make a **local, uncommitted** change to `core/libs/prx/libSceAgcDriver/tests/PerformanceOverlay.cpp`, or a small separate local program linked like the test, so it renders and reads back these frames:
   - **A:** 1920x1080 SDR (B8G8R8A8 sRGB), the overlay in the top-left corner, over a background that shows the blending: a smooth horizontal gradient from dark blue (0.05, 0.10, 0.25) to orange (0.90, 0.55, 0.20). Use the composition with both profile lines shown, i.e. `ComposeOverlay` with GPU and DRIVER enabled, filled with fixed sample values: FPS 59.9, frame 16.7 ms, a 120-frame history of mostly 16.7 ms with a few 33 ms spikes, GPU 9.8 ms, DRIVER 4.2 ms.
   - **B:** the same at 1280x720, to show the smaller scale.
   - **C:** the same as A with the overlay in the bottom-right corner (`ANYPS5_OVERLAY_POS=br`).
   Crop each to the overlay panel plus a 48-pixel margin, so the images stay small.
3. Encode each as PNG with Python's standard library (zlib, struct; no Pillow needed), then base64-encode it.

Report in `results/cloud-<n>/PRM-004.md` on `cloud-results`, text only:
- the exact head and how you rendered: the local change as a diff, the sample values, the crop rectangles;
- for each image: its size in pixels, its PNG byte size, its sha256, and the base64 between lines `-----BEGIN PNG A-----` and `-----END PNG A-----` (B and C the same);
- a short RESULT: block.
Keep each PNG under ~200 KB. If one is larger, use a smaller crop and say so.

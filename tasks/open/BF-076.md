## Where the refusals are (at f4549448f7)

- **`core/shader/recompiler/Optimization/src/ResourceTracker.cpp:643`:** the nested branch of `TryMakeTableColumn` returns false for `sampler`. That branch is the one where the heap handle is a `GetBufferResource` whose own V# is a table column, through an indirect parent pointer.
- **`ResourceTracker.cpp:715`:** `TryMakeIndirectColumn` accepts a low pointer word merged through a Phi (`PointerRecordOrigin`) only when `buffer` is true.
- **The materializer:** `NestedColumn` and `ReadColumn` in `ResourceMaterializer.cpp` already size a sampler record at 4 dwords. `ResolveImageTables` builds the map that the image and sampler records use.
- **The emitter:** `EmitTableWord` in `SpirvBackend/src/SpirvImageEmitter.cpp` emits the nested lookup, a dictionary search on the two pointer words, then the inner table. It fails with "has a nested image table without its buffer pointer" otherwise.

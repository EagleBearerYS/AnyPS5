# PRM-059: rerun agc_driver_pipelined_fill_gpu_heap under load with #9697's test fix on both trees
from: AnyPS5 PR Manager
for: any
priority: high

## Why

PRM-056 found #9508's `agc_driver_pipelined_fill_gpu_heap` failing more often under load on #7642's rebased head (fork `rebase/7642-on-9508-5547aa1` = 9e843c1a9e) than on #9508 alone (5547aa11ef): 8/350 against 1/350, all with "AGC graphics: a satisfied WAIT_REG_MEM skipped an overlapping queued write". PRM-058 (claimed) measures the same A/B again.

The Bug Finder traced the failure to the test-side race that #9697 fixed on `main`. Its commit **9587c4467b** ("test(agc): share the pipelined fill blocker with its lambda and end each case on an empty pipeline") is test-only: one file, `tests/execution/PipelinedFill.cpp`. In the race, a completion item outlives `WaitIdle` by about 0.2 ms, so the next case reads `Outstanding()` too early. Neither tree has that commit, because #9508's head predates its merge.

This task checks that with the fix in both trees, the failures go away on both.

## Steps

1. Make two trees, in separate build directories on the same machine, as the unprivileged user:
   - base: `refs/pull/9508/head` from `upstream` (expect 5547aa11ef) plus a cherry-pick of 9587c4467b;
   - head: fork `rebase/7642-on-9508-5547aa1` (9e843c1a9e) plus the same cherry-pick.
   If the cherry-pick conflicts on either, stop and report the conflict.
2. Build both with CI's configure flags, with `3rdparty/Vulkan-Headers` at #9508's pin (`git submodule update 3rdparty/Vulkan-Headers`).
3. Run each tree's `agc_driver_pipelined_fill_gpu_heap` with its ctest entry's exact environment (`ctest -N -V -R '^agc_driver_pipelined_fill_gpu_heap$'`) and its own `.prx` files.
4. Interleave the runs: 6 concurrent loops, each alternating base and head, 60 iterations per loop, so 360 runs per tree.
5. Record `nproc` and the load average.
6. Also run, once on each tree alone, `ctest -R '^agc_driver_pipelined_fill(_gpu_heap)?$' --repeat until-fail:10`.

# BF-251: libSceAudiodec M4AAC extended decoding modes (Mortal Shell II, PPSA34008): find the source, then implement only what it names

from: Bug Finder
for: any
priority: normal

## Why

Mortal Shell II (PPSA34008) stops 28 s in on Linux (JJenkx, RX 6650 XT) with:

`libSceAudiodec` `M4AAC extended decoding modes are not implemented`

- **The run:** main + #8091 (merged since) + #11580; see #11580 issuecomment-6458735445 and D#8844.
- **Where it throws:** `core/libs/prx/libSceAudiodec/Export.cpp`, `createAac`. It reads `extensionMode` at byte 24 of the M4AAC parameter block (when `ui_size >= 28`, range 0..1) and `outputMode` at byte 28 (when `ui_size == 32`, range 0..2), and throws if either is nonzero.
- **Who wrote it:** boykopovar, 8de11f73ee "validate aac sizes and extended mode ranges" (10-21) and f38d29fd08.
- **What we know:** the title sets one or both. Which one, and to what, isn't known.

No open PR covers it (`gh search prs "audiodec m4aac"` finds none). The source rule applies: a mode is implementable only when a source names what it does.

## Do

1. **Claim check.** Open PRs, unmerged PRs closed in the last 14 days, and forks of open-PR-limit authors that touch `libSceAudiodec`'s AAC path or these fields. Any claim: stop and report it.
2. **Sources.** Find what `extensionMode` and `outputMode` mean, from:
   - the SDK names in the repository's canonical headers (f38d29fd08), if they name the fields;
   - other emulators' `sceAudiodec` M4AAC code (shadPS4, Kyty, …), with commit links and lines: what they read at those offsets, and what they do for each value;
   - public documentation, if any.

   Say plainly what each source says and doesn't say.
3. **Decide.**
   - If a source names the behaviour of a value (for example, "1 enables HE-AAC SBR/PS decoding", or "output mode 1 is …"), implement **only that value** in `createAac` and the decode path, with tests of the named behaviour.
   - For HE-AAC, check what main's AAC decoder can do: if SBR or PS decoding isn't there, say so and stop. That is a feature, not a fix.
   - A value no source names stays the throw.
   - If nothing is sourced: no code. Report what is missing.
4. **If you implement:**
   - one or two commits on `upstream/main`;
   - fork branch `fix/audiodec-m4aac-extension-modes`;
   - red/green against main for each new case;
   - `docs/dev/debt/libSceAudiodec.md` updated for what stays unimplemented.

## For each PR (the same steps for every one)

Base: `upstream/main` at **66702f1cff**. `git fetch upstream main` and check that the commit is there. `origin` is the fork in this environment, so use `upstream` for every upstream ref.

1. **Head.** `git fetch upstream pull/<N>/head`. If it differs from the head listed below, use the new head and say so.
2. **Merge.** On a scratch branch at 66702f1cff, `git merge --no-edit <head>`. If it conflicts, list the conflicting files, run `git merge --abort`, and go on to the next PR. Don't resolve anything.
3. **Build** with CI's configure flags (`.github/workflows/build.yml`'s Linux job), incrementally in one build directory, then run `tools/check_test_registration.py build`.
4. **CI's Linux job, mirrored**, as an unprivileged user: `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx ctest --test-dir build --output-on-failure --timeout 120 --parallel 4 --output-junit ctest.xml`, then `tools/check_skips.py build/ctest.xml`.
5. **Its own tests.** These are the tests whose files or registrations the PR's diff (`git diff 66702f1cff...<head>`) adds or changes. Run each with `--repeat until-fail:10`.
6. **Failures.** Compare every failure with the baseline. Rerun a failure that isn't in the baseline 3 more times on its own. Report it as a flake only if it then passes, and give the counts.

**Baseline first:** steps 3 and 4 on 66702f1cff alone, on the same machine and in the same build directory.

**Known on these machines:**
- the IPv6 failures: four `guest_datagram_*` tests and `guest_tcp`;
- `guest_sce_net` skips;
- `agc_driver_preparation_scope_settle` is load-sensitive;
- `agc_driver_store_over_untracked` has failed on Linux on older mains (#5671).
Report any of these as baseline only if the baseline run shows it too.

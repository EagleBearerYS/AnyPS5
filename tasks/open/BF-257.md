# BF-257: libkernel_sys: thread suspension from FreeBSD 11.4 libthr, plus sceKernelSettimeofday

from: Bug Finder
for: any
priority: normal

## Why

BF-250 (`results/cloud-3/BF-250.md`) lists these as sourced bare stubs on main, unclaimed except for #8747's closed declaration list.

- **The suspension group** (`core/libs/prx/libkernel_sys/Export.Discovery.cpp`, around L320-340 on main):
  - `pthread_suspend_np`, `pthread_suspend_all_np` and `pthread_single_np`. FreeBSD 11.4 (8c639945a4) `lib/libthr/thread/thr_suspend_np.c` and `thr_single_np.c` name their behaviour.
  - Main already has the resume side, merged in #9573 (zaryabzip): `pthread_resume_np`, `pthread_resume_all_np`, `pthread_multi_np` and create-suspended. They go through `ResumeGuestThread_nid_no_patch` / `ResumeAllGuestThreads_nid_no_patch`.
- **`sceKernelSettimeofday`:** shadPS4 7ea677e56d `src/core/libraries/kernel/time.cpp` L565 maps `posix_settimeofday`'s errno to an SCE error. Main's `settimeofday` is done (#9682).

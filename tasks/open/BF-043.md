# BF-043: red/green test, cost and CI Linux mirror for the HTILE re-read fix (a #5627 regression that halves Planet of Lana)
from: Bug Finder
for: any
priority: high

## Why

Planet of Lana (PPSA19450) runs ~1.8× slower on current main than on a 10-11 build (7.06 against 12.7 fps at its L-meadow checkpoint, Windows, RTX 3070 Laptop). A profiled pair on this PC named the cause.

- **The code:** `storeBackClearedHtile` in `core/libs/prx/libSceAgcDriver/Graphics/src/DepthSurface.cpp`, added by #5627 (3e61fcf1f9, merged 10-15). Before each bind of a depth target with HTILE, it reads and scans the whole pipe-aligned HTILE (`HtileMetadataBytes`, 640 KiB to 1 MiB at the title's sizes).
- **The check it skips:** an "unchanged since the last read" memo (`htileReads`, `UnchangedSince`). That memo is skipped whenever `Recorder::PendingWriteOverlaps` finds any recorded GPU write over the HTILE. So until the writing batch is reaped, every bind re-reads and re-scans the whole HTILE, and the binds before the batch finished also wait for it (`[hooksync]` pending-write syncs).
- **In the title, per 780-s profiled run:** 1.14 M store-back reads (~700 GB), ~210 GPU waits per 10 s, and `[draws]` prepare at 5.7–7.7 s of every 10 s. On the 10-11 build it was 34–50 ms.

## The fix (already written)

Fork branch **`fix/agc-htile-reread-on-new-write`** at **24a11c115f**: one commit on upstream main 9bf01db663, `DepthSurface.cpp` and `DepthSurface.hpp` only.
- A read records `{CollectWrites generation, recorder, Recorder::NewestWriteNote(htile, bytes)}`. The note is stored only when `PendingWriteSettled` holds after the read; otherwise it's 0.
- A later bind skips the read when:
  - the memo's generation is non-zero and `UnchangedSince` holds;
  - and either no write note is pending over the HTILE (main's existing case), or the newest note is the one the memo recorded, on the same recorder.
- So a new GPU write over the HTILE, which gets a newer note, or a CPU or driver write, which stamps the tracker, forces the next read, as #5627 requires.
- Counters: `Graphics::HtileStoreBackReadCounts()` returns `{made, skipped}`.

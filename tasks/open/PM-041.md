# PM-041: restore the multisample read guard on lazy shader-memory capture pages (a regression from #1193), as a held fix branch
from: AnyPS5 Project Manager
for: any
priority: normal

#1193 ("perf(agc): cheaper shader-memory captures per draw", MichonGoddijn231849) merged into upstream main at 09:34 UTC, 2026-10-15. Main is now 1db84d5748. It dropped a safety check.

- **Before** (042eb7c801, `Execution/src/ShaderMemory.cpp:104-111`):
  - A page first touched by a capture was read whole with `GuestMemory::Read(base, page.words, sizeof(std::uint32_t))`.
  - `Read` runs the read guard first (`GuestMemory.cpp:2004`: `readGuard`, then `FlushGpuWrites`).
  - `MultisampleTarget.cpp` installs that guard (`:344` `GuestMemory::SetReadGuard(&guardReads)`; `:233-234` `RequireNoMultisampleTarget(address, bytes, "a CPU read")`).
  - So a capture over a live multisample target's memory threw. `tests/Recorder.cpp:6212-6304` checks the same refusal for the plain reads.
- **Now** (1db84d5748, `ShaderMemory.cpp:189-194` and `:220-223`):
  - The page gets only `GuestMemory::FlushGpuWrites(base, PageBytes)`, which runs the flush hook and not the guard, and then `page.lazy = true`.
  - Each 64-byte block (`BlockWords = 16`) is later copied with `std::memcpy` straight from guest memory.
  - No guard runs, so that capture reads the stale guest bytes silently.
- **Status:** no known title hits it.
  - We're offering the fix on #1193. It opens as a PR on a maintainer's yes or on a title's symptom.
  - So this task is branch and report only: no PR, nothing upstream.

## Tasks
1. **The fix,** on current upstream/main (1db84d5748 or newer), as fork branch `fix/agc-guard-lazy-capture-pages`.
   - Expose the guard from GuestMemory, e.g. `GuardRead(address, bytes)`, which runs `readGuard` when one is installed.
   - Call it over the page in `ShaderMemory::page` before the page is flushed and marked lazy. That keeps the old check at the same point and over the same range as the old whole-page `Read`.
   - Judge whether the block copy needs the check as well, for example:
     - a target that goes live between the marking and the copy;
     - a pooled page reused by a later capture (#1193 added the pool).
   - Pick the cheapest form that keeps the old semantics, and say why.
2. **Red/green:** a contained test whose capture's first read lands on a page overlapping a live multisample target.

# BF-366: build the fork's `diag/native-depth-publication-9533` on Linux, run the native depth tests, and show its refusal print once

from: Bug Finder (PC)

## Why

Three titles that ran before our merged #9533 + #9717 (merge `a4b76b2c0a`) now stop on current main. They are Curved Space (PPSA02817), NINJA GAIDEN: Ragebound (PPSA28002) and Blue Prince (PPSA25009), bisected by a tester on Linux/RADV. Each stops with:

```
AGC graphics: native multisample depth publication cannot distinguish an unwritten byte from a same-value guest store
```

That's `DepthSurface::PublishToGuest` (from #13021). The fork branch **`diag/native-depth-publication-9533`** (head **7a04c3f5b5**, one commit on upstream main 1c8c0efc8c) changes what happens at that refusal:
- It finishes scanning the three planes, prints `[native-depth-diag]` lines (the access, the target and per-plane counts), then throws the same message.
- It also prints one line per publication request (the first 16, then every 256th).

We'll ask the tester to run it, so it must build and must not change any test's result.

## Do

1. **Build:** fetch `diag/native-depth-publication-9533` from the fork (`git fetch fork diag/native-depth-publication-9533`, or the fork's URL if your clone has no `fork` remote). Check that its head is 7a04c3f5b5 and its parent is upstream 1c8c0efc8c. Build with CI's configure flags. Report any warning in the five changed files: `DepthSurface.hpp/.cpp`, `GuestBufferMemory.cpp`, `MultisampleTarget.cpp` and `ShaderResources.cpp`.

   ```

   ```

   Paste the test list and pass/fail/skip counts. Do the same on upstream main 1c8c0efc8c for comparison, if your build tree for it is at hand; otherwise say so.

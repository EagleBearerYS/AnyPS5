## What to add
Each line is shown only when its data exists. Gather everything cheaply, at most once per frame or once per second, and only while the overlay is shown. The guarantee stays: hidden means no commands and no extra work beyond what the first PR does. Where a per-packet increment is unavoidable, use a plain per-worker counter, not a shared atomic, and say what it costs when hidden.
1. **DRAWS:** draw packets and dispatches per frame, averaged over the last second, for example `DRAWS: 1240  DISPATCH: 85`. Take them from the packet workers' existing packet path. The `[draw] driver phases` line in DrawTiming.cpp counts draw packets under APS5_PROFILE_DRAW; the overlay's count must work without that switch.
2. **VRAM:** the device-local heap's usage against its budget, from VK_EXT_memory_budget, which the driver already enables and queries (`memoryBudget` in VulkanDevice.cpp, `heapBudget`/`heapUsage` in ShaderResources.cpp). For example `VRAM: 6.1/7.8 GB`. Query it at most once per second. Omit the line without the extension.
3. **RAM:** the process's private memory, once per second: GetProcessMemoryInfo's PrivateUsage on Windows, the equivalent from /proc/self on Linux. Keep the platform code minimal, following how the project already splits platform code.
4. **SHADERS:** pipelines created in the last second, plus the running total, so compile stutter is visible. Count at the driver's pipeline-creation choke point. If there's no single one, count where a pipeline-cache miss leads to creation, and say where you counted.
5. **RES:** the display buffer size and the window or swapchain size, for example `RES: 1920X1080 / 2560X1440`.

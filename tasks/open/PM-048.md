## Context

Our #6636 (`perf(agc): reuse address-based draw builds whose inputs are unchanged`, head ec17620356) composes with two other open PRs, but each pair needs one check that only fits once both are in. We've publicly committed to adding it if #6636 merges second, and to offering the code if it merges first. This task prepares both checks now, so whichever happens, the code is ready.

1. **With #6646** (ours: `fix(agc): plan a heap again when its mirror's range has left the write watch`, head 48c17f97dd, branch `fix/agc-heap-mirror-replan-unwatched` on the fork).
   - #6636's `ResumeSpace` refreshes a cached space's heap runs after `spaceMiss` finds the space current. That reaches the same "a heap mirror's range is no longer write-watched" check #6646 replaces.
   - **The resolution** (GAC-040's result §6, `results/cloud-2/GAC-040.md`):
     - `spaceMiss` returns a new `SpaceMiss::Unwatched` when a heap mirror of the cached space fails `heapMirrorWatched`;
     - `AcquireRegistered`'s `switch` gets `case SpaceMiss::Unwatched: break;` in place of #6646's `else hit = std::all_of(...)`;
     - `heapMirrorWatched` is defined above `spaceMiss`.
2. **With #6628** (MarcZX100: `fix(agc): exclude native MSAA spans from BDA tables`, head 4c415b5135, `upstream refs/pull/6628/head`).
   - A reused build keeps the `BdaResources` table it was built with (`ShaderResources.cpp:1918` in #6636), and #6628 makes that table depend on `MultisampleTargetRangeGeneration()`. None of #6636's space checks read it.
   - **The resolution** (as posted on #6636):
     - `BdaResources` keeps the guard generation its table was built or found under and exposes `TableCurrent()` (true while that equals `MultisampleTargetRangeGeneration()`);
     - the address-based reuse proof in `Revalidate` refuses the hit when `!bda->TableCurrent()`, so the draw builds anew.

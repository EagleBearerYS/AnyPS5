## Why

Lane B's goal is Resident Evil Village (PPSA01556) at ≤ ~16 GB private at its menu. With #7644 it's at ~21.4 GB.

On Windows, main commits the whole guest page-state table at start-up:
- **Where:** `core/libs/prx/libSceAgcDriver/Execution/src/GuestMemory.cpp:377` on today's main: `VirtualAlloc(nullptr, count, MEM_RESERVE | MEM_COMMIT, PAGE_READWRITE)`.
- **How much:** span / 4 KiB bytes. That's 250 MiB for Village, of which only ~12% is ever written at its menu (BF-064's census).
- **Linux** already gets this for free: calloc'd pages stay uncommitted until touched.

BF-071 (cloud-5, 2026-10-17) built two commits on fork `perf/agc-guest-tables-on-touch-v2`:
- 60fbcddcd2, the write tracker's block tables per leaf on Windows. **Drop it:** eljackjoestar-cmd's #6701 ("allocate Windows write-tracking stamps on demand", f06e5d4ebf) merged on 2026-10-19 and does the same.
- **9a6d8ba486, "perf(agc): commit the guest page-state table on first touch on Windows".** This is the one to rebuild. It adds `Execution/include/TouchedTable.hpp`:
  - Windows reserves the table and commits 64 KiB pages on first write.
  - A bitmap of committed pages is read before any load, and untouched loads return zero.
  - The first write commits under a mutex, with release order.
  - Run scans, `AnyOf`, `Max` and `Clear` skip untouched pages.
  - Linux is unchanged.
  - Tests: `agc_touched_table` (the commit charge of 64 scattered regions in 250 MiB, a 200k-op equivalence check, 8-thread first writes) and a Windows-only commit-charge check in `agc_write_tracking`.
  - Micro-bench: +0.8 ns per load and +0.9 ns per store when cache-resident, within noise when memory-bound.

Village measured both halves together as lane B's arm qlb5: −637 / −732 MB private at menu +1 / +10.

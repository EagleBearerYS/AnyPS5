- **PM-027** (in progress, `perf/shader-direct-cpu-evaluable-images`) removes tables for T#s the CPU can evaluate. This task covers what remains: columns that stay tables, meaning T#s selected per lane, and anything PM-027 can't make direct.

## Tasks (on current upstream/main)
1. **Design the skip.** A column whose source ranges (`tables.ranges`, or whatever the snapshot reads) have had no write since the previous snapshot reuses that snapshot's words and its resolved results, with no re-read and no per-record work.
   - Use the driver's existing write knowledge: GuestMemory stamps / `UnchangedSince` / generations, recorder pending writes, driver stores (`MarkWritten`), and DMA, CP and compute writes.
   - Spell out every way a write can reach table memory and how each invalidates the reuse. That includes CPU stores to unwatched or compared memory, which may need a byte compare, and ranges outside the write watch.
2. **Build it** behind no switch if it's clearly sound, or with an off-switch for debugging only.
   - Memory must stay bounded: a per-thread or per-device memo with eviction.
   - Thread safety: several queue workers capture at once.
3. **Tests:**
   - unchanged table → no re-read (a counter);
   - CPU write, GPU write, DMA fill, pending GPU write, and unwatched memory → re-read, and the new words are seen;
   - the key changes but the table doesn't → the correct record;
   - the existing image-table execution tests (`agc_driver_image_table*`, `agc_driver_bindless_images`) and `^agc` stay green.
4. **Microbenchmark,** before and after: repeated captures of an unchanged 32,768-key table, and of a 65,536-record heap. µs and words read per capture, plus the cost when every capture follows a write (the worst case).
5. **Overlaps:**

   - PM-027's branch: both must stack, so say how. Rebase onto PM-027's branch if it's pushed by then, or note the order;

## Commit 2: `fix(agc): ...` the fast proof refuses a sampled image whose memory became a multisampled target

The report: jotitadev on #6636 (review 5566570447), macOS / MoltenVK.
- `agc_driver_address_draw_reuse` fails at its `ThrowingProof` case: "an address-based draw build whose sampled image's memory became a multisampled target was reused".
- It fails when imports stay watched (the default there, and `APS5_WRITE_WATCH_IMPORTS=watch`).
- It passes with `APS5_WRITE_WATCH_IMPORTS=unwatch` or `APS5_NO_FAST_REVALIDATE=1`.
- So with watched imports, `fastRevalidate` finds the image's memory unchanged after `MultisampleTargetView` takes it over, and accepts the reuse. The full walk would throw, which counts as a refusal and is what the test expects.

The reviewer asks: "make the fast proof refuse that case (and check whether a cached non-address draw has the same gap), ideally with a Linux test using `APS5_WRITE_WATCH_IMPORTS=watch` so CI covers it".

1. **Reproduce first on Linux:** `APS5_WRITE_WATCH_IMPORTS=watch ctest -R '^agc_driver_address_draw_reuse$'` at commit 1. Report whether it fails at `ThrowingProof`. If it doesn't fail on Linux, find what differs from macOS's watched imports and report that before changing code.
2. **Find the cause in `fastRevalidate`:** what it compares, and why a GPU-side change of an image's owner (a sampled texture's memory becoming a multisampled color target) leaves nothing it sees.
   - Fix it at that cause. For example, make the fast proof also compare whatever the multisample-target registry changes when it takes over memory, or refuse the fast proof when one of the build's sampled image ranges is now a multisampled target.
   - Keep the fast path's cost for the common case, and say what the fix adds per proof.
3. **Register a second ctest of the same binary,** for example `agc_driver_address_draw_reuse_watched_imports`, with `ENVIRONMENT APS5_WRITE_WATCH_IMPORTS=watch` and the same properties as the existing registration, so CI covers it. It must fail without the fix and pass with it.
4. **The non-address case:** check whether a cached non-address draw (the decode cache and `Revalidate`'s fast proof for non-address builds) has the same gap, with a case that turns a sampled image's memory into a multisampled target between two uses.
   - If it has the gap, fix it in the same commit with its case.
   - If it doesn't, say why in the report.
5. **One debt sentence** in `docs/dev/debt/libSceAgcDriver.md`, next to the "Reused address-based draw builds" entry, only if something stays open. Keep that entry under 1,000 characters if you touch it (`check_conventions.py` warns over that).

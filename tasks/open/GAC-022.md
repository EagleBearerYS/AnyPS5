## Context

The folded DCC fix (cc5772a466, LabelHistory.cpp) makes `Driver::noteLabelStore` call `NoteKeysStore` for every recorded packet write with known bytes:
- packet stores;
- WRITE_DATA and RELEASE_MEM labels;
- deferred labels when they are recorded;
- label writes the CPU executes after a drain.

For one-value bytes, `NoteKeysStore` takes `GuestMemory::GpuMutex()` and runs `StorageTexture::ClassifyFill`. A zero label is one value, and titles write many. Before this, the note ran only in PacketMemory's packet-store path. Under the user's completeness rule, a fix's cost has to be measured, and it must not add a deadlock.

## The source rule (since 2026-10-25, after the review of #10900)
A function is implementable only when a source or a measurement names **its own** behaviour. That means its implementation in shadPS4, Orbital, Vita3K, RPCS3, dlc_emu or another emulator, a disassembly note or decompiler listing already in the tree, a public SDK header or sample, or a published console measurement.
- **Not enough:** a sibling's or twin's answer, a matching call shape, or a table or state that no source names.
  - A twin counts only when a source shows that this function forwards to it or shares its code.
  - In #10900, MarcZX10 pointed out that no source names a ForLib callback table, and the three ForLib calls went back to throwing (404d3812c0).
- **What to do with such a function:** it stays a throw, and it goes on the dropped list with the reason.
- **What to cite:** for every implemented function, the source line that names that function's behaviour (URL with a pinned commit, or `path:line` in the tree). A citation of a sibling in the same library doesn't count.
- **Apply this before Step 0's floor:** count only the rows that pass it.

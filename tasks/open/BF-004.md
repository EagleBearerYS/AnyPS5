1. Configure: `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ -DCMAKE_C_COMPILER_LAUNCHER=ccache -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DANYPS5_ENABLE_SPIRV_TOOLS=ON`. Drop the ccache launchers if you have no ccache.
2. `python3 tools/check_test_registration.py build`
3. `cmake --build build`, then `cmake --build build --target libs`
4. As an unprivileged user: `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx ctest --test-dir build --output-on-failure --timeout 120 --parallel 4 --output-log ctest.log --output-junit ctest.xml`
5. `python3 tools/check_skips.py build/ctest.xml`
6. `ctest --test-dir build -R '^agc_write_tracking$' --repeat until-fail:20 --output-on-failure`

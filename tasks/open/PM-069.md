## Why

The output-resolution change opens soon as its own PR (the user: "a pretty significant one in terms of what it fixes").
- On main every 4K title renders 3840x2160 whatever the display, because `sceVideoOutRegisterBuffers2` accepts display buffers of any size.
- The branch adds `ANYPS5_OUTPUT_RESOLUTION`, the output resolution the console reports. It also refuses display buffers larger than that with 0x80290005, as a console set to 1080p does, so titles fall back to a smaller render size.
- PRM-035 found it clean on CI's Linux job.

This task is the adversarial review a feature PR gets before it opens, plus the one test PRM-035 found missing.

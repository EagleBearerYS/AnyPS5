from: Bug Finder

## Why

The AGC redesign is approved (`pr-drafts/arch/redesign.md`, "Lanes"; the user, 2026-10-16 21:54 PT). Lane A moves texture binding to run time: shaders read their SRT and T#/S# from guest memory and look textures up in a device image table, instead of the CPU resolving every table per draw.

**This task is the recompiler half,** ported from fable-void's `wip/new-gpu-path` (head ed8f2d7a2e) onto current upstream main:
- a recompile option that emits the run-time path;
- with the option off, main's output is unchanged, byte for byte.

**The driver half is BF-048,** in parallel. You meet at the image table's ABI (`DeviceImageTableAbi.hpp` on his branch): take his ABI as is unless BF-048's result says otherwise.

His branch: `git fetch https://github.com/fable-void/AnyPS5.git wip/new-gpu-path`. **Fetching, building and porting his branch needs the user's OK in your own chat.** The PM is asking for it. Don't start without it.

## What to port

- **SRT read at run time:** b745f685f6, 08354cfe73, c75864796f, 650fc07b4f, 856b943fbf, fcf5835a10.
- **The image-table lookup** in `SpirvBackend/src/SpirvImageEmitter.cpp`: the 15-word key, hashing, up to 16 probes, the null descriptor and miss-ring record for an unnamed key.
- **The inline hit path and the per-invocation segment cache:** 84c3e8af38, 99d057d6a5. His helper calls cost 2.73 → 7–8 ms per dispatch until these.
- **Avoid his pipeline-creation trap** (a 541k-word module took 60 s; 2.7M words took 325–334 s):
  - don't emit an inline mode per possible format at every image access;
  - report module words per program in your measurements;
  - say which of his later fixes you took (85da056989 and related).

## What to do

1. **Port** onto current upstream main behind a recompile option, for example `RecompileOptions::runTimeImages`. With it off, the recompiler tests and the disk cache output are unchanged: check a corpus of the existing test shaders byte for byte.
2. **Tests:** his recompiler tests for run-time SRT/T#, adapted:
   - a program reading a T# from a 2,000-entry table by an index from user data;
   - one reading through a pointer chain;
   - one with an unnamed key on first use.

   Run spirv-val on every module.
3. **Measure on lavapipe:**
   - module words and creation time per test program, with the option on and off;
   - the GPU cost of the lookup's hit path against a constant descriptor index, using BF-048's table if it's there, or his test harness.
4. **Check:** `ctest -R '^(agc|recompiler|shader)'` with the option off, which must equal main; the CI Linux mirror.

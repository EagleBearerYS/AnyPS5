## Rules for this task

- **Read-only on code:** this task builds and tests. It changes no code and pushes nothing but its result to `cloud-results`.
- **Remotes:** use `upstream` for upstream refs (`refs/pull/N/head`). Post nothing upstream and open no PRs.

## Context

Upstream's CI skips its Linux and Windows jobs for these PRs (its Linux job needs upstream's self-hosted runner). So a mirror of CI's Linux job on a cloud worker is the only full-suite Linux run a PR's head gets. Tonight's mirrors (PM-060, PM-061, PRM-012) covered eight heads; these five open PRs of ours have no full-suite Linux run at their current heads either. (#6457 and #6451 are left out: their heads sit under #6730 and #6683, which PM-061 and PM-060 ran.)

- #6146 25594523ae (fix(agc): execute the DB's out-of-place depth expand)
- #6366 e986ee0f7a (fix(agc): leave a stage the title's pipeline ABI cannot prepare to its first use)
- #6012 e09870006d (feat(agc,videoout): show an optional performance overlay with F10)
- #5966 896b737700 (fix(libSceNet): let a datagram receive on an unbound socket wait on Windows)
- #5967 7f82da1080 (fix(libSceNet): read SO_RCVTIMEO and SO_SNDTIMEO as a timeval in sceNetSetsockopt)

## Task, for each head, in the order listed (one tree rebuilt per head is fine; ccache helps)

1. `git fetch upstream refs/pull/<N>/head` and check that it equals the head above. If the PR has moved, use the new head and say so.
2. CI's configure flags (`-G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DANYPS5_ENABLE_SPIRV_TOOLS=ON`), the build, and `python3 tools/check_test_registration.py build`.
3. As an unprivileged user: `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx ctest --test-dir build --output-on-failure --timeout 120 --parallel 4 --output-junit ctest.xml`.
4. `python3 tools/check_skips.py build/ctest.xml`.
5. Compare against this worker's baseline: without IPv6 the `guest_datagram_*` tests and `guest_tcp` fail and `guest_sce_net` skips, and `agc_driver_preparation_scope_settle` is a known flake under `--parallel 4`. Rerun any other failure alone ×5. If it still fails, check whether it also fails on upstream main 5d9dcc42d2.
6. **#5966 and #5967** are libSceNet fixes, and some of their own tests may be among the IPv6 baseline failures. Name which of each PR's own tests ran and which the baseline blocks, so the result doesn't read as coverage it isn't.

## Result

- the `check_skips` and registration output;

"Clean against the baseline" for a head is the expected answer.

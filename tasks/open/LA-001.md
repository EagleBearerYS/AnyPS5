# LA-001: lane A base. Upstream main plus the PR 6947 stack (GPU descriptor heap), built and tested on Linux with its switches off and on

## Why

Lane A of the approved AGC redesign (`pr-drafts/arch/redesign.md`) moves image tables to run time: a shader reads a T# from its table at run time and finds its descriptor through a device-side key table, so the CPU stops resolving every table record per draw. On upstream main, Resident Evil Village's menu snapshots tables of 32,768 records (48-byte records, the T# at byte 16) at about 8 ms per snapshot.

The Bug Finder decided to build lane A on Raghav314's open upstream PR 6947, "perf(agc): GPU descriptor heap (APS5_GPU_HEAP)", instead of porting a rival heap. PR 6947 gives GPU-mode stages one global image heap (4096 slots per image kind) and a sampler heap (256 slots), and leaves image tables on the per-draw path. Lane A fills that gap.

PR 6947 is stacked on upstream PRs 6946 (`APS5_DRAW_PIPELINE`), 5656 and 6632. Its head `refs/pull/6947/head` was fab8dc64b0 at 2026-10-17 05:12 UTC, based on main 2fab88d102. A test merge onto main 750eb13d87 conflicts in only two files.

This task makes the base branch every later lane A task builds on, and its Linux test baseline.

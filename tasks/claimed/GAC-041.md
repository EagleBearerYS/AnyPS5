## The problem

#6479 ("perf(agc): take the host import budget from the device's memory budget") makes the effective import budget at most the host heap's `VK_EXT_memory_budget` budget, less its other usage, less an eighth.

On Resident Evil Village (PPSA01556), RTX 3070 Laptop GPU, NVIDIA driver 617.42, Windows 11, 15.4 GB RAM, with `APS5_HOST_IMPORT_MIB=6400` set:

```
[gpu] host import budget: 3752 MiB live of 4480 MiB (APS5_HOST_IMPORT_MIB); 85047 imports (115203 MiB) refused so far, 9691 of them remembered, last 0x230200000+0x30100000 by build
```

- **F3's cap was too low.** It lowered the configured 6400 MiB to 4480. 6400 MiB is known to run clean on this machine, with no `vkAllocateMemory (-2)`; failures start at 6864 MiB. That is in the PM's comment on #6472, https://github.com/boykopovar/AnyPS5/pull/6472#issuecomment-6197485344.
- **The cost:** 85,047 refusals (115 GB). It likely set up a heap-mirror stop (GAC-040) and costs speed.
- **The sampled texture cache line at the same time:** `device-local heap 0 has a VK_EXT_memory_budget budget of 7250 MiB and uses 3367 MiB`. That's the device-local heap; the host heap's numbers weren't printed.

## The fix the PM set (in the user's name)

1. **An explicit `APS5_HOST_IMPORT_MIB` wins** over the device cap. The user set it, so it isn't lowered by the report. The failure-driven ceiling still applies, so a real `vkAllocateMemory` failure can lower it.
2. **With no explicit setting,** F3 doesn't cap below main's default (the largest host heap less 2 GiB, or whatever main's default rule is on the branch's base) unless a `vkAllocateMemory` failure has happened. The lower-on-failure path stays as is.
3. **Check why the report is low.** Why does NVIDIA's `VK_EXT_memory_budget` give ~4480 MiB of room when 6400 runs clean? Is "others' usage" (`heapUsage − min(heapUsage, live)`) counting the game's own host buffers, mirrors or staging, which the driver can share? Or is it NVIDIA's report itself (WDDM's local budget vs the commit limit)?
   - Read the code: what F3 subtracts, and what other driver allocations land in that heap.
   - Change the formula only if you can show from the code and documentation what it double-counts. Otherwise rules 1 and 2 are the fix.
   - Print the host heap's budget, usage and the import live bytes once, in the existing budget line (or a sibling), so a Windows run shows them.
4. **Tests,** red on #6479's head, green with the fix:
   - explicit setting vs a lower device report;

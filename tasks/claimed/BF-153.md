## Why

Ratchet & Clank: Rift Apart (PPSA01474) gets past `LoadAddressU32@pc=0x13bc0` with our #9749 (6db7b36aef). It then stops 425 s in, in compute 0x116bb61900, with `ShaderRecompiler::Recompile: sampler resource limit exceeded`. The two captured #9633 requests (0x116bb67b00 and 0x116bb5e100) replay to the same stop. This is Tamalero's report (Linux, RTX 4090): https://github.com/boykopovar/AnyPS5/pull/9749#issuecomment-6347108120.

**The refusal:** `AddSampler` (`core/shader/recompiler/Optimization/src/ResourceTracker.cpp:1892-1904` on `main` 0def01bcb5) dedups by descriptor source and refuses past `ShaderInfo::MaxSamplers = 32`. `:2042` then fails with the title's text.

**A gap in our own #7527 (bab404e7af):**
- #6243 (ours) gives every CPU-keyed table read a one-record table of its own, a `selected` column, so N reads of one heap become N sources.
- #7527 made `PlanTableColumns` (`:1383-1405`) re-plan while the estimate is over a limit, unselecting the largest selected group (`LargestSelectedGroup`, `:1460-1495`, which spans image and sampler columns alike) until it fits.
- But `PlannedWithinLimits` (`:1407-1459`) returns `images.size() <= MaxImages && pairs.size() <= MaxSampledPairs`. It computes each pair's sampler, but never counts distinct samplers against `MaxSamplers`.
- So a shader with 33 to 64 sampler sources from selected columns, within 64 images and 64 pairs, is refused. Before #6243 those columns would have shared one source.

**Not known yet:** whether Rift Apart's shader is this case, or whether it needs more than 32 genuinely distinct S#s. Tamalero offered to count. This task builds the fix for the gap either way, since it's a real gap on `main`, and gives Tamalero a branch to replay.

## The change

In `PlannedWithinLimits`:
- collect the distinct `sampler` values, exactly as `AddSampler` will key them: a column source, or a direct handle with its sample-adjust flag;
- return false when there are more than `ShaderInfo::MaxSamplers` of them.

The existing loop then unselects the largest selected group until images, pairs and samplers all fit, or no selected group is left (then `AddSampler` refuses as today).

**Checks:**
- The estimate must never count fewer samplers than `Collect` adds, so it can't plan a shader that then refuses. Say how you checked that the two key the same way: direct samplers, sample-adjust, nested image tables (#9457's code isn't on `main`, but check `main`'s own table-column kinds), and samplers read through `FindTableColumn`.
- Factor out a shared key helper if one is needed, as #7527 did with `ImageKey` and `SameImageKey`.
- **No change to `MaxSamplers` or the 32-bit sampler masks.** `DescriptorBindingBuilder.cpp:519` and the driver's `Sampler.cpp` and `ShaderResources.cpp` take `std::uint32_t` masks with `1u << element`. Widening those is a separate question, decided by Tamalero's count.

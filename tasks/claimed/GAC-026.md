- **The event:** in the #5703v2 check boot (-ports 4cd4260a9a + #5703's follow-ups, `APS5_HOST_IMPORT_MIB=6864`, import trace off), the log has one `[gpu] host import of 0x1f02000000+0x800000 failed at vkAllocateMemory (-2); falling back to copies`. - **Why it matters for F3:** F3's plan drops an adaptive ceiling to the live bytes at a `vkAllocateMemory` failure.

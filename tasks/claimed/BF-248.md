## Why

Ghost of Tsushima Director's Cut (PPSA02225), on a tester's 16 GB Windows NVIDIA machine, stops at:

`a CPU read of 0x1500000000+0x98600000 overlaps multisampled color target 0x1544ed0000+0x1fe0000 (2 samples), whose samples are only on the host: guest access to it is not implemented`

How it gets there:
- The host import of that 2,438 MiB range fails, so the range goes to a new mirror.
- The mirror's fill (`GuestMemory::Read` → `GuardRead` → `guardReads` in `MultisampleTarget.cpp`) reads the whole range on the CPU.
- The 2-sample colour target in that range is the colour alias over a native multisample depth plane, the one #9742 accepts when HTILE proves its clear.

#7002 (Amoenus, open, head `f84c2139bd`, MERGEABLE with main) changes `guardReads` into `SynchronizeMultisampleTargetRead_nid_no_patch`. On a guarded CPU read, that publishes the overlapping native colour target to guest memory (`PublishMultisampleTargetColor_nid_no_patch`) and then reads. That is this read. We want a tester branch that adds #7002 to the stack the tester runs, and an answer to one question (below) before we offer it.

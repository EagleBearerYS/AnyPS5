## Context

- On our Resident Evil Village (PPSA01556) fast tree, with every import settled (`APS5_SETTLE_FLOOR_KIB=0`), the static menu runs at 0.5 fps with private memory flat at ~18.2 GB.
- In the first scene, private memory grows ~200 MB a minute (23.9 → 24.9 GB in 5 min), so a session ends at the PC's commit watchdog after ~15–20 min.
- There the host import budget is pinned at its 6400 MiB setting, with 7.1 M address-based build refusals; at the menu there were none.
- **The leading suspicion** (from GAC-041's result §2, `results/cloud-3/GAC-041.md`): each refused import is served by a host-visible stand-in copy (`copyBufferProperties(false)`, kept in the buffer pool's retention tiers) or a heap mirror (`APS5_HEAP_MIRROR_MIB`, 24 GiB by default). If those are retained per build, per range or per epoch and not reclaimed, memory grows with the refusal count.
- The Bug Finder is reading the profiled scene from this PC and may add an addendum with its numbers. Read `tasks/claimed/PM-049.md` again before you finish, in case it has.

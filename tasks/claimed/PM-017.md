## Why
- PM-016 records unlocks posted directly as `_UnlockTrophy`. Many PS5 titles unlock instead through statistics: a title's `sce_sys/uds/udsNN.ucp` maps posted events to stat updates, and its `sce_sys/trophy2/trophyNN.ucp` gives each trophy an `unlockCondition` on a stat.
- Resident Evil Village (PPSA01556) may work that way. A Village trace on the PC will tell, but this part is needed for most titles either way.
- The same trophyNN.ucp holds the names, grades and groups that Trophy2 reports as placeholders today.

## What to build (on top of feat/np-trophy-unlocks; new branch feat/np-trophy-stats)
1. **A `.ucp` reader.** Use the container layout PM-016 documented from KytyPS5's interface facts: big-endian magic 0xB228C60A, version 1, size at 0x08, entry count at 0x10, TOC offset at 0x14, and 0x40-byte entries from TOC+0x20 (a 32-byte name, a big-endian offset, a big-endian length).
   - Bounds-check everything. A malformed file logs once and disables only that feature.
   - Read the title's files at run time from its own `sce_sys` (find how AnyPS5 resolves the title's app0/sce_sys paths). Never bundle any.
2. **Trophy metadata** from trophyNN.ucp's `tropconf.json` (`trophies[]`: id, grade "PGSB", groupId, hidden, platinumTrophyId, unlockCondition) and `tropmeta_<lang>.json` (names, details, groups). Trophy2's queries then report real names, grades and hidden flags. Pick the language from AnyPS5's system language setting, with English as the fallback.
3. **Stat rules** from udsNN.ucp:
   - `stats_definition.json` gives `statDefinitionArray`, with the aggregation, at least "latest" and any others documented publicly;
   - `stats_extraction.json` gives `statsExtractionRuleArray`, where `condition.eventName` plus `action.input` become `action.output.statId`.
   On each posted event, apply the matching rules, update the per-title stats (persisted next to PM-016's unlock file), and evaluate every trophy's `unlockCondition` (`udsStatId`, `targetValue`, `comparator` ge/gt/le/lt, `progressive`). Unlock through the same path as PM-016, with the same log line, the same listener hook and the same persistence.
4. **Platinum:** if tropconf names a platinum and every trophy it requires is unlocked, unlock it, if that can be established from the public data. Otherwise, say so in the result.

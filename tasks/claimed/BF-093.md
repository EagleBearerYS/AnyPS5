## Why

Lane C's first piece, C-1 (upstream #7184), merged on 2026-10-17. Its next piece is the per-packet CPU tail. That's what a draw still costs once binding resolution, capture and recompiles are gone, and the redesign's target of ~30–45 µs per draw needs it cut.

**On Resident Evil Village's (PPSA01556) menu** (the fast tree, profiled, per draw packet):

| phase | µs |
|---|---|
| decode | 19.9 |
| precheck | 6.0 |
| program prepare | 4.1 |
| epilogue: from `Graphics::Draw`'s return to the packet's end | 49.5 |
| skipped and labels | 9.7 |
| recording inside `Graphics::Draw` | ~37 |

**On a harness:** BF-046's floor arm costs 57.5 µs of driver CPU per draw (runs 56–73) on lavapipe. Per draw it still does decode, target lookup, descriptor sets, push constants, recording and keep. The bench is fork `exp/bf046-main` b7d6d98610 (`tests/execution/VillageDrawCost.cpp`, ctest `agc_driver_village_draw_cost`). The floor is fork `exp/bf046-floor` 767ec61bd6 (`APS5_FLOOR_REUSE=1`, wrong output allowed). The method is in `results/cloud-2/BF-046.md`: `LP_NUM_THREADS=2`, and driver CPU by thread (`qworker`, `draw-commit`).

**Main has changed this path since 10-18,** so the 10-18 split above is a guide, not today's numbers. Merged since then:
- #6566 (TheAggie): fewer heap allocations per recorded draw;
- #7489 (AlxcBTW): skips the staging, write-back and label-run leading barriers that a covering barrier already orders;
- #6931 (AnthonyClemens): CPU-path indirect draws queued on the draw pipeline;
- #5656 (Raghav314): data-only draw hits compare only the user words a stage reads;
- e4898783b6: `APS5_SAMPLE_COMMITTER`, a sampler for the draw committer. Use it if it splits the committer's side better than clock pairs.

Open PRs on the same path, to read before you cut, so we don't build what someone has published: #7930 (AnthonyClemens: skip CPU-path indirect draws that draw nothing), #6188 (mitul72: compile uncached draws ahead of queue 0), #5925 (adriadam10: build a submission's pipelines ahead on a compile pool), #1896 (fisherjoey), and #6946 (Raghav314: the draw finisher pipeline). If your largest part is one of theirs, measure their PR on the bench instead of writing ours, and report it.

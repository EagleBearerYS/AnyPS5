## Why

#6678 (our open PR, "settle Windows imports under 1 MiB without blocking") made Planet of Lana (PPSA19450) ~12% slower on the PC with its deferred settles on. The suspected cause is the number of submissions to the settle queue: an import lookup polls every 100 µs and can submit one batch per poll.

Fork branch `followup/6678-settle-batching` **aaa1a3856e** is two commits on #6678's head 5f822a5008:
- ebccff674f `feat(agc): report deferred settle counts from the settle poll, with batches submitted`;
- aaa1a3856e `fix(agc): submit deferred settle reads once a batch fills or its oldest read has waited 100 ms`, with a new Windows ctest, `agc_import_settle_batching`.

The settle path and all `agc_import_settle_*` tests are Windows-only (`#ifdef _WIN32`, registered under `if(WIN32)`). So on Linux this task checks only that nothing else changes. The red/green of the new test runs on the PC.

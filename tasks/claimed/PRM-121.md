### Ask 1: overflow cleanup can drop writes newer than the proved baseline

- `Execution/src/GuestMemory.cpp`: once a subscription has `MaxRecordedBumps` (1024) bumps, later bumps aren't recorded and `overflowedAt` is set (:169-171). `TrimSubscriptionBumps(sub, B)` (:254-258) then clears the overflow and every bump whenever `overflowedAt <= B`.
- `B` is read before the proof work: `Graphics/src/ShaderResources.cpp` around 3870, before `fastRevalidate`, and `indexBaseline` around 4105, before the full revalidation that runs after an overflow fallback. The trim is at :3763. CPU, driver and pending stores can bump the subscription from other threads in between. Those bumps are newer than `B` and weren't recorded because of the overflow, so the trim forgets them, and the next partial proof's `SubscriptionBumpsSince(B)` (:236-241) returns a list without them.
- **The maintainer's sequence:** fill the 1,024-entry history, overflow at generation G, take the fallback baseline G, finish that proof, then bump another block at G+1 before the receipt trims G. The G+1 bump isn't recorded, trimming G clears the overflow marker, and on the next call `SubscriptionBumpsSince` succeeds with no blocks, so the partial index path can accept without checking the changed element.
- **The fix they ask for:** clear the overflow only when the subscription's generation still equals `B`, checked under the index mutex. Otherwise keep it set and erase only bumps `<= B`.
- **The test they ask for:** a case that overflows, bumps after the baseline read, and expects the next proof to fall back. Put it beside the existing write-index cases (likely `tests/execution/TableIndexValidation.cpp`, or wherever the subscription-bump cases live; read the PR first). It must fail on `4922da2dec`'s code with its own message, and pass with the fix.

### Ask 2: agc_driver_table_index_validation doesn't run in ctest

- Execution tests are `EXCLUDE_FROM_ALL` and registered only through `agc_add_default_test` or a `tests/cmake/<name>.cmake` fragment. `TableIndexValidation.cpp` has neither, and it needs `APS5_TABLE_INDEX`, so its ten event-source cases never run.
- Add `core/libs/prx/libSceAgcDriver/tests/cmake/agc_driver_table_index_validation_tests.cmake`, following the other fragments (look at `agc_driver_sampled_cache_budget_tests.cmake`, which this PR also edits). Register `agc_driver_table_index_validation` with `ENVIRONMENT "ANYPS5_NO_SHADER_CACHE=1;APS5_TABLE_INDEX=1"` and `SKIP_RETURN_CODE 77`, plus the Windows PATH line if the other fragments' tests that link libc have one.
- Make the test return `VulkanTestSkipped` (77) instead of 0 when there is no write watch, so a machine without one shows as skipped, not passed.

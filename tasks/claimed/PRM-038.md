```
fix(videoout): refuse display buffers larger than ANYPS5_OUTPUT_RESOLUTION

Reporting the configured size alone moved no title. With the setting at
1280x720 or 2560x1440, Animal Well (PPSA22520) and Planet of Lana
(PPSA19450) still registered 3840x2160 display buffers, as Resident Evil
Village (PPSA01556) does on main, which reports 1920x1080 and the HD
class before registration. These titles do not size their buffers from
sceVideoOutGetResolutionStatus or sceVideoOutGetOutputStatus.

With the setting, sceVideoOutRegisterBuffers2 now refuses main-output
buffers wider or taller than the setting, other than 1920x1080, with
VIDEO_OUT_ERROR_INVALID_RESOLUTION (0x80290005). SharpProspero documents
that answer for a size the console is not set up for, and that
1920x1080 is accepted on any console. A title that registers 3840x2160
and falls back on that answer then registers a size the setting allows.
The refusal is logged at its 1st, 2nd, 4th and later power-of-two
counts, with the count, so a title that keeps retrying shows in the log.
A buffer attribute change and PS4 display buffers of such a size throw,
because the console's answer to them is not known. Without the setting
nothing changes.

guest_video_out_output_sequences plays the sequences a title can use to
pick its size (the reported status, the reported class, output mode
probes, 3840x2160 with a 1920x1080 fallback, a second set at 3840x2160,
an attribute change) at each setting and checks each answer.
```

## Why

In Resident Evil Village (PPSA01556)'s first scene, the 6400 MiB host import budget is full. On the settle tree, one build range is refused over and over. qsW's log printed this line 126 times (text only; no game data):

```
[gpu] host import budget: 6399 MiB live of 6400 MiB (APS5_HOST_IMPORT_MIB); 5978411 imports (634831 MiB) refused so far, 5315222 of them remembered, last 0x2372400000+0x80000 by build
```

- **Cost, in bf-settle's profiled scene:**
  - 37,627 refusals per present, and 469,842 of the run's refusals were not remembered;
  - import lookups take 710 ms per present (floor 0: 12 ms);
  - every refused use copies the range on the CPU.
- **Why each refusal is expensive:** #6457's 4a84bbf917 remembers the refusals of requests that may not evict. "A request that may evict always tries again", so each of these requests runs `evictableBytes` over all ~4,400 live imports and is refused again.
- **Why eviction never succeeds there** (from the code; part 2 confirms it):
  - An address-space hit stamps every import its space maps (`region.direct->lastUse = stamp`).
  - `UploadFinish` then sets `buildFloor` to that build's floor.
  - `evictable()` needs `!pointerHeld && lastUse + 256 < useCounter`.
  - With ~72 address-based builds per second, the imports the space maps never age past 256 uses.

## Part 1: the fix (code, on the fork)

1. **Remember an evicting request's refusal while its outcome can't change,** and answer later requests for that run from memory. They still count as refused and as remembered.
   - **The memory must expire as soon as the request could succeed:**
     - an import retired or made (`epoch` and `liveBytes`);
     - the budget changed, or one of the run's ranges changed;
     - evictability could have changed. Recency lapses after `protectedUses` more uses, and a raised `buildFloor` unholds imports.
   - Pick the cheapest rule that is exact or errs toward retrying. A wrong "refused" means CPU copies for good, so retrying is the safe side.
   - Say in the result how often the memory expires in a steady state with ~72 address-based builds per second.
2. **Requests that may not evict keep #6457's behaviour unchanged.**

   - The request imports the range again, rather than answering from memory, after:
     - an import retires;
     - the budget is raised;
     - enough uses pass without a restamp for an import to become evictable.

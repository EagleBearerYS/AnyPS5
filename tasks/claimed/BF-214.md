## What
#9749's tester Tamalero ran our v4 diagnostic (fork `test/9749-diag-callers-v4` 516e1dcf8f) on Ratchet & Clank: Rift Apart (PPSA01474), on main plus #9633 and #9749. The title stops at 1,300 s:

```
compute shader 0x116bb76f00: runtime image descriptor is invalid: image 4 source 104 r128 0 active 1 words 04efd000 00040011 00017a00 00005204 0af00000 00000000 00000612 00fff000
[image-source] image 4 flags: class 2 dimension 3 mip mode 0 read 0 written 1 atomic 0 depth compare 0 table 4294967295 first use pc 0x390
```

The full output is at https://github.com/boykopovar/AnyPS5/pull/9749#issuecomment-6394778216; quote what you need from this task, since upstream pages give you 403.
- **The image:** image 4 is a storage image that is written and never read, with no table. Its 8 words are SRT words 44–51, and in this dispatch they hold a buffer V# (base 0x1104efd000, stride 4) and four small words.
- **No overlap:** no other source reads those slots.
- **No pruning:** both blocks that hold the store are reached only over edges with no recorded condition, so the activity pass can't drop it.
- **Why it stops:** word 3 is `00005204`, so TYPE is 0. `nullImageDescriptor` (`core/shader/recompiler/Optimization/src/ResourceMaterializer.cpp`, near L101) accepts TYPE ≤ 1 only for a read-only slot with no table. That rule came from measurements:
  - #4139: simonbbby on gfx1036, and billythemenace2 on gfx1010;
  - #5828: sample, load and resinfo through a TYPE 0/1 T# return zeros with no fault.
  Written and atomic slots were left throwing because nobody measured a store.

### Part 2: the fix, ready behind the measurement
- **Branch:** `fix/shader-null-storage-image-type0` on current `upstream/main`, independent of #9749.
- **What it does if stores are dropped:** a static, written, non-atomic slot with no table, whose T# has TYPE ≤ 1, is bound as a null storage image: writes are discarded and loads return zero, as Vulkan's `nullDescriptor` (robustness2) defines.
  - Change it in both places #5828 changed: `nullImageDescriptor(const ImageResource&, const DescriptorValue&)` in the recompiler, and `IsNullTextureResource` in `Graphics/src/GuestTextureResource.cpp`.

  - Atomic slots keep throwing.

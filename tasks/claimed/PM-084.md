# PM-084: why queue 0 drains its draw pipeline before other packets, and how to keep order without draining
from: AnyPS5 Project Manager
for: any
priority: normal

## Why
On Resident Evil Village's menu, queue 0's packet worker hands draws to a committer thread (`DrawPipeline`, from #1201/#1202). Before some non-draw packets it waits for the committer to empty. A profiled run shows, per 10 s, `drains: packet 260-354 (522-726 ms) ... indirect 119-140 (2390-2504 ms)`, with packet drains by opcode `0x50 x207-286, 0x15 x39-52, 0x40 x8-10, 0x93 x6-7`. The indirect drains are #1896's subject (fisherjoey). This task is about the packet drains, which will be the next serialization once #1896's are gone.

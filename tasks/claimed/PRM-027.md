# PRM-027: #6944, shrink the thread-local lookup log after an oversized build
from: AnyPS5 PR Manager
for: any
priority: high

CnRJay reviewed #6944 ("fix(agc): keep a build's own texture lookup records past the log bound", branch `fix/agc-lookup-log-fits-build`, head bde2a8f0af, one commit on upstream main f474fb7768; review 5554223875). One small code point:

> The thread-local log keeps the capacity of the largest build (272,000 bytes for 2,000 textures) on every thread that ever built one. Shrink it after a build that exceeded the old bound, so a loading thread doesn't hold it for the life of the process.

The code: `ShaderResources.cpp` at bde2a8f0af, lines ~384-420. `logLookup` keeps at most `bound` (1024) records, except that it no longer drops a running build's own records (`buildLookupsStart`), so one build can grow the vector far past the bound. `BuildLookups`' destructor (the outermost one) ends a build. The vector's capacity stays at its peak afterwards.

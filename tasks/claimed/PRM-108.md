## Context

- **PRM-106** (`results/cloud-5/PRM-106.md`) read #12840's failing case. #12840's head is 6bec085232.
- **The case:** `core/libs/prx/libSceAgcDriver/tests/BdaResources.cpp:2896-2917`, in `heapMirrorTests`, from 781dc4525b. It runs only where the guest arena exists, which is Windows (`:2795-2799`; `libc/src/GuestArena.cpp:184-192`). On Linux it prints `guest arena unavailable or not write-watched: heap mirrors not tested`.
  - On GitHub's Windows runner it fails at `:2906`: "a writable heap mirror a program stores to through addresses is not writable in the BDA table".
- **PRM-106's reading:** the case is stale against #12840's own later commits.
  - `AddressRanges` (`Graphics/src/GuestBufferMemory.cpp:6177-6212`) gives a written part:
    - `Read|Write|Masked` on a **copy-backed** mirror (`:6193`);
    - `Read|Write` on a resident mirror's **bound** block;
    - `Read|Write|Spill|Masked` on a resident mirror's **unbound** block (`:6194-6210`).
    The case expects plain `Read|Write` for every part.
  - Since bf54c5e942, 99f1f37aed, bbeb08e9f6 and 7e7c81a2aa, `WriteBack` with address stores writes back only the declared ranges and the pages reported through `NoteAddressStores` / `NoteStorePages`, as `ShaderResources.cpp:6005-6006` does for the GPU. The case writes bytes 1000 and 65536+2000 directly and reports nothing, so `:2917` would fail even where `:2906` passed.
  - Production is right per that reading: a copy-backed range is writable, `Masked` records the stored bytes, and 7e7c81a2aa writes them back. `agc_driver_bda_store_heap_mirror` covers that path on Linux, with real shader stores and `SetResidentAddressSpaceLimit(1)`.

## What to do

1. **Re-read PRM-106's lines at 6bec085232** and confirm them, or show them wrong. If production turns out wrong (a copy-backed writable mirror not writable, or its stores not written back), stop. Write it up with no commit.
2. **The fix:** one test-only commit on 6bec085232, branch `prm/12840-heap-mirror-case` on the fork, changing only `tests/BdaResources.cpp`:

# BF-163: imports that map a read-write alias demote resident runs before #9159 marks them (GTA V's remaining zlib faults)
from: Bug Finder
for: any
priority: high

## Why

Grand Theft Auto V (PPSA04264) still crashes in its "[RAGE] HDD Streamer" thread with #9181 and #9159 applied. tibzejoker linked one crash to a single resumed write at zlib's `inflate_fast` (eboot +0x28aa8ab) into a 16 KiB `MEM_MAPPED` view ([#9136 comment](https://github.com/boykopovar/AnyPS5/issues/9136#issuecomment-6356302049)). Windows' exception dispatch writes below `rsp`, which overwrites the guest's red zone (#361). Their local copy of BF-162's change (the mark kept on `Physical`) still had the faults, so another path arms these views.

**The path found by reading, at fork `fix/agc-compared-when-shared-remap` 47c8df4950** (BF-162, one commit on #9159's head 99aeb0ac56):
1. `importAllocation` (`core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp`, ~`:1712-1740`, Windows) checks each region of the import range. When the range is not all writable private memory, for example a resident run next to a shared page in the same 64 KiB block, it calls `GuestArenaMapAlias_nid_postfix`.
2. `WindowsMappings::MapAlias` (`core/libs/prx/libc/include/WindowsMappings.hpp`, ~`:287-330`) `demote`s every resident run inside the range. Those pages become shared views (`MEM_MAPPED`), and `demote` sets `slot->stored = true`, so every later `Map` of that physical memory is a shared view too (`single()` at ~`:107`). Only `ForgetSection` clears it.
3. Only then does `GuestMemory::ImportWatched` run (`GuestBufferMemory.cpp` ~`:1758`, `staysWatched` = `watchedHostPointer`). After the import, it marks with `GuestArenaCompareResidentWhenShared_nid_no_patch` (`Execution/src/GuestMemory.cpp` ~`:1603`), which skips pages that are no longer resident (`if (residentOnly && !it->second.resident) continue;`, `WindowsMappings.hpp` ~`:194`).
4. The pages the import itself demoted are left unmarked. Its own armed-only walk, or the next clearing collect, arms them through `Collect`'s alias loop (~`:454-466`), and a guest store faults.
- `demote` keeps the `collected` bits of the run, so `Collection::Armed` selects them.
- Each later import that overlaps one of these pages takes the alias path again and demotes its neighbours, so the shared set can grow over a session.

## Context

Upstream's CI skips its Linux and Windows jobs for these PRs (its Linux job needs upstream's self-hosted runner). So a mirror of CI's Linux job on a cloud worker is the only full-suite Linux run a PR's head gets. Tonight's mirrors (PM-060, PM-061, PRM-012) covered eight heads; these five have no full-suite Linux run at their current heads, and they're on the user's merge-request list for the morning, so a clean run backs each request.

- #6243 090c0dad15 (perf(shader): select the record of a T# whose offset the CPU evaluates)
- #6455 285ac78c06 (fix(agc): stamp the watched blocks of a store into partly watched memory)
- #6475 07a4ac7e15 (fix(agc): run the read guard over a shader capture's lazy pages and raw word reads)
- #6470 a61c30bff6 (fix(recompiler): run a pixel shader the guest does not iterate once per pixel)
- #6641 6522b92fde (fix(agc): stop and join the driver's thread pools at shutdown)

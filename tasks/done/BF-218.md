### What to check
1. **Stub correctness against #5640's design** (read #5640's code on main and its PR text in `git log d01070d6c3^2`).
   - **Short exits:** the stub borrows the instructions just before the exit, runs them with RSP still lowered, then raises RSP, pops and returns. Check that:
     - every borrowed instruction is position-independent, or re-encoded;
     - RSP-relative operands are moved by exactly the lowered amount;
     - flags and other registers come out of the stub exactly as the original sequence leaves them;
     - a branch target landing inside the borrowed range is refused.
   - **Short prologues:** the stub pushes, lowers RSP, then runs the borrowed instructions. Check the same points, and whether anything can jump into the middle of the original prologue.
   - **Leaves without pushes or an allocation:** RSP is lowered on entry and raised before `ret`. Check every exit (tail calls, multiple `ret`s, `ret imm16`) and every RSP-relative access.
   - **The rbp-only push case (07798774b6):** check that it frames correctly whether rbp is used as a frame pointer or only saved.
2. **The refusals:** check that each refusal reason in the relinker output is correct and covers what can't be framed (branch, `ret`, RIP-relative, and the others listed).

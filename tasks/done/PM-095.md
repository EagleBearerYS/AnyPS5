## Why

The user wants a generic way for players to make titles render below 4K (dev-chat users keep asking). PM-094's research (results/cloud-5/PM-094.md on `cloud-results`) ranks an **app0 overlay** first. A directory beside `app0/` whose regular files shadow app0's lets a player replace a data file, such as a Unity title's `Media/boot.config`, without editing the dump. Build it exactly as PM-094 section 2 specifies. Read that section first; it has the behaviour, the hook points at `a701f9f788` and the test table.

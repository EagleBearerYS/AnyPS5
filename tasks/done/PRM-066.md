# PRM-066: #12840 review: zero stores into unbound blocks are lost; pin store-page exhaustion

## Why

#12840 (`fix(agc): write back BDA stores into writable heap mirrors`) is ready for review. Its head is **425cd9d8b0**: upstream `refs/pull/12840/head`, the same commit as fork branch `fix/agc-bda-store-writable-mirror`.

oneandonlydean reviewed that head: https://github.com/boykopovar/AnyPS5/pull/12840#issuecomment-6518837738. Two of the three points are code.

1. **A store of zero into an unbound block is lost.**
   - In `core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp`, `WriteBack`'s unbound-block path (line ~6489 at 425cd9d8b0) calls `store(first, current, std::vector<std::byte>(current.size()))`. It compares the store page with zeros, so only the non-zero bytes reach guest memory.
   - So a thread that stores `0x00`, or a dword `0`, over a non-zero guest byte in an unbound block of a resident heap mirror leaves the old byte.
   - The copy-backed path a few lines below (~6519-6524) already writes only the bytes whose bit is set in `entry->mask`.
2. **Store-page exhaustion is a hard stop, and no test pins it.** A dispatch that stores to more distinct pages than the pool holds faults with `FaultReason::StorePages`. `BdaResources.cpp:372` then throws "... found none of the N store pages free (APS5_BDA_STORE_PAGES)". The reviewer asks for a test at pool + 1 pages, and for the description to say what a title sees.

## What to do

1. **Check the mask first.** Confirm that the shader's store-page code sets the per-byte mask bits for stores that are redirected into a store page for an unbound block of a *resident* mirror, not only for copy-backed mirrors. That code came in fbb103c45f; find it from `PipelineSpecialization::StorePages`. If the redirect path doesn't set the mask, make it.
2. **Fix:** in the unbound-block path, write the masked bytes only (written byte = stored byte where the mask bit is set), as the copy-backed path does, instead of comparing with zeros. Keep the counters (`spilledBytes`, `comparedBytes`) meaningful.
3. **Test** in `core/libs/prx/libSceAgcDriver/tests/execution/BdaStoreHeapMirror.cpp`. The unbound cases use `fill = bound ? 0x11 : 0x00` (line ~515), which can't show the bug.
   - Add a case where the guest block holds non-zero bytes and a thread stores zero, both a byte and a dword, into an unbound block of a resident mirror. After the write-back, guest memory reads 0 there, and the neighbouring bytes keep their value.
   - Do the same on a copy-backed mirror as a control.
   - **Red:** the new case on 425cd9d8b0's code. **Green:** with the fix.
4. **Exhaustion test.** Keep it cheap by setting `APS5_BDA_STORE_PAGES` small (for example 4) for that case.
   - A dispatch that stores to exactly `slots` distinct unbound pages succeeds, and its stores reach guest memory.
   - One that stores to `slots + 1` pages fails with the StorePages message.
   - Assert the documented failure. This is a real refusal path, not a `NotImplemented` placeholder.
5. **Report, as text, for the PR description:**
   - what a title sees on exhaustion (a stop with that message; raising `APS5_BDA_STORE_PAGES` is the workaround);
   - whether a fallback is feasible, for example binding the block and taking the masked path, with a rough cost. Don't build it unless it's small and safe.

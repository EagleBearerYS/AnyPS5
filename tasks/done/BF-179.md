# BF-179: libSceNetCtl: sceNetCtlGetResult reports no error for IPv4 events, as sceNetCtlGetResultV6 does (two titles stop on it at boot)
from: Bug Finder (2026-10-23 02:5x PT, sweep pass 11)
for: any
priority: high

## Why

`sceNetCtlGetResult` throws on upstream main after its checks (`core/libs/prx/libSceNetCtl/Export.cpp` ~584):

    throw std::logic_error("sceNetCtlGetResult: service event results are not implemented");

Two titles stop on it:
- **Worms Armageddon: Anniversary Edition (PPSA20052) 01.003.000,** 2 s into boot on `main` 44a59edc3a, with no earlier stop: `what():  sceNetCtlGetResult: service event results are not implemented`. JJenkx reported it on upstream issue 9851 (comment of 2026-10-23 08:53Z) and in discussion 10082.
- **Monster Hunter Wilds (PPSA24191),** upstream issue 9851: with the earlier keyboard stop stubbed and no network, it stops here. MarcZX10 narrowed the first call to event `1` (DISCONNECTED).

**The precedent in the same library:** `sceNetCtlGetResultV6` (Export.cpp ~785, merged in upstream PR 8321) accepts `NET_CTL_EVENT_DISCONNECTED`..`NET_CTL_EVENT_IPOBTAINED`, writes `*error_code = 0` and returns 0. For any other event type it throws `... event type N is not implemented`.

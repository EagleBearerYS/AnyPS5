- B266-1, B267-1, B268-1 and B268-2 are open PRs;

## Do

1. **Freed claims:** take every sourced row those tables mark as claimed by a PR or a fork branch. For each claim, give its state today:
   - merged: the row is done; drop it;
   - open;
   - closed unmerged, with why (read the closing comments).
   A row is free only if its claim closed without a maintainer rejecting the approach, and nothing has replaced it.
2. **Sourced-blocked rows** (BF-268 lists 14, the others have their own): is the blocker merged or gone now?
3. **New sources:**
   - **shadPS4:** main moved from 0614ce324b to 1d8004a22f, changing 5 library files, all `np_handler`/`np_score` plus `save_data/save_backup.cpp`. Any row they newly give a real body is a new sourced row.
   - **fpPS4:** check its main for library files changed since the date BF-268 used.
   - Stubs that only log and return OK are not sources (the coverage source rule: the source must name the function's behaviour).
4. **The claim check** on every candidate from steps 1-3:
   - open upstream PRs, by changed files **and** by title or body search for each function name;
   - PRs closed since 10-15;
   - fable-void's fork;
   - the limit forks BF-268 named.
5. **Batches:** group free sourced rows by library. A batch is 4-12 rows in one library.
   - **If one reaches 4, build the top one:**
     - on fork `feat/<library>-sourced-b299-1`;
     - one commit on `upstream/main`, stacked on an open PR only if the rows need its types (then say which, and why);
     - exactly the source's behaviour;
     - a debt entry: console behaviour unmeasured, the source named, differences listed;
     - tests in the same commit;
     - red: main's throwing bodies with the new signatures abort the new cases; green: `--repeat until-fail:10`;
     - no placeholder-throw assertions.
   - **If none reaches 4,** build nothing and list the best partial groups.

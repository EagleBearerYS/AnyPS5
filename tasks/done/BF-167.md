## Why

BF-163 (cloud-5, results/cloud-5/BF-163.md) built fork `test/9136-shared-arming-diag` (8c97f618e9, on fix `fix/agc-import-alias-compared-when-shared` 1ad5f29e20). On each resumed write into a shared view, `HandleWrite` prints:
- the page;
- its alias count;
- `stored`;
- `comparedWhenShared`;
- `aliasDemoted`;
- the collect that last armed it.

Its audit found three ways a page that was resident becomes an unmarked shared view, which any of 106 copy-tracked clearing collects then arms:
1. `MapAlias` (an import over a mixed range): fixed by BF-163 for spans the import keeps watched, still open when the import fails;
2. `Map`'s shared path: a second guest mapping of one page demotes its **whole** resident run;
3. `breakRun` (from `reset`, so from `Map`, `Reset` and `Commit` at a boundary inside a resident run): it demotes the **whole** run, and the pages outside the range stay mapped once, as shared views.

Grand Theft Auto V (PPSA04264)'s remaining zlib faults (#9136, two crash logs) hit "fresh 16 KiB `MEM_MAPPED` views". Paths 2 and 3 fit that as well as path 1. One run of tibzejoker's with a diagnostic that names the path tells us which fix to build.

## Do (a new commit on `test/9136-shared-arming-diag` 8c97f618e9; it stays diagnostic only)

1. **Record why each view was demoted.** `View` gains a `demotedBy` value with these cases:
   - `none` (never demoted, or mapped shared from the start);
   - `alias` (from `MapAlias`);
   - `secondMapping` (from `Map`'s shared path), and whether this page itself is the doubly mapped one or another page of the run;
   - `breakRun` (from `reset`), with which of `Map`, `Reset` or `Commit` reached it.

   Set it in `demote`, from each caller. Also record `stored` at the time of the page's last `Map`, and whether that `Map` was resident or shared.
2. **Print it.** Add these fields to the existing `[shared-arming]` line, keeping its rate limit (first 64, then every 1000th).
   - **Totals line:** every 10 s, or at the 64th line and then every 1000th, print the counts of resumed shared writes by `demotedBy` (and by "mapped shared from the start"). The counts must still come out if the title crashes later.
   - **Output path:** write each line with `std::fprintf(stderr, ...)` followed by `std::fflush(stderr)`. On Windows the module's `stderr` is `HostStandardErrorFile_nid_no_patch()` (`core/libs/prx/libc/include/HostStandardStreams.hpp`).
3. **Test it under Wine,** as BF-163 did: a scratch probe (not committed) that drives each of the three paths and a store into each armed page. Show each path's printed line.
4. **Merge check:** check that the branch merges cleanly with `refs/pull/9181/head` (d6e270ea9f), since tibzejoker runs #9181 with #9159. If it doesn't, give the resolution.

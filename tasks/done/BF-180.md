# BF-180: #9159: a refused collect must not let a pre-sharing generation read as unchanged (embersas's stale sampled read)
from: Bug Finder (2026-10-23 04:2x PT)
for: any
priority: high

## Why

Our upstream PR 9159 (`fix/agc-rewatched-imports-compared-when-shared`, head **1ad5f29e20**) makes rewatched direct memory "compared when shared". embersas found a stale read in it, combined with #9181 (upstream PR 9159, comment 6363081974; Windows 11, RTX 3080 Ti).

**The ordering:**
1. 128 KiB of direct memory; `Unwatch` then `Rewatch` on its first 64 KiB block; described as a 128×128 R32_UINT tiled texture.
2. The sampled texture is cached, with production `CachedSampledTexture`.
3. The memory is shared through a second mapping.
4. One 4-byte CPU store, with no lookup between sharing and the store.
5. A GPU `texelFetch` reads every texel.

**The result:** the first lookup returns the old texture with no comparison, and the GPU reads the old texel. The next lookup compares and corrects it. On main, every ordering is correct.

## The mechanism (confirmed by reading the code at 1ad5f29e20)

- **`Rewatch`** (`Execution/src/GuestMemory.cpp` ~1526) now calls `GuestArenaCompareWhenShared` before walking. That sets `page.comparedWhenShared` on every page in the range (`libc/include/WindowsMappings.hpp` ~190-200), resident pages included.
- **While the pages are resident,** `collectable()` (~519) checks only `!watchResident`. So the walk succeeds and `coverage.Restore` runs: the block is **covered**.
- **Sharing through a second mapping** demotes the resident run (`demote`), so the pages become non-resident views. From then on, `collectable()` refuses them (`found->second.page->comparedWhenShared`), and so does `Collect`'s fresh path (~372).
- **`collectWrites`** (GuestMemory.cpp, `if (!walkWrites(...)) return 0;`) returns 0 and **stamps nothing**. Coverage is untouched, so the tracker still claims to cover the range.
- **The sampled cache's hit** (`Graphics/src/ShaderResources.cpp`, `cachedTexture`'s `unchanged()`) calls `GuestMemory::UnchangedSince(address, bytes, it->generation)` with the entry's **pre-sharing** generation. With no newer stamp it returns true, the old texture is kept, and `it->generation` becomes the collect's 0. The next lookup's `unchanged()` is false at generation 0, so `equalsCommitted()` compares and corrects. That matches the report exactly.
- **On main,** the first collect after demotion walks the demoted pages and reports them written, so `UnchangedSince` fails and the cache compares.

That restores main's "the first collect after demotion reports the range written" for every `UnchangedSince` and `WrittenSince` user, not only the sampled cache.
   - **Check (a)'s steady-state cost.** With a shared, compared range and no writes, every refused collect would stamp again.

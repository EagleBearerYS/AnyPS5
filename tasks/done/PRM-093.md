## Why

jotitadev ran #7642's head **88ad9e88d8** on Linux, on an RTX 3070 (NVIDIA 595.99.02) with the descriptor heap live (https://github.com/boykopovar/AnyPS5/pull/7642#pullrequestreview-5721150049). They ran `^agc` with the switches set for the whole run:
- `APS5_GPU_HEAP=1` alone: the six `agc_driver_heap_slots*` tests pass.
- `APS5_GPU_HEAP=1 APS5_GPU_PATH=1`: they fail, with:
  - `a full heap refuses another owner's view`;
  - `one free slot of eight refuses the heap`;
  - `storage owners that leave one free slot of eight refuse the heap`;
  - `views that leave one free slot of eight refuse the heap`.

Their reading: with the path on, the heap's slot accounting no longer matches what those tests assume. Either a test assumption, like the four #9508 fixed in dfe95cc969, or the device-image table taking slots the tests don't expect.

**No cloud worker has a descriptor-heap device** (lavapipe skips the GPU-heap tests). So this is a code read, plus anything that runs without the heap.

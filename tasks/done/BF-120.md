# BF-120: port the address-based build's eviction before the copy cap onto main (Demon's Souls and ASTRO BOT abort there)
from: Bug Finder
for: any
priority: high

## Why

Two titles abort on current main at the address-based build's copy cap.

**Demon's Souls (PPSA01342), on main 36f60df9e** (https://github.com/boykopovar/AnyPS5/discussions/1283#discussioncomment-19037774):
```
host import budget: 7893 MiB live of 7955 MiB ... 294335 imports refused
FATAL: an address-based build copies 359 MiB ... (outside the write-watched arena)
```

**ASTRO BOT (PPSA21564), on plain main on Windows,** 2 of 2 runs: `FATAL: an address-based build copies 1099 MiB of 1 registered ranges` (https://github.com/boykopovar/AnyPS5/discussions/357#discussioncomment-19058078).

**The cause, confirmed on 10-14 (PM-022, PM-024):**
1. The address-based pass imports with `evict=false`, so the import is refused at the budget.
2. The heap mirror is refused because part of the range is unwatched.
3. The range is copied, and `AddressCopyOverflow` aborts.

Main still doesn't evict before copying (`GuestBufferMemory.cpp` ~3652, the abort at ~3701; the text is at :2963).

**The fix exists, on main of 10-15:** fork branch `fix/agc-address-copy-evict` = 7e8f52f93a.
- 19c1300f91, `fix(agc): an address-based build evicts idle imports instead of copying past the cap`.
- 7e8f52f93a, the test `agc_address_copy_cap` and the related mock-device tests.
- Verify 38838902888 showed main FATAL 3/3 and the fix 10/10 on both Linux and Windows.
- It's 5,065 commits behind main now and conflicts in 6 files: `CMakeLists.txt`, `GuestBufferMemory.cpp`, `tests/BdaResources.cpp`, `tests/BdaTests.hpp`, `tests/Graphics.cpp` and `docs/dev/debt/libSceAgcDriver.md`.

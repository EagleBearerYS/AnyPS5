# BF-139: does agc_driver_pipelined_indirect_draw deadlock on main, or only time out under load?
from: Bug Finder
for: any
priority: normal

## Why

Upstream's push Build of `main` da54c652e3 (run 39725502001, job 119648924514, 2026-10-22 05:04 UTC) failed one test: `agc_driver_pipelined_indirect_draw` printed `pipelined indirect draw: the queue worker and the draw pipeline deadlocked` after 21.8 s. That line comes from the test's `Finish()` (`core/libs/prx/libSceAgcDriver/tests/execution/PipelinedIndirectDraw.cpp:157-166`), when `AgcDriverWaitIdle_nid_postfix()` hasn't returned within 20 s. The next Build of the same commit (run 39727094000) passed, and the 38 Builds of main before it passed too. That run used ctest with 16 parallel jobs on a 16-core runner.

So either the draw pipeline has a rare real deadlock, which would hang titles, or the test's 20 s idle wait is too short when the machine is loaded. The test is billybobpicklio's (73983f1c29, "queue CPU-path indirect draws on the draw pipeline"). Its siblings `PipelinedFill.cpp:116` and `PipelinedPrefetch.cpp:54` have the same check.

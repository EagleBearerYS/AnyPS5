## What
On #10900, MarcZX10's review pointed out that no source names a ForLib callback table. The PR's own debt line admitted it, and AGENTS.md L7 says unknown general behaviour throws. The three ForLib calls went back to throwing (404d3812c0). The rule from now on: **a function is implementable only when a source or a measurement names its own behaviour.**
- **Not enough:** a sibling's or twin's answer, a matching call shape, or a convention.
- **When a twin counts:** only when a source shows the function forwards to it or shares its code.

Several of our open coverage PRs have rows that rest only on such a basis. Find out, row by row, whether a source names each row's behaviour. This is read-only: no code, no branch.

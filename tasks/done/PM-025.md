## 1. Option 2, the source fix: re-watch on Windows when an import is freed
Without it, one stray window import leaves the heap unmirrorable for the rest of the session. #4448 does this on Linux only.
- **Feasible?** Windows can't re-arm a write watch on part of an allocation without a reset. So it likely needs a re-walk that marks the blocks dirty (or treats them as changed once) when they come back on the watch. Work out the exact sequence with file:line: `coverage.Restore`, `GetWriteWatch`/`ResetWriteWatch` semantics, and what the mirror's generations need so nothing stale is served.
- **Cost:** per retire, and per build if any.
- **Risks:** races with the import still in flight; CPU stores during the gap.
- **Rank it against eviction (PM-024's fix):** do we need both, and which comes first? Build it only if it's small and clearly sound, with its own test (import a window of the heap, retire it, build; the heap must be mirrored with the right bytes). Otherwise give the design and the estimate.

## 2. What eviction does to the normal case
If the address-based pass can evict, Village's 768 MiB heap may end up **imported** (zero-copy) instead of mirrored. Then no heap mirror is refreshed per build, and the scene cost cut #1 attacks would disappear at its source. Report:
- **Why the pass uses `evict = false`.** It may be deliberate: evicting there could drop imports the same build already looked up. Find the commit and its reasoning. If it is deliberate, can eviction exclude the build's own lookups safely?
- **A Village-like budget** (a 5840 MiB budget with 5080 live; idle imports of mixed ages; one 768 MiB heap). With eviction allowed, which imports get pushed out? What do they cost when they are next needed: re-imported, or copied? Does it thrash between builds?
- **Per-build cost, heap imported against heap mirrored:** model it, or measure it with the `--perdraw-bench` mode on `test/agc-image-mirror-epoch-compare` (ce6959aba, cloud-1's PM-020), if that's quick to reuse.
- **The PC experiment** the Bug Finder plans for later: one Village run with `APS5_HOST_IMPORT_MIB` raised by ~1 GiB, to see whether the heap gets imported and what the scene costs then. Say which log lines to read (`[gpu] host import budget`, `[buffers]`, `APS5_TRACE_HOST_IMPORT`), and whether anything else should be switched on.

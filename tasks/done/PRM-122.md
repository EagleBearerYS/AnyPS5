## What the module does (rooklz's measurements)

**`sceNetInetNtopWithScopeId`** (FUN_00006be0 → FUN_000065e0) and **`sceNetInetPtonWithScopeId`** (FUN_000072d0 → FUN_00006ee0):
1. The zone after `%` is an interface **name** from a fixed table (`lo0`, `eth0`, `eth1`, `dbg0`, `gbe0`, `bt0`, `wlan0`, `wlan1`, `phone0`, `pppoe0`), mapped to a slot (FUN_00005d40) and then to the kernel index (FUN_00005ea0). A decimal zone matches none, so `"fe80::1%2"` and `"ff02::1%4294967295"` return 0, not 1.
2. Ntop with a nonzero scope finds the interface whose index matches (FUN_00005f20), copies its 16-byte name and appends `%<name>`: it prints a name, never `%2`.
3. Ntop with a null address or null text sets errno `ENOSPC` (28) and returns null; a too-small buffer gives the same 28. A family other than 28 (the console's AF_INET6) sets `EAFNOSUPPORT` (0x2f) and returns null. None of these throw.
4. Pton's `%` branch is guarded by `scopeId != nullptr`: with a null `scopeId` a plain address still converts, and an address with `%` fails to parse (returns 0). A family other than 28 returns `0x8041012f` with errno 47; a null text returns `0x80410116` with errno 22. A null destination faults in the module; rooklz suggests returning `EINVAL` as the reasonable host behaviour (decide with the project's rules below and say what you chose and why).

**`sceNetConfigGetDefaultRoute`** (NID `lFJb+BlPK1c`, wrapper 0x153f0, not-initialized check in the shared route-table getter at 0xc70):
- Not initialized: returns `0x804101C8` with errno 200, before the getter. No throw.
- The wrapper calls the locked route-table getter `(AF_INET, record, 1, 1)`. A negative getter result passes through unchanged; a result other than 1 returns `0x8041130C` with the output untouched; 1 stores the kernel record's dword at offset 0x84 into the output and returns **1** (success is 1, not 0).
- The wrapper does not check for a null output pointer.

## Why

BF-321 (`perf/agc-index-skips-template-audit` 3b1178c9d5, on #12745 6a930fc672) skips #8047's time audit for templates the write index proved.

**In Resident Evil Village (PPSA01556), profiled, boot tree `diag/village-ceil3-index-skips-audit` c3a17826c8,** per 10 s:
- the audit's full walks fell from 1,873 to 97;
- `[rescache] revalidate` fell from 1,217 ms to 752 ms;
- it made ~7,000 calls, ~6,900 of them fast;
- the write index made ~7,000 proofs, ~6,900 accepted (~210 ms in all), with ~120 fallbacks.

So ~0.107 ms per call. Only ~0.030 ms of that is the index proof, and the ~100 audits left cost ~0.004 ms per call. **~0.07 ms per call is spent elsewhere in `ShaderResources::revalidateFull`,** and we don't know where.

On BF-321's Village harness, the same span is 37.9 µs per call at 0 % writes and 52.5 µs at 2 % (head, BF-321 §5). So the harness has the same pieces at a smaller scale, or lacks some of the game's.

**The bar for any lever after this** (the PM's): worth building only if the split names one piece costing about **0.3 s per 10 s or more in Village** (~0.043 ms per call at ~7,000 calls) that an exact change can remove. This task measures; it builds no lever.

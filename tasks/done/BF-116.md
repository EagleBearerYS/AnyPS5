## The fix (already written, on the fork)

- Fork branch `fix/agc-draw-aliases-by-key`, head **41196116ee**, one commit on upstream main cf2c667060.
- `Driver::drawAliases` used to hold `shared_ptr<DrawEntry>`. After the draw cache evicted or replaced that key, the alias kept the old entry and all its stage variants alive. Only `MaxAliases` (16,384) bounded it.
- Now an alias holds the draw key. `relocateDrawEntry` looks the key up in `drawCache`, and drops the alias when the key is gone.
- The files: `Execution/include/Driver/Driver.hpp`, `Execution/src/Driver/Draw/DrawRelocate.cpp`.

- **A new case, e.g. `EvictedEntriesServeNoRelocation(bool libraries)`,** run in its own process mode `--evicted`.
- **A new ctest `agc_driver_draw_cache_relocation_evicted`:**
  - command `agc_driver_draw_cache_relocation_tests --evicted`;
  - `ENVIRONMENT "ANYPS5_NO_SHADER_CACHE=1;APS5_DRAW_CACHE_ENTRIES=2"`, plus `SKIP_RETURN_CODE 77`;
  - the WIN32 `PATH` list, like the generated agc execution ctests. The generic loop near the `agc_driver_constant_store_tests` exclusions in `core/libs/prx/libSceAgcDriver/CMakeLists.txt` shows how.
  - The existing ctest keeps running the other cases with no arguments.
- **The flow I have in mind** (adjust it to how the cache really behaves; the existing `MovedDataHitsTheCache` is the model):
  1. Teach the alias exactly as `MovedDataHitsTheCache` does: VertexCode, data at moved addresses, 4 draws, so 2 inserts and 0 hits.
  2. One more moved draw must hit through relocation. That checks the setup.
  3. Evict the taught entries with draws of another identity (SecondVertexCode, a few distinct contents, each drawn twice so it's admitted) until `DrawCacheCounters().evictions` shows the taught keys left the 2-entry cache.
  4. One more moved draw (VertexCode, new address, same contents) must **not** hit. `hits` stays unchanged: an evicted entry serves no relocation.
- **Red:** with `DrawRelocate.cpp` and `Driver.hpp` from main (the fix reverted, the test kept), step 4 must fail. The alias still holds the evicted entry, so relocation finds a donor.
- **Green:** with the fix it passes, and the existing ctest still passes.

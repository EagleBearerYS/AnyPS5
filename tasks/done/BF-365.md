# BF-365: time `agc_driver_pipeline_journal`'s cold run on three upstream main commits, on one machine

## Why

`agc_driver_pipeline_journal` is near ctest's 120 s limit on GitHub's Linux runner in its first (cold) run.
- **The 1.41 GiB filler cost is understood.** Since #8365 (merge `15f719a5f9`, 11-01), `expandModule` zero-fills the size a module record claims before checking its zstd frame. The test's 0x5a filler records claim 1.41 GiB each. Open PR #15423 fixes it with a two-line change (below). On GitHub's runner its warm runs drop from ~50 s to ~8 s.
- **The cold run is the open question.** With #15423 (head e9ac2db947 on main d1ae628bc2, run 41752529697), the cold run was still 119.72 s. On 10-31, main `d30e04fb8a` (before #8365) took 67.8 s cold and 5.1 s warm (run 41175053022).
- **Those are single samples on different GitHub runners.** On one commit (main 086c0686c8), two runs gave 106.2 s and 135.91 s cold. So we don't know whether cold really grew ~50 s, or whether the runners differ.
- **This task:** one machine, a clean A/B/C pair, before anyone bisects 980 merges.

"Cold" here means Mesa's on-disk shader cache is empty, as on a fresh runner. The test already gives itself a fresh AnyPS5 cache and journal directory each run.

## Trees (all upstream main, fetch from `upstream`)

- **A:** `d30e04fb8a` (10-31, before #8365; `expandModule` does not exist yet). Build as is.
- **C:** `15f719a5f9` (#8365's merge, 11-01), with the patch below.
- **B:** `1c8c0efc8c` (main at 11-03 22:26Z), with the patch below.

The patch is #15423's one hunk in `core/libs/prx/libSceAgcDriver/Graphics/src/PipelineJournal.cpp`, in `expandModule`. Apply it by hand if the context differs; it removes the filler cost so the cold times compare like for like:

```diff
     std::uint32_t bytes = 0;
     std::memcpy(&bytes, payload.data() + 20, sizeof(bytes));
-    module.resize(bytes);
     const auto frame = payload.subspan(ModuleHeaderBytes);
+    if (ZSTD_getFrameContentSize(frame.data(), frame.size()) != bytes) return false;
+    module.resize(bytes);
     const auto expanded = ZSTD_decompress(module.data(), module.size(), frame.data(), frame.size());
```

Don't commit it anywhere; it's for this measurement only.

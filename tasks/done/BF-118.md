## Why

Resident Evil Village (PPSA01556)'s menu runs 32% faster with the draw cache off (env session arm C, 0.373 → 0.491 fps). bcortezf's #5404 bypasses the draw cache while its hit rate is under 5%. oneandonlydean reviewed it on 2026-10-17 and asked for four things: https://github.com/boykopovar/AnyPS5/pull/5404#issuecomment (the 23:57 UTC comment).
1. A rebase. The branch is ~2,600 commits behind main, and all four files conflict.
2. Don't hide working stage reuse. The bypass counts only whole-draw `drawHit`, but `useDrawEntries` also gates `stageEntries` (Draw.cpp, `const bool stageEntries = useDrawEntries && ...`). Either count whole-draw plus stage hits, or bypass only the whole-draw lookup and insert.
3. The window counters (`fetch_add`, then `exchange` and `store`) can race between queue workers. Use one CAS on a packed counter.
4. Measurements on the rebased head (the PC does those, not you).

We'll offer the result to bcortezf as commits to take as-is.

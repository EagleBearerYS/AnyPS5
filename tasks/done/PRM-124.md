## Goal

That case (`RunSplitRead(reader, SecondHalf::Mirrored, false)`, ~:655-694) returns early with "skipped, guest memory is not write-watched here" unless `AgcDriver::GuestMemory::WriteWatched()`. Find out whether it runs on Linux with lavapipe, and if it does, whether it ever fails under repeats. No fix is wanted yet.

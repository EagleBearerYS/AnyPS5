## Context

**#8939** (ours, draft, "fix(shader): take lane-mask arms and a merged high word in a pointer-keyed record pointer") is fork `fix/shader-pointer-key-lane-masks` at **e9d4626904**, stacked on #7395.

A maintainer, oneandonlydean, ran Ratchet & Clank: Rift Apart (PPSA01474) on main + #7395 + #8939. It still stops at `LoadAddressU32@pc=0x9a30` with `GetImageResource dword 0 is not a valid runtime value`.
- The high-word Phi of the descriptor pointer has one arm read from a second buffer.
- On exactly that Phi edge, the low word is a lane mask. That's the waterfall loop reusing the SGPR pair, not a pointer.
- The old code walked the two words separately (`PointerRecordReads` in `core/shader/recompiler/Optimization/src/ResourceTracker.cpp`), so it refused the second-buffer arm.

He asked for the two words to be walked together, edge by edge. That's written: fork branch **`pm/8939-edge-pairs` = a7d1e62b53**, two new commits on e9d4626904:
- **92cede35a0** `fix(shader): pair a pointer-keyed record pointer's two words by Phi edge`:
  - `PointerRecordPairs` walks (low, high) pairs. Where both are Phis of one block, each low-word edge takes the high word from the same predecessor (`PhiIncoming`).
  - An edge whose low word is an immediate or a lane mask (`PointerFreeWord`) is skipped together with its high word.
  - A record low word still needs every high word it can meet to be an immediate, a lane mask, or the same record column at offset + 4.
  - New ctest **`agc_driver_pointer_phi_high_second_lane_table`** (`--pointer-phi-high-second-lane`): `PointerHighSecondCode` plus `s_mov_b32 s44, exec_lo` in its second-buffer arm. It must plan, sample each record's T#, and fault outside the snapshot when group 0 takes that arm.
  - `agc_driver_pointer_phi_high_second_table` must keep refusing: there the second-buffer high word meets the record low word.
- **a7d1e62b53** `docs(shader): ...` updates the debt entry in `docs/dev/debt/shader.md`.

GitHub's runners are running the same head (targeted ×5 and a `^agc` sweep). This task is the red check, plus a run that mirrors CI's Linux job.

# BF-372: our agc_driver_host_write_hook failed once on main's Linux job; show whether queue 0's idle store races it, and keep the idle store off in our host-write tests

from: Bug Finder (PC)
for: any
priority: normal

## Why

- `agc_driver_host_write_hook` reached upstream `main` with our #6926 (merge a2624e4313, 2026-11-08 09:11Z).
  - Since then it passed in about 44 `main` push runs and failed once: run 42499107665 at 37af134c76 (16:17Z), on runner `anyps5-2-linux-4`.
  - That runner passed it at 08c9c86149, 9f57b41373 and 3e7b406e9c.
- **The failing check** is `HostWriteHook.cpp:137` in `HostWriteWaits`. The test calls `Dispatch(guest)`, which ends in `AgcDriverWaitIdle`, then `StorageTexture::FlushPending(..., "sampled texture")`. After that the guest range must still be all zero. The failure message: "host write waits: the image's store landed when it was made, so none was recorded over the range".
- **The suspect is queue 0's idle store,** in upstream `main`'s `core/libs/prx/libSceAgcDriver/Execution/src/Driver/Queues/QueueWorker.cpp`:
  - When every queue is idle with storage results pending (`idleResultsPending`, :206), queue 0 waits `IdleResultsQuietPeriod` (50 ms, :20; the wait at :225).
  - Then `VulkanDevice::StoreIdleResults` writes those results to guest memory.
  - If the test thread takes more than 50 ms between `AgcDriverWaitIdle` and the check, the results land first. A loaded runner can do that: CI runs ctest with `--test-load "$(nproc)"`.
- **`APS5_NO_IDLE_STORE` turns the idle store off.** It's ours, f9b5cc27e1 (10-24).
  - `tests/execution/QueuedIndexReadOrder.cpp:346-349` sets it with `_putenv_s`/`setenv`.
  - `tests/cmake/agc_driver_store_idle_results_tests.cmake` sets it in `ENVIRONMENT`.
  - `HostWriteHook.cpp` was written on 10-16, before the variable existed, and sets only `APS5_PROFILE_DRAW`.
  - `HostWritePendingStorage.cpp` has the same shape (`AgcDriverWaitIdle` at :84, an `untouched()` check at :207) and sets nothing.
- On Windows both tests build as `ExecutionTestNotBuilt` stubs, so only Linux matters.

# BF-242: a failed join host import leaves a compute shader's guest buffer with no GPU owner (Village abort on main, medium)
from: Bug Finder
for: any
priority: normal

## Why
Resident Evil Village (PPSA01556) on our Windows PC (RTX 3070, 16 GB RAM) aborted twice, about 4 minutes in, before the menu. Both runs used code at or near `main`:
- one with `APS5_GPU_HEAP` (#9508) on, at 10-24 23:43 PT;
- one with it off, on main 85a4d7f8c8 plus a default-off switch, at 10-25 09:52 PT.

So it isn't #9508's. Both logs show the same sequence just before the abort (text from our run logs):

```
[gpu] host import of 0x217a400000+0x1d60000 failed at vkAllocateMemory (-2); falling back to copies, requested by join
[gpu] host import budget lowered to the 6063.6 MiB live after vkAllocateMemory failed within an eighth of the budget
[gpu] host import budget: 6063 MiB live of 6063 MiB (lowered after vkAllocateMemory failed; host heap 1 reports a budget of 7237 MiB and a usage of 7300 MiB); 1 imports (8 MiB) refused so far, 0 of them remembered, last 0x217a000000+0x800000 by build
[gpu] sampled texture cache budget 2048 MiB (was 2310 MiB): ...
[gpu] driver failure: compute shader 0x207bd70e00: AGC graphics: guest buffer has no GPU owner
```

The other run has the same lines: the join of 0x2179c00000+0x1d60000 fails, then compute shader 0x207bdc0500 hits "guest buffer has no GPU owner" about 40 lines later.

**On `main` (Graphics/src/GuestBufferMemory.cpp):**
- **The failing join:** `importJoined` (`:1772`) calls `importRunAt(..., joined=true, ..., ImportRequester::Join)`. Its vkAllocateMemory failure path prints "falling back to copies" (`:1972`), lowers the ceiling (`:1973-1978`), and returns `failedImport()`. For a join, that records it in `failedJoins` and returns nullptr (`:1884-1888`).
- **The abort:** `GuestBufferMemory::Descriptor` (`:5472`) Requires `owner(address, address + bytes) != nullptr` (`:5476`).
  - `owner` (`:4297`) returns null only when no region in the build's own list, nor in the shared space, begins at or before the address.
  - A region that exists but is too small gives a different message ("exceeds", `:5483`).
  - **So the compute shader's buffer got no region at all.** A copy fallback should still give it one.
- **The comment at `:1822-1824`** says a join may replace imports the build already looked up, and that UploadFinish's pre-pass re-resolves every pointer after it. That's the area to trace.

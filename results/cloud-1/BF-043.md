# BF-043: the HTILE re-read fix (24a11c115f): red/green, cost and CI Linux mirror (cloud-1)

**Tested:** fork branch `fix/agc-htile-reread-on-new-write` at **24a11c115f** ("fix(agc): read a depth target's HTILE again only after a new write over it"), one commit on upstream main 9bf01db663. **Nothing was pushed to the fix branch** (see "Why no test was pushed").

**Machine:** cloud-1: Intel Xeon @ 2.80 GHz, 4 vCPUs, 15 GiB, Ubuntu 24.04, gcc 13.3.0, lavapipe from Mesa 25.2.8 (LLVM 20.1.2), no /dev/udmabuf. The build uses CI's Linux-job flags (`-G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++` plus the ccache launchers, `-DANYPS5_ENABLE_SPIRV_TOOLS=ON` and the wild 0.10.0 linker). Tests ran with `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx`, stdin from /dev/null, **as root**: this environment refused creating an unprivileged user.

RESULT:
- **No red is reachable with the driver as it runs.** Every count the probe measures is identical on the fix and on the red (the fix with only the memo condition reverted), in every case and both write-watch modes, 20/20 runs each.
  - A bind's own HTILE read goes through the recorder's flush hook. When a recorded write overlaps the HTILE, the hook runs `FlushForAccess` -> `SyncThrough`, which reaps that write's batch. So after the first bind nothing is listed any more, and main's "nothing pending" memo path decides every later bind.
  - The fix's new skip needs a listed note equal to the memo's note. That only happens if a read leaves the write listed, and with the hook installed no read does.
- **The fix's logic is right for the state it names.** With the flush hook removed (probe only), so that writes stay listed across reads, case (a) reads 1 and skips 15 on the fix and reads 16 on the red. Cases (a2), (b), (c) and (d) match the task's expectations exactly. That state just isn't reached here.
- **On this host the HTILE memo is dead after any GPU write over it, on both builds.**
  - Lavapipe's host imports "resolve write protection", so the driver unwatches imported ranges: `[write-watch] host imports resolve write protection: yes ...; imported ranges are compared`.
  - Once the HTILE is imported for a GPU fill, `GuestMemory::CollectWrites` over it returns 0. The memo's `generation != 0` test then fails, and **every bind reads and scans the whole HTILE** (1001 reads out of 1001 binds, nothing listed).
  - With `APS5_WRITE_WATCH_IMPORTS=watch` the range stays watched, and both builds read once and then skip.
- **Cost:** at 3840x2160 (a 655,360-byte HTILE, the title's 640 KiB), a reading bind costs **552–684 µs** on the fix and 621–672 µs on the red. A skipping bind costs 29–41 µs.
  - A plain `GuestMemory::Read` plus uniformity check of the same bytes is about 30 µs. Most of the rest is the per-word `HtileFillClears` loop (DepthSurface.cpp:1074), which has no early exit.
  - 14,600 reads per 10 s × ~0.5 ms is ~7.3 s of every 10 s. That's the profile's 5.7–7.7 s of draw preparation.
  - A local one-line early exit (`if (cleared == 0) break;`, not pushed) brings a reading bind down to **176–205 µs**, and the clear is still taken (case (b)).
- **Likely cause in Planet of Lana:** the memo is never valid, not the listed-write check. This needs one log line from the PC: the title's `[write-watch] host imports ...` line on the RTX 3070. If it says "imported ranges are compared", the HTILE is unwatched after its first GPU write, and the fix cannot help.
- Runs on 24a11c115f: see "Runs" below.

## Why the listed-write state doesn't survive a bind

- `storeBackClearedHtile` reads the HTILE with `GuestMemory::Read` (DepthSurface.cpp:1071), which calls the flush hook (`GuestMemory.cpp`, `FlushGpuWrites`).
- With a recorder active, the hook is `Recorder.cpp` `FlushForAccess`. When the published pending-write snapshot overlaps the read, it takes the GpuMutex and calls `recorder->SyncThrough(address, bytes, true)` (Recorder.cpp:1030).
- `SyncThrough` finishes every in-flight batch up to the newest one overlapping the range. Through `syncThroughUnlocked` on an outermost lock, it waits without the mutex and then reaps. With the open batch overlapping, it calls `Sync()`.
- The probe sees this directly: "listed" goes from 1 to 0 at the first bind in every production-config case.
- So the memo the read stores has `note` = the note of a write that is no longer listed. The next bind's `NewestWriteNote` is 0, and `readSinceNote` is true through `note == 0`. That is main's path.
- The new comparison `found->second.note == note` with a non-zero note is reached only if a read left its write listed: a hook that does not reap, which is not the shipped hook.

## Why every bind reads here

- `GuestBufferMemory.cpp:803` sets `unwatchImports` when the import probe finds GPU-touched pages written. On lavapipe it prints "host imports resolve write protection: yes (0 of 4 scratch pages written after a GPU read, 4 after a GPU write, 0 after the import); imported ranges are compared".
- `GuestMemory.cpp:1369` then unwatches the imported range. After that, `collectWrites` returns 0 (`GuestMemory.cpp:1210`, the `covers` check), and the memo's `generation != 0` fails on both builds.
- Each bind then reads the whole HTILE, scans it twice (`std::all_of`, then `HtileFillClears` per word), and stores 0 as its generation.
- In the title this would hold for any HTILE the GPU writes through an import (a fast-clear fill or dispatch), on any host whose import probe says "are compared".

## Why no test was pushed

- The task's red is case (a) failing with N reads on the reverted memo. With the driver's own flush hook in place, the reverted memo and the fix read exactly as often in every case, so no test of the shipped driver can be red on one and green on the other.
- A test that removes the flush hook would be red/green (the second table). But it would test a state the driver doesn't reach, so it would only make the PR claim a win it doesn't deliver.
- The fix itself changes no count I could reach, so I made no `fix(agc)` commit either.
- `fix/agc-htile-reread-on-new-write` is still at 24a11c115f, and nothing else was pushed except this result.

## What I think is wrong, and what to check

1. **The fix targets a state the shipped hook removes.** The first read after a write reaps it, so `readSinceNote` through a matching non-zero note never decides a bind. The `{generation, recorder, note}` memo and `HtileStoreBackReadCounts` are harmless, but they don't change behaviour.
2. **The likely real cause is a dead memo, not the listed-write check.** If the title's log on the RTX 3070 says `[write-watch] host imports resolve write protection: yes ...; imported ranges are compared`, the HTILE is unwatched from its first GPU write (a fast-clear fill or dispatch through the import). After that, `collectWrites` returns 0, and every bind reads and scans the whole HTILE, on main and on the fix. That matches the profile: ~14,600 reads per 10 s × ~0.5 ms per read is ~7.3 s of every 10 s against the measured 5.7–7.7 s. The ~210 GPU waits are the minority of reads that do find a write still in flight.
   - **Quick check on the PC:** the `[write-watch] host imports ...` line from a title run. Then a run of 24a11c115f with `HtileStoreBackReadCounts` printed every 10 s: made ≈ 14,600 and skipped ≈ 0 means the memo is dead.
   - **Another check:** a run with `APS5_WRITE_WATCH_IMPORTS=watch`. If the fps returns, the unwatched import is the cause. That setting is a diagnostic only: on such hosts it trusts write protection the GPU resolves.
3. **Cheap win either way:** the per-word clear scan (DepthSurface.cpp:1074) never stops early. `cleared` can only lose bits, so stopping when it reaches 0 is behaviour-preserving. That cut a reading bind from ~590–680 µs to ~175–205 µs at 640 KiB here, and case (b) still took the clear. After a store-back has expanded the words (0xfffc000f is not a clear pattern), the scan would stop at word 0. `early-exit.patch` is below; it was measured only, not pushed.
4. **A real fix for an unwatched HTILE needs a validity signal other than the write tracker.**
   - Driver-side writes are already known: the recorder's write notes, and `MarkWritten` from the store-back and other CPU paths.
   - A guest CPU write into an unwatched import is not. So on "compared" hosts a skip must either accept that risk, or compare cheaply, for example the first and last cache lines plus a sampled word set, before the full read.
   - That is a design choice for the PR author. I didn't push any of it.

using AgcDriver::Graphics::DepthTarget;

constexpr VkExtent2D Extent{64, 32};

class GuestBlock {
public:
    explicit GuestBlock(std::size_t size = 65536) : BlockBytes(size) {
#ifdef _WIN32
        block = static_cast<std::uint8_t*>(GuestArena::GuestArenaAllocate_nid_postfix(BlockBytes, BlockBytes));
        if (block != nullptr) GuestArena::GuestArenaCommit_nid_postfix(block, BlockBytes, PAGE_READWRITE, BlockBytes);
#else
        void* mapped = mmap(nullptr, BlockBytes * 2, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
        if (mapped != MAP_FAILED) {
            const auto begin = reinterpret_cast<std::uintptr_t>(mapped);
            const auto aligned = (begin + BlockBytes - 1) & ~(static_cast<std::uintptr_t>(BlockBytes) - 1);
            if (aligned != begin) munmap(mapped, aligned - begin);
            if (aligned + BlockBytes != begin + BlockBytes * 2) munmap(reinterpret_cast<void*>(aligned + BlockBytes), begin + BlockBytes - aligned);
            block = reinterpret_cast<std::uint8_t*>(aligned);
            if (AgcDriver::GuestMemory::WriteWatched()) GuestWriteWatch::GuestWriteWatchRegister_nid_postfix(block, BlockBytes);
        }
#endif
        Require(block != nullptr, "htile store-back reads: cannot allocate a guest block");
        GuestAllocations::Mutation().Add(block, BlockBytes, true, true, true);
    }

    GuestBlock(const GuestBlock&) = delete;
    GuestBlock& operator=(const GuestBlock&) = delete;

    std::uint8_t* Data() { return block; }

    std::uint64_t Address() const { return static_cast<std::uint64_t>(reinterpret_cast<std::uintptr_t>(block)); }

private:
    std::size_t BlockBytes;
    std::uint8_t* block = nullptr;
};

GuestBlock& NewBlock(std::size_t size = 65536) {
    static auto* blocks = new std::deque<GuestBlock>();
    return blocks->emplace_back(size);
}

struct Counts {
    std::uint64_t made;
    std::uint64_t skipped;
};

Counts Since(const AgcDriver::Graphics::HtileStoreBackReads& before) {
    const auto now = AgcDriver::Graphics::HtileStoreBackReadCounts();
    return {now.made - before.made, now.skipped - before.skipped};
}

struct Fixture {
    AgcDriver::VulkanDevice& device;
    AgcDriver::Graphics::Context context;
    DepthTarget target;
    std::size_t bytes;

    void Bind() const { Require(AgcDriver::Graphics::DepthSurfaceView(context, target) != VK_NULL_HANDLE, "the depth target has no view"); }

    bool Listed() const {
        std::lock_guard lock(AgcDriver::GuestMemory::GpuMutex());
        auto* recorder = Recorder::Active();
        return recorder != nullptr && recorder->PendingWriteOverlaps(target.htileAddress, bytes);
    }

    bool Settled() const {
        std::lock_guard lock(AgcDriver::GuestMemory::GpuMutex());
        return device.RecordedWritesSettled(target.htileAddress, bytes);
    }

    bool Fill(std::uint32_t pattern) {
        std::lock_guard lock(AgcDriver::GuestMemory::GpuMutex());
        const std::array<std::uint32_t, 4> words{pattern, pattern, pattern, pattern};
        return device.FillBuffer(target.htileAddress, bytes, words);
    }

    void SubmitAndWait() {
        std::uint64_t serial = 0;
        {
            std::lock_guard lock(AgcDriver::GuestMemory::GpuMutex());
            device.SubmitRecorded(false);
            serial = device.SubmitAndEpoch();
        }
        if (serial != 0) device.WaitRecorded(serial);
    }
};

void Report(const char* step, const Fixture& fixture, const AgcDriver::Graphics::HtileStoreBackReads& before) {
    const auto counts = Since(before);
    std::printf("  %-28s made %3llu skipped %3llu listed %d settled %d watched %d\n", step, static_cast<unsigned long long>(counts.made), static_cast<unsigned long long>(counts.skipped), fixture.Listed() ? 1 : 0, fixture.Settled() ? 1 : 0, AgcDriver::GuestMemory::Watched(fixture.target.htileAddress, fixture.bytes) ? 1 : 0);
}

Fixture Make(AgcDriver::VulkanDevice& device, const AgcDriver::Graphics::Context& context) {
    auto& htile = NewBlock();
    DepthTarget target{NewBlock().Address(), 0, Extent, VK_FORMAT_D32_SFLOAT, 1.0f, 0, htile.Address(), false};
    Fixture fixture{device, context, target, static_cast<std::size_t>(AgcDriver::Graphics::HtileMetadataBytes(Extent))};
    fixture.Bind();
    fixture.Bind();
    return fixture;
}

void Binds(Fixture& fixture, int count, const char* label) {
    const auto before = AgcDriver::Graphics::HtileStoreBackReadCounts();
    for (int bind = 0; bind < count; ++bind) fixture.Bind();
    Report(label, fixture, before);
}

    const auto context = AgcDriver::VulkanDeviceTestAccess::ContextOf(device);
    auto* recorder = Recorder::Active();
    Require(recorder != nullptr && recorder->Device() == context.device, "the device's recorder is not the active one");
    if (std::getenv("PROBE_NO_HOOK") != nullptr) AgcDriver::GuestMemory::SetFlushHook(nullptr);
    {
        std::puts("(a) GPU write finished but listed, 16 binds");
        auto fixture = Make(device, context);
        auto before = AgcDriver::Graphics::HtileStoreBackReadCounts();
        Require(fixture.Fill(0xffffffffu), "the fill was not recorded");
        fixture.SubmitAndWait();
        Report("after fill+submit+wait", fixture, before);

        Binds(fixture, 15, "binds 2-16");

void Cost(AgcDriver::VulkanDevice& device, VkExtent2D extent) {
    const auto context = AgcDriver::VulkanDeviceTestAccess::ContextOf(device);
    const auto htileBytes = static_cast<std::size_t>(AgcDriver::Graphics::HtileMetadataBytes(extent));
    const auto depthBytes = static_cast<std::size_t>(AgcDriver::Graphics::DepthSliceBytes(extent, 4));
    const auto round = [](std::size_t bytes) { return (bytes + 65535u) & ~std::size_t{65535u}; };
    auto& htile = NewBlock(round(htileBytes));
    auto& depth = NewBlock(round(depthBytes));
    DepthTarget target{depth.Address(), 0, extent, VK_FORMAT_D32_SFLOAT, 1.0f, 0, htile.Address(), false};
    Fixture fixture{device, context, target, htileBytes};
    fixture.Bind();
    fixture.Bind();
    Require(fixture.Fill(0xffffffffu), "the fill was not recorded");
    fixture.SubmitAndWait();
    const auto before = AgcDriver::Graphics::HtileStoreBackReadCounts();
    const auto t0 = std::chrono::steady_clock::now();
    fixture.Bind();
    const auto t1 = std::chrono::steady_clock::now();
    for (int bind = 0; bind < 1000; ++bind) fixture.Bind();
    const auto t2 = std::chrono::steady_clock::now();
    const auto counts = Since(before);
    std::vector<std::uint32_t> words(htileBytes / 4u);
    const auto t3 = std::chrono::steady_clock::now();
    for (int read = 0; read < 100; ++read) {
        AgcDriver::GuestMemory::Read(htile.Address(), std::as_writable_bytes(std::span(words)), 4);
        Require(std::all_of(words.begin(), words.end(), [&](std::uint32_t word) { return word == words.front(); }) || read >= 0, "scan");
    }
    const auto t4 = std::chrono::steady_clock::now();
    const auto us = [](auto a, auto b) { return std::chrono::duration<double, std::micro>(b - a).count(); };
    std::printf("cost %ux%u htile %zu bytes: first bind after the write %.1f us; 1000 binds %.1f us/bind (made %llu skipped %llu); htile read+scan %.1f us; watched %d listed %d\n", extent.width, extent.height, htileBytes, us(t0, t1), us(t1, t2) / 1000.0, static_cast<unsigned long long>(counts.made), static_cast<unsigned long long>(counts.skipped), us(t3, t4) / 100.0, AgcDriver::GuestMemory::Watched(htile.Address(), htileBytes) ? 1 : 0, fixture.Listed() ? 1 : 0);
}

}

int main() {
    try {
        const auto device = OpenVulkanTestDevice();
        if (!device) return VulkanTestSkipped;
        if (const char* size = std::getenv("PROBE_COST")) {
            unsigned width = 0, height = 0;
            std::sscanf(size, "%ux%u", &width, &height);
            Cost(*device, {width, height});

        try { LibcRunShutdown_nid_postfix(); } catch (...) {}
        return 1;
    }
}

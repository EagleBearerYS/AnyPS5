## 5. Boot switches
- **FSR:** `ANYPS5_UPSCALE=fsr`.
  - **Optional sharpness:** `ANYPS5_FSR_SHARPNESS` sets RCAS sharpness in stops, from 0.0 (sharpest) to 2.0, default 0.2.
  - **Where EASU runs:** only when the fitted image is larger than the display buffer on either axis, for example a 1920x1080 buffer in a 2560x1440 or 3840x2160 window. Otherwise only RCAS runs.
  - **Startup line:** `[present] ANYPS5_UPSCALE=fsr: FSR 1 EASU when the window is larger than the display buffer, RCAS sharpness 0.20`.
  - **Bad values:** the start fails on any other value of `ANYPS5_UPSCALE`.
- **Trace:** `APS5_TRACE_DISPLAY_QUERIES=1` prints `[display-query] …` lines on stderr, one per distinct call and answer.
- **Both together:** `ANYPS5_UPSCALE=fsr APS5_TRACE_DISPLAY_QUERIES=1`. On Windows cmd: `set ANYPS5_UPSCALE=fsr` and `set APS5_TRACE_DISPLAY_QUERIES=1` before the start.
- **Which titles show FSR:** per PM-029, those whose param.json `attribute3` has 0x4 (resolution detection). The trace's `param.json` line shows that bit for each boot.

## Per-source reds on a1345c6917

**Method:**
- `agc_driver_table_index_validation`'s cases run one at a time, as `runner`, with `APS5_TABLE_INDEX_BREAK=<source>` exported; that drops the source's bumps.
- Two modes per case:
  - **counter mode:** the case asserts its source's bump count;
  - **outcome mode:** the case asserts only what the draw sampled and which proof it took.
- The case names are the test's own.

| case | break | counter mode | outcome mode | message (counter mode, then outcome mode where it differs) |
|---|---|---|---|---|
| cpu | cpu | exit 1 | exit 1 | "cpu write: the draw after a CPU write to the sampled texture still sampled its old texels (brightest 255, accepted 1, …)" |
| table | cpu | exit 1 | exit 1 | "table word: a T# word change in the table did not invalidate the O(1) proof" |
| driver | driver | exit 1 | exit 1 | "driver store: a driver store over a texture did not bump its subscription"; "… took the O(1) proof or rebuilt the object" |
| pending | pending | exit 1 | exit 0 | "pending write: the recorded storage write did not bump the subscription over the texture" |
| unwatch | unwatch | exit 1 | exit 0 | "unwatch: leaving the write watch did not bump the texture's subscription" |
| remap | forget | exit 1 | exit 0 | "remap: the free and remap of the texture's range did not bump its subscription" |
| release | release | exit 1 | exit 1 | "release: dropping the sampled textures from the cache did not bump their subscription"; "… took the O(1) proof" |
| import | import | exit 1 | exit 1 | "import: an import over a texture did not bump its subscription"; "expected the imported element looked up again without a rebuild" |
| compared | compared | exit 1 | exit 1 | "compared: expected the unwatched element on its per-element proof inside the O(1) path"; "a CPU write to the compared texture was missed or rebuilt the object" |

- **Every source's case goes red in counter mode with its own source dropped.**
- **Outcome mode stays green for pending, unwatch and remap,** as BF-124 found on the original branch, for BF-124's reasons:
  - **`pending` and `unwatch`:** the sweep's collect over a range the write watch no longer covers fails, so the draw falls back on coverage. On this head both outcome cases stay green with every source dropped (`APS5_TABLE_INDEX_BREAK=cpu,driver,pending,unwatch,forget,release,import,compared`: exit 0 each), as BF-124 found.
  - **`remap`:** the re-registration is fresh, so the `cpu` source catches it too. With `APS5_TABLE_INDEX_BREAK=cpu,forget` the outcome case goes red (exit 1): "remap: the draw after a remap of the sampled texture took the O(1) proof or sampled the old mapping (brightest 255, accepted 1, …)".
  - So each of the three can only be red on its own bump, which counter mode checks.
- **Specificity:** each case passes with a different source dropped (exit 0): cpu with forget, table with pending, pending with cpu, remap with cpu, compared with cpu, driver with cpu, unwatch with cpu, release with import, import with release.
  - The exception is `array` with `cpu` dropped (exit 1, "array: a write to the base slice of a 2D array read as 2D was missed or rebuilt the object"), because `cpu` is that case's own source.
- **All cases with nothing dropped:** exit 0.

### What
A cached draw over an image table proves every sampled texture on every Revalidate: one write-watch collect, one depth-plane flush and one generation compare per element, so the proof grows with the table (main: 1,607 µs of lookup per draw at 4,096 entries in the Village harness, 1,288 µs of it in Revalidate).

With `APS5_TABLE_INDEX=1` the build subscribes its watched textures and watched T# table spans to a write index over 64 KiB blocks. Writers bump the subscriptions over the blocks they touch: tracker stamps (CPU and driver), recorded storage writes, unwatch, allocation changes, a texture leaving the cache and a host import over a texture's range. Revalidate sweeps the subscription's spans once and proves only the bumped elements, the depth, DCC and storage-backed elements and the elements outside the write watch; a bumped draw-build texture is looked up again (from the same first-layer words the build uses) and re-bound without a rebuild.

**The merged `[image-table] (10 s)` line under `APS5_PROFILE_DRAW=1`**
- **No test exercises it.** `reportTables()` prints only once 10 s have passed since its first call, and every test finishes sooner.
  - The only tests that set `APS5_PROFILE_DRAW=1` are the prepared-shader tests (`CMakeLists.txt:1809`).
- **Static check:** the format has 12 specifiers (`%llu` ×8, `%s` ×3, `%.1f`), followed by 12 arguments.
- **Compiler check:** this container's GCC checks printf formats by default; a scratch mismatch warns with `[-Wformat=]`. `ResourceMaterializer.cpp` recompiled in this build with no warning.
- **Runtime check:** I built a 10-line scratch `clock_gettime` shim that moves the monotonic clock 11 s forward on every read.
  - I loaded it with `LD_PRELOAD`, with `APS5_PROFILE_DRAW=1`, under `agc_shader_memory_tests --table-snapshot-reuse` and `--bindless`.
  - Both exit 0, and they print 37 and 54 report lines. Samples:

  ```text
  [image-table] (10 s): 1 snapshots, 1 tables, 1 keys, 1 selected records, structural poison: none, narrowing 0 applied / 0 skipped, reused 0 unwritten / 0 compared, 99000.0 ms
  [image-table] (10 s): 2 snapshots, 2 tables, 8192 keys, 0 selected records, structural poison: none, narrowing 0 applied / 0 skipped, reused 1 unwritten / 0 compared, 3608006.4 ms
  [image-table] (10 s): 1 snapshots, 1 tables, 3 keys, 0 selected records, structural poison: none, narrowing 0 applied / 0 skipped, reused 0 unwritten / 1 compared, 99000.0 ms
  [image-table] (10 s): 1 snapshots, 1 tables, 4 keys, 0 selected records, structural poison: unmapped=4, narrowing 0 applied / 0 skipped, reused 0 unwritten / 0 compared, 55000.1 ms
  ```

  - Every field prints in place with a value from both sides: PM-027's selected records, and PM-028's reused unwritten and reused compared, as well as poison.
  - The ms values are inflated only because of the shim.
  - The narrowing skip-reason suffix (`%s%s`) stays empty in these runs, because neither mode skips a narrowing. Its two arguments (`":"` or `""`, and `skips.c_str()`) are covered by the compiler check.
  - The shim is deleted, and the worktree is clean.

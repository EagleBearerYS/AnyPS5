**`audio_out_shutdown` is a timing check, not something #6683 changed:**
- The check is `RequireParked` in `core/libs/prx/libSceAudioOut/tests/AudioOutShutdown.cpp:47-53`. It samples an output counter, sleeps 100 ms, and fails if the counter moved.
- So a mixer step still in flight when four tests share the CPU can trip it.
- #6683 changes no file under audio (`git diff --name-only 5d9dcc42d2...3d2d8e5305 | grep -ic audio` = 0).
- No earlier result on `cloud-results` names this test. It is a new flake seen once here, worth adding to the baseline's watch list.

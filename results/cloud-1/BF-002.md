## Setup

- Machine: cloud-1 (Linux VM, 4 vCPU Xeon @ 2.80 GHz, 15.7 GiB RAM). Ubuntu 24.04, gcc 13.3.0, CMake 3.28.3, Ninja 1.11.1, ccache 4.9.1. lavapipe from Mesa 25.2.8 (LLVM 20.1.2).
- Each tree is a git worktree with its own build directory `build-<X>`. All three share one ccache. Builds and tests ran as an unprivileged user, as on the CI runners.
- Configure flags were CI's full Linux-job set: `-G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ -DCMAKE_C_COMPILER_LAUNCHER=ccache -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DANYPS5_ENABLE_SPIRV_TOOLS=ON`. These are the task's flags plus the compiler and ccache launcher flags. Then `cmake --build build-<X>` and `cmake --build build-<X> --target libs`.
- Tests ran from the tree root: `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx ANYPS5_NO_SHADER_CACHE=1 ctest --test-dir build-<X> -R '^agc' -j4 --output-on-failure`.
- I also set `MESA_SHADER_CACHE_DIR` to one lavapipe cache shared by all trees, as CI's job does, so run order did not give one tree a cold cache. The trees ran one at a time (B, C, D) with nothing else running.

## Flakiness and odd results

- No run of any test failed: 1521 tests in step 1, 60 runs in step 3, and 82 more runs in the checks below (22 of `agc_driver_address_draw_reuse`, 60 of its neighbours).
- `agc_driver_address_draw_reuse` took 21.7 s in C's step-1 run, against about 1 s in every later run. This is not a flake.
  - It was the first run of a new test, so lavapipe compiled its pipelines with nothing cached. With an empty `MESA_SHADER_CACHE_DIR` it takes 20.84 s on C, and 0.94 s on the next run.
  - On a CI runner with no shader cache, it would use about 2/3 of the 30 s per-test budget at this machine's speed.
  - Under contention (`-j4` with `agc_driver_graphics`, `agc_driver_buffer_format` and `agc_formatted_buffer_once`, 10 repeats each) it took 0.87–1.11 s on C and 0.85–1.29 s on D, all passing.
- `agc_driver_flat_store` (33.5–33.9 s) and `agc_driver_vcmp_f32_denormals` (28.4–32.8 s) are near or over 30 s on all three trees, B included. This is the baseline on this machine, not a change from the follow-up. The VM also has no `/dev/udmabuf`, so shared direct memory is copied instead of imported. All `^agc` tests still pass with that fallback.

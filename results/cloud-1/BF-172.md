# BF-172: make the driver-driven execution tests skip without a Vulkan device (cloud-1)

**Base:** upstream main **ef0d8ae3b5** ("Merge pull request #8739 …"), the newest at 07:10 UTC.

**Head:** fork branch `test/agc-execution-skip-without-device` = **49a892412**. It is one commit on ef0d8ae3b5: "test(agc): skip the pipelined metadata pass tests without a Vulkan device". Author and committer are Yunus Shaikh, unsigned, with no trailers.

**Machine:** cloud-1: Intel Xeon @ 2.10 GHz, 4 vCPUs, 15 GiB, Ubuntu 24.04, gcc 13.3.0, wild 0.10.0, lavapipe from Mesa 25.2.8, no IPv6.

RESULT:
- **Device-less on main:** of the ten sources' 22 ctest registrations, only two fail without a Vulkan device: **agc_driver_pipelined_metadata_pass** and **agc_driver_pipelined_metadata_pass_draw_pipeline**. Both stop at `[gpu] driver failure: vkCreateInstance: Vulkan result -9`, then `vkCreateInstance: Vulkan result -9`.
- **The other 20 pass in every case.** In no run, with or without lavapipe, do they construct a `VulkanDevice`. They are left alone (below).
- **The change**, in `tests/execution/PipelinedMetadataPass.cpp` only:
  - it adds `#include "VulkanTestDevice.hpp"`;
  - it adds `if (!OpenVulkanTestDevice()) return VulkanTestSkipped;` as the first statement of `main()`'s `try`. That is after the `APS5_*` switches are set, and before the test registers guest memory or submits. This is the same form GpuMapOnFiber, PreparationScopeSettle and PreparedShaders use.
  - The probe device is a temporary, released at the end of that statement, before the driver opens its own.
  - With `ANYPS5_REQUIRE_VULKAN` set, the helper rethrows. The test's `catch` prints the error and returns 1, so it still fails.
  - Both registrations already have `SKIP_RETURN_CODE 77`, from the execution-test loop and the `agcDrawPipelineTests` loop. CMake is unchanged, and so is all product code.
- **Checks:**
  - **Repeats:** the two changed tests, `--repeat until-fail:10` on lavapipe: 100% of 2 passed, 20 passed runs.
  - **CI's Linux mirror:** on the head, 1927 tests, 1837 passed, 86 skipped, 4 failed. That is identical to main's on the same machine. Only the IPv6 tests fail on both.
  - **`check_skips.py`:** the same single flag on both (`guest_sce_net`, no IPv6), so the change adds no skips under `ANYPS5_REQUIRE_VULKAN=1`.
  - **Conventions:** pass, with 0 added `//` lines.

## Tests left alone, and why

They pass with no ICD, with and without `ANYPS5_REQUIRE_VULKAN=1`, and on lavapipe, on main and on the change. Their output never shows a `VulkanDevice` being constructed, even when lavapipe is there. They drive the CPU side of the driver: queues, DMA, labels, registration, shutdown and caches.

A probe would only make them skip on device-less hosts and lose that coverage:
- PipelinedDma: agc_driver_pipelined_dma, _draw_pipeline;
- PipelinedPredicatedLabelOrder: agc_driver_pipelined_predicated_label_order, _draw_pipeline;
- PipelinedPrefetch: agc_driver_pipelined_prefetch;
- RegistrationPrepareShutdown: agc_driver_registration_prepare_shutdown;
- RegistrationPrepareStack: agc_driver_registration_prepare_stack;
- ShutdownThreads: agc_driver_shutdown_threads, plus the modes _joined, _queued_prebuilds, _compare_helpers, _draw_committer, _shader_cache_writer, _late_shader_cache, _async_log_held, _exit_after_start;
- DrawWriteRanges: agc_driver_draw_write_ranges, _draw_pipeline;
- ImageTableCache: agc_driver_image_table_cache;
- ProgramWritesMemory: agc_driver_program_writes_memory.

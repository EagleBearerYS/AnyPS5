## 2. `ShaderResources::Revalidate` (address path)

- **F1's `try { ... } catch (const std::exception&)` stays** around `ResumeSpace`, `proveBuild` and `SpaceImportsCurrent`.
- **Each step counts through PRM-014's `refuse(...)` inside the `try`:**
  - `ResumeSpace` → `Space`;
  - `proveBuild` → `Imports` or `Proof`, by the report's failure;
  - `SpaceImportsCurrent` → `Imports`, setting `ProofFailure::Imports`.
- **The `catch` sets `outcome.failure = ProofFailure::Other`** (`outcome` is `*report`, or a local when `report` is null) and returns `refuse(AddressReuse::Threw)`.
- **The reuse path runs after the `try`:** `suspend.armed = false; reuseProved = true; return true;`.
- **Why a new "threw" bucket rather than an existing one:**
  - The throw can come from any of the three steps, so no one bucket fits all throws.
  - "space" has its sub-reasons (state, replaced, …) counted inside `ResumeSpace`, and they sum to it. A throw from there would leave that sum short.
  - "images or buffers" counts proofs that failed. A throw is an error, which a tester should see apart from ordinary refusals.
- **On the line**, `threw N` sits between `imports` and `moved buffers`. The enum is `{ Reused, NotReusable, InUse, Snapshots, Space, Proof, Imports, Threw, Moved, Count }`.

## 3. `BeginUse` / `CompleteUse`

```cpp
struct Use {
    Use(shared_ptr<atomic<uint32_t>> counter, shared_ptr<const void> hold, bool reusedSpace) : uses(...), space(...), reused(reusedSpace) {
        uses->fetch_add(1, acq_rel);
        if (reused) HoldReusedSpace(true);
    }
    ~Use() {
        if (reused) HoldReusedSpace(false);
        uses->fetch_sub(1, acq_rel);
    }
    ...
};
return std::make_shared<const Use>(usesInFlight, guestMemory.SpaceHold(), std::exchange(reuseProved, false));
```

- **`CompleteUse` is F3's**, with no `Completed` guard and no second decrement.
- **A batch discarded without running its completions** destroys the token, which releases the use and the held-space count together.
- **Several uses of one build in flight** each carry their own flag.
- **`EndUse`** keeps PRM-014's `reuseProved = false`, so a proof whose draw is not used (moved buffers) is dropped.

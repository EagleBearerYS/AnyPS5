### 2.2 B: the fixes the default path needed

`SpaceReuseDisabled()` now reads `APS5_NO_ADDRESS_DRAW_REUSE`, which replaces the `APS5_GPU_HEAP` row in ENVIRONMENT.md. `NeverReusable` asks the store question only for a stage that binds the BDA table.

On by default, a hit that retook the space must give it back on every path; otherwise the cached build pins the space's allocations and a free waits `APS5_PIN_WAIT_MS`:
- `ReleaseSpace` with no space held returns nothing and keeps `releasedSpace`. A second call used to reset it, and the next `RetakeSpace` then failed.
- A hit that throws before it is served (`CheckBufferAliases`) releases the space, through a guard.
- `Draw()` releases a space still held when the draw ends without `keepRecordedDraw` (prepare returned false, or a throw), into the active recorder.
- The transition path (`!lean` with moved buffers builds afresh) releases the template's space first.
- No recipe is made from a space-reuse build. `DrawWithRecipe`'s proof (`ProveCurrent` = `Revalidate`) neither retakes the space nor checks snapshots. #9508's recipe condition at `src/Draw.cpp:3421` is the same.

### 2.3 C, D and E

- **C:** `BeginDrawUse` gives each use a fault record (#8971's a581de8679 mechanism, adapted to draws).
  - The first use in flight takes the build's own #8963 slot and sets.
  - A concurrent use takes a slot of its own (a table-less `BdaResources`) and sets from `AllocateRewritten` that repeat the build's writes with that slot.
  - The moved-buffer and snapshot sets go through the same writer (`writeDrawSets`).
  - Each completion runs `BdaResources::CheckUse`, which checks that record with the build's tables and clears it.
  - Storing BDA builds stay never reusable; D counts them as "not read-only".
- **D:** one outcome per address-based draw that could take part in the cache.
  - The outcomes: `reused, built; refused: not read-only, not space-only, snapshot outside the space (copied), partial overlap, snapshot changed, moved GuestBuffers element, patched data word, space or epoch change, in use, revalidation`.
  - `built`, `snapshot changed` and `revalidation` are added to the task's list, so that every draw counts exactly once.
  - "In use" now refuses a hit whose build still holds its space, without removing it from the cache; A shared it.
  - The line prints after `[rescache] draws`. An 11 s loop under `APS5_PROFILE_DRAW=1` (not committed) printed `[rescache] address-based draws (10 s): reused 12341, built 1; refused: not read-only 0, … revalidation 0`.
- **E:** the hit syncs the recorder through snapshot ranges with pending writes before `SnapshotsServedInPlace` (#6636's 6e5b5bdf4b). E also adds the debt entry in `docs/dev/debt/libSceAgcDriver.md`.

## 4. Deviations from the task

1. **"A moved read-only V# base" refuses.** It does not. A lifts `usesBda` in `MovedReadOnlyBuffers`, so a moved read-only buffer inside the space is rebound per draw and the draw is reused (counted "reused"). The refusing control under "moved GuestBuffers element" is a moved V# whose range a recorded fill overlaps. Refusing every moved V# would undo #9508's lift.
2. **"A changed data word under a misalignment patch".** No case reaches it.
   - The patch exists only when a misaligned buffer's adjustment byte lands in a shader-data allocation rather than a push constant.
   - This fixture's stages produce none.
   - D counts it (`MovedReadOnlyBuffers` reports the patched case), and the debt entry records it.
3. **The ring cases are not red on D.** The containment proof A brought already serves moved slots inside the space. The cases are red with the reuse off, as A ships, and on A itself only the first case was run.
4. **"In use" has no test either.** Draws are serialized under the GPU mutex, and B's guards release the space on every exit, so no draw finds another draw's space held.

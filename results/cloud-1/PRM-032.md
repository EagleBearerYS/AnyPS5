# PRM-032: CI Linux job for 8 of our PRs on main e1ac3300d3 (cloud-1)

**Machine:** cloud-1: Intel Xeon @ 2.80 GHz, 4 vCPUs, 15 GiB, Ubuntu 24.04, gcc 13.3.0, ccache 4.9.1, wild 0.10.0, lavapipe from Mesa 25.2.8 (LLVM 20.1.2). No IPv6, no /dev/udmabuf.

**Each PR:**
- In the tree /home/user/AnyPS5: `git fetch upstream pull/<n>/head`, `git checkout -f --detach e1ac3300d3`, `git merge --no-ff --no-edit` the head.
- An incremental build with CI's Linux-job configure (`-G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ -DCMAKE_C_COMPILER_LAUNCHER=ccache -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DANYPS5_ENABLE_SPIRV_TOOLS=ON` plus the wild linker flags), then `--target libs`.
- `tools/check_test_registration.py build`.
- `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx ctest --test-dir build --test-load 4 --output-on-failure --timeout 120 --output-junit ctest.xml` with CTEST_PARALLEL_LEVEL=4 and stdin from /dev/null, then `tools/check_skips.py build/ctest.xml`.

**Differences from the task:** tests run **as root**, because this environment refused creating a `runner` user. That adds two known root-only results: `guest_named_shm_concurrency` fails, and `savedata_memory_growth_read_failure` skips. Both exit 0 as `nobody`. Main's tree for step-6 reruns is built only if a failure outside the baseline appears.

# PRM-059: agc_driver_pipelined_fill_gpu_heap under load with #9697's test fix on both trees

worker: cloud-5

## Result

With #9697's test fix (9587c4467b) cherry-picked, **both trees passed 360 of 360** interleaved runs, 0 failures in every loop.

I also ran the same harness, on the same machine with the same loops, on the trees **without** the fix, as an extra control the task did not ask for. Both failed at the same rate: **base 9/360, head 10/360**. Every failure was `AGC graphics: a satisfied WAIT_REG_MEM skipped an overlapping queued write`.

So on this machine:
- the failure is #9508's test-side race, and the fix removes it on both trees;
- #7642's commits do not change its rate: 10 against 9 under identical interleaving.

Nothing was pushed; the two cherry-picks are local commits only.

`UI_set_result(ui, uis, result)` in detail:
- It clears `UI_FLAG_REDOABLE`, and returns -1 for a null `uis`.
- **Prompt or verify string:**
  - A result shorter than the minimum sets REDOABLE, queues `ERR_PACK(40, 0xfff, 101)` and returns -1. A result longer than the maximum does the same with reason 100.
  - Without a result buffer it queues reason 105 and returns -1, without setting REDOABLE.
  - Otherwise it copies the result with its NUL.
- **Boolean string:** it stores the first ok or cancel character the result contains, or `'\0'`. Without a buffer it queues reason 105.
- **Other types:** unchanged, return 0.
- **What is not modeled:** the `ERR_asprintf_error_data` text, because the queue keeps codes only and no export reads error data.
- **What throws:** a null `ui` or `result`, or null boolean characters when one must be compared.

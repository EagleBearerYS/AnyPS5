## Method

**Parser:** PM-089's method, unchanged.
- Main's `tools/progress.py` (38d463a6cf) supplies `code()`, `stub_calls()`, `DEFINITION`, `CALL`, `QUALIFIED` and `body_end`. They run over every `.cpp` of a library directory, skipping `tests/`, and the results are cached by blob.
- A name is done when any definition of it no longer reaches `NotImplemented_nid_no_patch`. Names ending `_nid_no_patch` are skipped.

**PRs:** each PR is measured as `merge-base(main, head)` → head.

**What counts as a claim** (PM-089's rules), for a name in the row's library or its `.native`/`-module` directory:
- **implements:** the body no longer throws.
- **changes:** the body changed but still throws.
- **moves to X:** the stub is deleted and the name is defined in library X in the same PR. The claim says whether it is implemented or still todo there.
- **removes:** the stub is deleted with no new definition.
- A name implemented only in an unrelated directory is not a claim. No unclaimed row has one.

**Status** of each row:
- **done on main:** the row's library, or the library it moved to on main, has a body that no longer throws. 12 libkernel_sys rows count here as done in libkernel.
- **claimed:** otherwise, at least one open PR claims it.
- **unclaimed:** neither. `ktimer_create` is still todo, now in libkernel (#9314 merged); it stays a libkernel_sys row.

**Authors** are the GitHub logins in the task's data block. PM-089 used commit author names (for example "Yossi Yadgar" is `YossiYad` here). **Titles** are each PR's first commit subject; this session has no GitHub API access to upstream.

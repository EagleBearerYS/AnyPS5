**Behaviour, as the sources say:**
- **Retains:** the count goes up by one. The result is 1 when the new count is above 1, as `CRYPTO_add(...) > 1` gives.
- **`SSL_get_client_random`:**
  - with a null output it returns 32 without reading the connection, so even a null `SSL` works;
  - otherwise it copies `min(32, max_out)` bytes and returns that count.
- **The version setters:**
  - 0 resets the bound to the method's and the protocol version to 0;
  - DTLS methods accept only DTLS 1.0 (`0xFEFF`) and 1.2 (`0xFEFD`);
  - an inverted range, a range outside the method's, or a clamped DTLS version with no DTLS name returns 0 and writes nothing;
  - otherwise the range is clamped to the method's.

**Recorded differences:** null objects (connection, state, context, method) throw, where LibreSSL dereferences them. This module creates none of these objects, so the tests build caller-owned ones. The debt entries record both.

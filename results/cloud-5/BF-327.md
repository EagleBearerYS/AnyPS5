## The test

**The scene:**
- a write-watched surface, host-imported, so the template's sampled binding is a view of its storage image;
- a warm-up proof;
- a second, smaller storage image (16×16) over the same base: the foreign image.
- **Each of 3 rounds:** that image is marked dirty, the template is proved, and each proof must count exactly **1 foreign and 1 T1-eligible pending fast-fail, and 0 snapshot**.

**Why the import keeps the write watch:**
- With the default probe, this VM's imports leave the watch. The template's fast proof then stops at a collect refusal (unwatched) and never reaches the pending check.
- So both tests run with `APS5_WRITE_WATCH_IMPORTS=watch`.
- The test skips (77) when host imports are unavailable, the import is refused, or the imported surface has left the write watch.

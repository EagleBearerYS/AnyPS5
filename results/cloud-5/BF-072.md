- **The new key:** `"top_phases_calls_per_s"`, an object printed right after `top_phases_ms_per_frame` in every summary line: windowed `APS5_TRACE_FRAMES`/`APS5_TRACE_SECONDS` and `APS5_TRACE_SUMMARY_EVERY` intervals.
  - **Its phases:** the same top phases, in the same order, under the same names (`Name(scope, stage)`).

  - **Each value:** the phase's calls ÷ the seconds between the line's first and last present, the same `span` that `worker_busy_pct` divides by. The format is `%.3f`, like the other numbers.
  - A line with fewer than two presents has no span and prints 0.000.
  - **Calls:** `TraceThread::account` already counts one call per `Add` in `entry.count`, and `Collect()` returns it in each `Total`.
    - `Summary` now adds `total.count` into a `calls` map beside `phases`, under the same names and with the same `Driver.WorkerWait` exclusion.
    - For `APS5_TRACE_SUMMARY_EVERY` the counts are the interval's own, because `TraceFormat::Since` already subtracts the previous interval's `count` along with its `length`.
  - **Existing keys:** every key and its format is unchanged. The only change is the new object inserted between `top_phases_ms_per_frame` and `trace_dropped`.

## 1. The change

`Execution/include/PerformanceTrace.hpp`, `TraceFormat::Summary`:
- **New constant** `RatedPhases{"Driver.Draw", "Driver.Packet"}` beside `TopPhases`.
  - These are the two `PerformanceTimer` scopes of the queue worker: `Draw.cpp` `PerformanceTimer timing("Driver.Draw")` and `PacketExecution.cpp` `PerformanceTimer timing("Driver.Packet")`.
  - With no stage, their names are those strings.
- **In the per-thread totals loop,** a `calls` map gets `total.count` beside `phases[...] += total.length`, under the same name, with `Driver.WorkerWait` still excluded.
- **After `top_phases_ms_per_frame`:**
  - the list is the first `TopPhases` names of the sorted `top`, then each `RatedPhases` name with a nonzero count that isn't already listed;
  - each is printed as `calls / seconds(span)`, or 0 when the span is 0.
- **Unchanged:** `TopPhases` (8), the sort, `top_phases_ms_per_frame` and every other key.

`docs/dev/BUILD.md`: the summary line's field list now has `top_phases_calls_per_s`, described as above.

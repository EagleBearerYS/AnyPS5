## The change

`Append` (`core/libs/prx/libSceAjm.native/src/Ajm.cpp`) lost its null-list `NotImplemented`. The new structure:
- **`JobRejected`** holds `Append`'s two invalid-parameter checks: a null batch, and counts above 255, an oversized parameter block or sideband. `Append` and `CheckedAppend` both call it first, so the order of results is unchanged.
- **`CheckedAppend`** keeps the null-list check, after those same checks, and is used by:
  - `sceAjmBatchJobRunSplit`, which passes the caller's lists;
  - `sceAjmBatchJobControl`, which passes its sideband input. It stays todo anyway through its own throws.
  - `sceAjmBatchJobGetStatistics`, which has no source (below). The check can't fire for it (no lists, zero counts), so its runtime behaviour is unchanged.
- **The six sourced builders** call `Append`. They pass null lists with zero counts, so the check could never fire for them.

**No job is built or run differently.**

## libSceNpUniversalDataSystem: Export.cpp is not built (fourth commit)

**It was an oversight:**
- **The commit:** e39d55fa24 (xdCloudy, 2026-10-21, "feat(prx): add missing libSceNpUniversalDataSystem exports") added `Export.cpp` with 11 `(void)` throwing Int exports.
- **The missing line:** the library's own `CMakeLists.txt` was never changed. The generic `Export.cpp` rule (`core/libs/CMakeLists.txt:159`) applies only to libraries without a CMakeLists of their own.
- **The effect:**
  - On main, the unpatched `.prx` exports the 32 `PendingExports.cpp` Int functions and none of the 11 (`nm -D --defined-only`).
  - The 11 are defined nowhere else in `core/`.
  - Their 32 siblings, from the same export inventory, are built, and their debt says they exist "solely to resolve known imports". The 11 were meant for the same.
- **Would a title import them?** No importer is recorded: BF-208 lists none, and I have no game data to check. A title that imports one now gets a resolved export that throws, which is the tree's rule for every todo row.
- **`progress.py`:**
  - It counts the 11 as todo today. It reads every non-test `.cpp` in the library directory and never consults the build, so it was counting functions that are not exported.
  - After the fix they are exported and still todo, so the count is right and nothing in `progress.py` needs to change.
  - The totals do not move: libSceNpUniversalDataSystem is 41/84 done on both main and the head.

**The fix:**
- `${CMAKE_CURRENT_SOURCE_DIR}/Export.cpp` is added to the library's `add_library` list.
- **Test:** `ResolveInternalExports()` in `guest_np_trophy_unlocks_tests` (`GuestNpTrophyUnlocks.cpp`) calls each of the 11 and requires the `"<name> not implemented"` runtime_error from its own body.
- **Debt:** two "Unknown function info" entries (732 and 667 characters) in the wording of the `PendingExports.cpp` ones.
- **Red/green:**
  - **Red:** without the CMake line the test does not link; Wild stops at "Undefined symbol sceNpUniversalDataSystemIntTerminate". On main, 0 of the 11 symbols are exported.

## 1. The test

**Where it lives.** `tests/Recorder.cpp`, beside main's `refreshProofTests`, `keyProofTests` and `pendingKeyStoreTests`.
- It is built from the same fixtures those use: `AllocateWatched`, a registered guest allocation with its host import, a `StorageTexture` made directly with `StorageTexture::Create`, and the recorder's open batch.
- It runs as `agc_driver_recorder_tests --pending-key-refresh-only`, registered as `agc_storage_pending_key_refresh` with `SKIP_RETURN_CODE 77 TIMEOUT 30`, like `agc_pending_key_stores`.

**Its construction:**
1. **The target:**
   - a 256x256 surface, format 56, `kR64KBX` tiling (as `refreshProofTests`), texels 0x55;
   - its 1,024 DCC keys right after it, all 0x00: a fast-cleared 0000 clear;
   - both in one watched block, registered and host-imported.
   - Host imports are forced watched for the test (`SetImportWatch(base, ImportWatch::Watch)`, restored on exit), as `agc_unchanged_cpu_stamps` does. Without that, a device that compares imports instead of watching them (this lavapipe VM: "host imports are compared") has no write collection over the import, and no refresh proof is ever taken.
2. **Settle:** two `Refresh()` calls upload the image. It must report `UploadedKeys() == Clear0000`.
3. **The first draw:**
   - a recorded `vkCmdClearColorImage` of the image (the "draw", as in `refreshProofTests`), then `MarkDirty()`;
   - `MarkDirty` on a target whose uploaded keys are a clear code is the path that stores the keys uncompressed. `MarkDccUncompressed(context, …)` records the 0xff fill into the keys' import, with its memo entry and write note;
   - it must leave `UploadedKeys() == Uncompressed`, `recorder.PendingWriteOverlaps(keys)`, and the key bytes still 0x00, so the store is recorded but not landed.
4. **16 more draws in the same batch:** each one `Refresh()`es the target and then draws into it again.
   - `StorageTexture::RefreshesProved()` is main's existing cumulative counter, the one `refreshProofTests` reads. It must rise by 15, so exactly 1 of the 16 refreshes ran the full storage refresh.
   - The store must still be pending afterwards.
   - No test-visible counter was added: this one already existed.
5. **A CPU write:** `texels[0] = 0x11`. The next `Refresh()` must not be proved.
6. **Retire:**
   - `recorder.Sync()`; the keys must now be 0xff;
   - the next `Refresh()` must not be proved (the pending proof ends with its batch);
   - the one after must be proved (the proof is taken again over the landed keys).

**Time:** 0.09 s for the test on this VM (0.08 s red).

## Step 1: main's proof checks against the index

These are main's checks in a cached object's `Revalidate`, in order.
- **Per element** means the index keeps main's check for those elements only. They go to `perElementTextures`, run through `fastRevalidate`'s new `only` argument.
- **Own event source** means a writer bumps the index instead.

| main's check | where | index |
|---|---|---|
| `CompletePendingCpuWrites` per direct region, described range and storage image | head | **Replaced** by one `AnyPendingCpuWriters` check: no copied writer, draw writer or completion label (the early-out each call makes, hoisted). With a writer, main's loop runs. |
| `FlushDepthPlanes` per direct region | head | kept |
| `RequireNoMultisampleColorTarget` per described range | head | kept (an atomic load when no guarded target exists) |
| record present (`NoRecord`) | per element | **stays per element** |
| depth surface (`DepthSurfaceHolds`) | per element | **stays per element** |
| `Released()` → `Replaced` (#8047, first case) | per element | **Own event source `release`.** The texture cache's erase and admit refusal bump the texture's blocks with a lookup bump; the element is looked up again. |
| `FlushDepthPlanes` per element | per element | **Replaced** by one call per subscription span. |
| `CollectWrites` per element (`Collect`) | per element | **Replaced** by `SweepSubscription`, one collect per coalesced span. A failed collect is a fallback. |
| DCC keys, `KeyFastPath`, cleared views (`Keys`, `ClearedView`) | per element | **stays per element** (DCC elements) |
| view of a storage image: `ProvedKeys`, `Cached` (`Evicted`) | per element | **stays per element** (elements with a source) |
| pending registry `ScanPending` and T1 `refreshOwnObjects` (`Pending`) | per element | **Own event source `pending`** (`markLayersPending` → `NoteGpuPending`), plus one span-level `ScanPending` when the pending serial moved. An overlap is a fallback, where main's T1 path runs. |
| `UnchangedSinceAll` over the records' generations (`Changed`) | per element | **Replaced** by the subscription's generation, moved by the `cpu`, `driver`, `forget` and `unwatch` sources. |
| storage images: keys, collect, `StorageImagesCached` | per image | **stays per image** (`withStorage`) |
| epoch gate (`pendingSerialSeen == serialBefore`) | per object | equivalent: the index keeps its own `subscribedPendingSerial` |
| a lookup answer that changes after a host import (#8047, second case) | full walk | **Own event source `import`.** `ImportWatched` bumps the imported range with a lookup bump; the element is looked up again. |
| periodic audit `TemplateAuditDue` (#8047, `APS5_TEMPLATE_AUDIT_MS`) | after the proof | **kept**: it forces the full walk after an index proof too |
| element outside the write watch | per element (its collect fails, so the full walk runs) | **per element, compared:** looked up again on every proof (`comparedTextures`; `cachedTexture` compares its bytes) |
| an image table's T# words | not checked (the content key misses on a change) | watched table spans subscribed (a bump is a fallback); unwatched spans copied and compared |
| imported-buffer part, staging copies | after the proof | unchanged |

## Step 2: the port

### Adaptations to main

- **Conflicts in `GuestMemory.cpp`:**
  - The `GuestAllocations` invalidator is registered when the index is on, as well as for main's arena or image cache.
  - `stamp()` keeps main's leaf/coarse code and bumps the index when a stamp is stored.
- **BF-041's `ExpProfile` is gone.** Its counters are one `[rescache] write index (10 s)` line under `APS5_PROFILE_DRAW`, plus `WriteIndexOutcomesCounted()` for the tests.
- **#8047's two cases became event sources,** `release` and `import`.
  - Theirs are lookup bumps: the element is looked up again, not just proved.
  - A bump record keeps its kind and coalesces only with a record of the same kind.
- **The index absorbs its own release bumps.** Looking an element up again releases the old texture, which bumps the same subscription. When every bump since the proof is a lookup bump over an element this proof just replaced, the proof moves past it. Without this, the draw after a re-resolve never settled.
- **Main memoizes collects per collect epoch,** and the driver bumps the epoch once per packet. The tests' direct `VulkanDevice::Draw` calls bump it before each draw.
- **Main narrows an image table to the records its evaluable keys select** (`ResourceMaterializer::Narrow`).
  - BF-041's test key (constants → keys buffer) planned a 1-entry table, so a write to another element touched nothing bound.
  - The key is now user data plus `v_cvt_u32_f32(position) >> 31`, which is zero at run time but unknown to the planner. The whole 8-entry table is bound.
  - The same applies to the harness (step 4).
- **Removed:** BF-041's `APS5_TABLE_INDEX_NO_PARTIAL` measurement knob, and a `depth` break hook no test used.
- **Port bug, fixed in `8151a19d21`:**
  - BF-041 looked an element up again from its raw T# words.
  - Main (`7ef917d474` and `a71ba9edb9`, 10-17/18) builds a 2D read of a 2D array from its base slice alone, and narrows the words in the full walk.
  - The index's lookup found the whole array instead and re-bound the element to it. From then on, a write to any other slice changed the element again.
  - The fix narrows with `firstLayerWords` and passes the multisample view type, as the build and the full walk do. The `array` case is red without it.
- **`ENVIRONMENT.md`:** rows for `APS5_TABLE_INDEX` and `APS5_TABLE_INDEX_BREAK`.
- **Off (the default),** the only added work is one relaxed load per stored tracker stamp.
- **No added comments** (0 added `//` lines). Conventions check: "All conventions checks passed" (base upstream main).

## Step 4: harness (Village)

### The table mode, made templatable (`943d45f44b`)

- **Main had no templates in this mode.** The T#s were loaded with `s_load_dwordx8 s[16:23], s[2:3], s36`, a register offset the SRT walker doesn't plan, so every draw was an address-based build (BF-117).
- **The T#s now come from `s_buffer_load_dwordx8`** through a T# table V# at a fixed SRT offset (root + 0x220).
- **The key** is still the object V#'s index, plus a word of frame data read with `buffer_load_dword` at run time (zero). The planner can't narrow the table to the records a known key selects, so every draw binds the whole table, as a bindless title does.
- **Result on main:** after warm-up, every draw is a template hit. Revalidate proves all N entries per call (`[image-table]` shows N keys per table).
- **`VILLAGE_WRITE_PERCENT`** rewrites that share of the table's textures with their own bytes before each frame. The proof sees the writes, and the sampled texels stay the same, so `Check` holds and P1 isn't credited with a rebuild main must do.
- **Writes per frame at 2%:** 20 textures at 1,024 entries, 81 at 4,096.

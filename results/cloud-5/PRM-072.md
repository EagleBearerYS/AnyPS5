## The new test

**`agc_driver_bda_store_heap_mirror_store_pages_default`** = `agc_driver_bda_store_heap_mirror_tests --store-pages-default`.
- **Its properties:** `SKIP_RETURN_CODE 77`, `TIMEOUT 60`, and the Windows `PATH` line as for `_store_pages`.
- **No `APS5_BDA_STORE_PAGES`,** so the pool is the default.
- **Precondition:** `BdaResources::StorePageSlots() == 1024`.

**The dispatch:** `PagesCode`, the 64/65 test's shader, compiled for a **1,024-thread** workgroup.
- **The helpers:** `Compile` and `Run` take an optional thread count, default `Threads` = 64, so every other case is unchanged.
- **The pages:** thread *t* stores at `s[0:1] + t * 4096` (pages 0-1023) and at `s[2:3] + t * 4`, all into one more page (1024). That's **1,025 distinct 4 KiB pages**.
- **The heap:** a fresh zero heap, sized only for those pages (64 KiB + 1,025 pages, rounded up to 64 KiB blocks: 4,224 KiB). So every page is in an unbound block of the resident mirror.
- **Both mirror kinds:** resident, then copy-backed (`AddressSpaceLimit(1)`), as `_store_pages` does.

**Asserts:**
- **The refusal:** the use is refused with `found none of the 1024 store pages free (APS5_BDA_STORE_PAGES)`.
- **No store landed:** none of the dispatch's 2,048 stores reached guest memory. Each of pages 0-1023 still reads 0 at offset 0, and dwords 0-1023 of page 1024 read 0.

**Not asserted:** that exactly 1,024 pages fit. With 16 linear probes the table can refuse earlier.

**Why not a 16-store unrolled shader:** a first version ran 64 threads each storing into 16 pages. Its many inlined store-page lookups took about 30 s to compile cold on llvmpipe (32 s under ctest, about 3 s with a warm Mesa cache). The 1,024-thread `PagesCode` version takes **1.76 s cold** (`MESA_SHADER_CACHE_DISABLE=true`) and **0.21-0.26 s** warm.

**The refusal line it got,** the same on both mirror kinds, both on `822a2b879e` and on `425cd9d8b0`'s code:

```
[gpu] deferred write-back failed: BDA store at 0x7f25d25bd000 (4 bytes, instruction 0xc) into a heap mirror found none of the 1024 store pages free (APS5_BDA_STORE_PAGES)
```

`instruction 0xc` is the first store, into the threads' own pages. So the table refused before all 1,024 own pages were placed, as the probe limit predicts.

**MBUS-1, libSceMbus (1): `sceMbusEventCallbackFuncsInit_`. Can be implemented.**
- **Source:** the library's own debt entry, "sceMbus event subscriptions" in `docs/dev/debt/libSceMbus.md`, recorded from disassembly. It says "EventCallbackFuncsInit only clears memory and has no defined return value; its protected stub retains the existing integer return".
- **The callback table:** `MbusEventCallbacks` is `{ onOverflow, onEvent }`, 16 bytes (`include/Api.hpp`). `EventCreate` copies that "16-byte callback table".
- **The implementation:** clear `size` bytes at `callbacks`, and keep the `int` return as 0.

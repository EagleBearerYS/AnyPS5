## 2. What the code says (not confirmed by a run)

**The case,** `BdaResources.cpp:2896-2917`:
1. A leased build with `AllowAddressStores()` (:2900), `AddWritable(address + 16, 32)` (:2901) and `Upload(true)`.
2. It requires every BDA part over the 128 KiB range to be exactly `Read|Write`, at `device + offset` (:2906).
3. It then writes straight into the mirror through `access.addressBytes(device)` (:2910), at bytes 16, 1000 and 65536+2000.
4. It requires all three in guest memory after `WriteBack()` (:2917).

The case came in with 781dc4525b, and #12840 hasn't touched it since.

**What production does now,** at `Graphics/src/GuestBufferMemory.cpp`, 6bec085232:
- `addAddressStoreSpans` (:6420-6437) adds the whole served span of a writable heap mirror to `writes`, after the declared writes (`declaredWrites` = 1 here: the `AddWritable` range).
- **`AddressRanges` (:6177-6212) gives the written parts `Write` (:6192), plus a flag that depends on the mirror:**
  - `Masked` when the mirror is **copy-backed** (`mirror->resident == nullptr`, :6193);
  - per 64 KiB block when it is **resident**: a bound block gets plain `Read|Write`, an unbound one `Read|Write|Spill|Masked` (:6194-6210, the flag at :6205).

  So only a resident mirror whose two blocks are both bound meets the case's exact `Read|Write`. **A copy-backed mirror gives `Read|Write|Masked`, and the check at :2906 fails with exactly the runner's message.**
- **A mirror is copy-backed when `ResidentBuffer::Create` returns null** (`ResidentMirror.cpp:348-360`): no `sparseBinding`, `sparseResidencyBuffer` or `sparseResidencyAliased`, or the resident address-space limit is reached.
  - The heap mirror then gets a plain `Buffer`: `ResidentBuffer::Create` is at `GuestBufferMemory.cpp:3200`, the `Buffer` at :3243.
  - This doesn't depend on host imports: the runner's `host import ... falling back to copies` lines come from the host-import path (:2202), which serves other ranges.
  - Whether the runner's device has sparse residency I couldn't read: its job log tail holds only cleanup, and the artifact host is blocked from this VM.
- **`WriteBack` writes back less than the case expects.** With address stores, it writes back only:
  - the declared ranges (`declared`, :6508);
  - the pages the GPU reported through `NoteAddressStores` and `NoteStorePages`. Only `ShaderResources.cpp:6005-6006` calls them.

  This holds for a resident mirror (:6554-6597) and for a copy-backed one (:6598-6620, which needs a store mask per page, :6612). The case writes bytes 1000 and 65536+2000 directly and reports no pages, so **at the head they are not written back on either kind of mirror.** The check at :2917 ("an address store into a writable heap mirror did not reach guest memory") would fail even where :2906 passed.
  - That rule came with #12840's own later commits: bf54c5e942 (note only the stored runs), 99f1f37aed (compare only the pages BDA stores hit), bbeb08e9f6 (resident stores without reading back the span) and 7e7c81a2aa (copy-backed write-back by per-byte store masks). At 781dc4525b, `WriteBack` still compared the whole span.

**Why I read it as (T) and not (P):**
- On a copy-backed mirror, production does make the range writable (`Write`, plus `Masked` so the shader records which bytes it stored).
- 7e7c81a2aa writes the masked bytes back.
- `agc_driver_bda_store_heap_mirror` covers that path with real shader stores. It forces the copy-backed path with `SetResidentAddressSpaceLimit(1)` (`tests/execution/BdaStoreHeapMirror.cpp:152-156`, :676-703, :743-759), and that test runs on Linux.
- The unit case models a "store" as a direct write with no reported pages, and expects exact `Read|Write`. Neither has been true since #12840's later commits.

**Main's side:**
- Main has resident and copy-backed heap mirrors: `ResidentBuffer::Create` and the plain-`Buffer` fallback are both there.
- Main has no `addAddressStoreSpans` and no `Masked` bit. Per 781dc4525b's message, main refuses a store through an address into a heap mirror as read-only.
- **#12840 adds the address-store path,** including its copy-backed form.

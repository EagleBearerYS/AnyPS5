## The cause

Confirmed by reading the code at f3eb5557e:

- Head's `rewatchSettledImports` passes `Rewatch` the span [base & ~0xffff, (base+bytes+0xffff) & ~0xffff). For a 0xc4000-byte import at a 64 KiB base, that span ends 0xc000 past the import.
- `Rewatch` walks the whole span: `walkWrites` → `collectWindowsWrites` → `GuestArenaCollectWrites` → `WindowsMappings::Collect`.
- With `clear` set, `Collect` first requires `collectable(address, end)` (WindowsMappings.hpp:358, :492-508). That function returns false for any non-view page that isn't MEM_COMMIT/MEM_PRIVATE.
- `GuestArenaCommit` of 0xc4000 bytes replaces exactly those pages of the placeholder (WindowsMappings.hpp:43-57). The rest of the block stays a reserved placeholder, so the walk fails, `Rewatch` skips the range, and the import stays unwatched.
- Head's `Rewatch` also refused anything that wasn't 64 KiB-aligned (GuestMemory.cpp:1553), so a caller had no correct span to pass.
- The test prints `VirtualQuery` for the page past the import, so the Windows run shows the state of that page (see Tests).

## Changes

1. **`Rewatch` takes 4 KiB-page-aligned ranges** instead of 64 KiB blocks.
   - Where: `core/libs/prx/libSceAgcDriver/Execution/src/GuestMemory.cpp:1553`, where `% WriteBlockBytes` became `% WritePageBytes` for both ends.
   - The rest of `Rewatch` was already page-granular, so it is unchanged:
     - `coverage.Covers` and `coverage.Restore` (WriteWatchCoverage.hpp);
     - the write walk;
     - `noteCpuStore` (per-page CPU stamps).
   - Every block a range touches still gets its `driverPieces` erased and is stamped whole as a CPU store (GuestMemory.cpp:1558-1561). That is the conservative stamp the task asked to keep.
   - A range that isn't whole pages is still skipped.
2. **`rewatchSettledImports` passes the import's own pages:**
   - `core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp:863` adds the constant `settlePageBytes = 0x1000`.
   - `:1122` pushes [base & ~0xfff, (base+bytes+0xfff) & ~0xfff) into `ranges`.
   - `comparedImportShares(state, base, first, stop)` (:1115) and `StorageTexture::AnyLiveOverlaps(span)` (:1117) still use the 64 KiB `first`/`stop` span, unchanged.
3. **Docs:**
   - `docs/dev/ARCHITECTURE.md:147`: the deferred-settle sentence now says the lookup returns the import's pages, with whole-block CPU stamps, and that the rest of a partly covered block stays unwatched.

## Tests

All new write-watch cases are Windows-only. They sit inside WriteTracking.cpp's `#ifdef _WIN32` block (605-1125) and run as a Windows-only ctest mode:

- `CMakeLists.txt:714-716`: `agc_write_tracking_rewatch_import_pages` runs `agc_write_tracking_tests --rewatch-import-pages`, with SKIP_RETURN_CODE 77 and TIMEOUT 20, and has the libc PATH added like the other Windows modes.
- `WriteTracking.cpp:1660` dispatches the mode.

None of them needs a Vulkan device. They use guest arena reserve and commit, `ImportWatched(..., staysWatched=false)`, `Rewatch`, `Watched`, `CollectWrites` and `UntrackedHint`.

The helpers are at `WriteTracking.cpp:745-793`:

- `BlockSpan` / `PageSpan`;
- `PrintPageState` (prints `VirtualQuery` State/Type/Protect);
- `ImportFixture`: reserves N 64 KiB blocks at a 64 KiB base, commits a prefix, fills it, collects, and on destruction resets and releases;
- `UnwatchImport`;
- `RequireRewatchedStores`: a rewatched import is collected, and a CPU store into its last page is seen afterwards.

The mode runs these cases in order:

1. **`CheckRewatchWholeBlockImport` (:795), the existing 64 KiB-multiple case.**
   - Setup: a 4-block import at a block base, 1 block in.
   - Asserts that `PageSpan == BlockSpan`, that `Rewatch` returns it, that only its blocks are stamped, and that stores are seen.
   - Green on head and on the fix (control).
2. **`CheckRewatchImportTail` (:808), the 0xc4000 case from step (1).**
   - Setup: 13 blocks reserved, 0xc4000 bytes committed, unwatched as an import.
   - Prints `page past a 0xc4000-byte import: State 0x… Type 0x… Protect 0x…`. On Windows I expect State 0x2000 (MEM_RESERVE, the placeholder).
   - `Rewatch(BlockSpan)`, which is head's `rewatchSettledImports` span: asserts that it **does not** return the import and that the unwatch serial is unchanged. This confirms the cause. If the tail were committed, this step would fail with "the 64 KiB span past the import's committed pages returned to the write watch".
   - `Rewatch(PageSpan)`: asserts `Watched(base, 0xc4000)`, and checks `Covers`/`Watched` at the edges of a range ending inside a block:
     - `Watched(base+12 blocks, 0x4000)` is true;
     - `Watched(base, bytes+1)`, `Watched(base+bytes-1, 2)` and `Watched(base+bytes, 4 KiB)` are all false;
     - `UntrackedHint` is 0 and the serial has changed;
     - stores are seen.
3. **`CheckRewatchUnalignedImport` (:824), the 0x…1000 base.**
   - Setup: the import is base+0x1000 with 0xc4000 bytes; 0xc8000 bytes are committed and the rest of 13 blocks is reserved.
   - Prints the state of the page past the commit.
   - The block span must not return the import; the page span must.
   - Page 0 of block 0 and the page after the import stay unwatched.
   - Stores are seen.
4. **`CheckRewatchImportBesideUnwatchedImport` (:840).**
   - Setup: 14 blocks committed. Import A is 0xc4000 bytes; import B (0x1c000 bytes) starts at A's end and shares A's last block. Both are unwatched.
   - Rewatching A's pages returns A.
   - B's first page, B's last page in A's tail block, and B's last page all stay unwatched, and B still reads as untracked (`UntrackedHint != 0`).
   - Rewatching B then returns both.

Changed in `CheckRewatch` (WriteTracking.cpp:712-723, Windows, ctest `agc_write_tracking`):

- A range that isn't whole pages ([block+1, block end)) does not return anything, and the serial is unchanged.
- The old assertion "part of a block returned to the write watch" became the page contract: [block+4 KiB, block end) returns exactly those pages. Page 0 and the whole block stay unwatched, and the serial changes.
- The later serial check compares against the serial after that partial rewatch.

Cross-platform edge case:

- `tests/WriteWatchCoverage.cpp:102-112` (ctest `agc_write_watch_coverage`) covers `Covers` after a page-granular restore that ends inside a block (0xc4000), and one that starts and ends inside blocks (+0x1000).
- It passes on this machine against the unchanged header, and on head (WriteWatchCoverage.hpp is not modified).

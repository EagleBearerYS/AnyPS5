## The line

The new section goes in the existing `[guestmem]` line (one per 10 s, under `MemoryProfiled()` = `APS5_PROFILE_DRAW`). It follows the v3 `| collect failures (10 s): … ranges: …` part, before `| arena …`:

```
| outside (10 s): store-unwatched N, import-unwatched N, unwatched N, excluded-untagged N, host-region N, never-watched N, other N; ranges: <cause> 0x<address>+0x<bytes> x<count> (by <site> at commit gen G, tracker gen T, packet 0x<opcode> queue Q, from +0x<offset>) ...
```

- **Counts:** they add up to v3's `outside` count, since both are counted in the same call.
- **Ranges:**
  - up to 8 (cause, address, bytes) entries, each with its count;
  - the `(by …)` part appears only when the range was excluded by an unwatch that left a tag;
  - it reads `no packet` when the unwatching thread runs no PM4 packet;
  - `from +0x…` is the module offset of the caller of `MarkWritten`, `MarkPossiblyWritten` or `Unwatch` (0 for imports), for `nm` or a map file.
- **Expected on the PC, if O2 holds:**

## How each sub-reason is decided (`GuestMemory.cpp` at 34ca984534)

**Tagging, at the unwatch**
- **Tag (`tagUnwatched`, L1941):** `unwatchLocked` (L1955) does what it did before, then, under `MemoryProfiled()` only, tags every 64 KiB block of the span in `WriteTracker::unwatchTags`, clamped to the arena on Windows. A tag holds:
  - the site;
  - the arena commit generation passed to `coverage.Exclude`;
  - `tracker.generation`;
  - the caller's return address;
  - `CurrentPacket()` (opcode, queue).

  A block keeps its first tag until it is restored (`try_emplace`).
- **Sites:**

  | Site | Where | Line |
  |---|---|---|
  | `store` | `markWritten`, when the store's fresh collect fails | L2244 |
  | `import` | `ImportWatched` without stays-watched | L2048–2049 |
  | `import-kept` | `ImportWatched` with stays-watched | L2090, L2093 |
  | `unwatch` | `Unwatch()` | L1986 |

  For `store`, the caller is the return address of `MarkWritten` / `MarkPossiblyWritten` (L2260, L2264).
- **Restore clears the tag (`forgetRestoredTags`, L1442, Windows):** after `coverage.Restore`, in `watchPrivateMapping` (L1459, the commit-generation restore) and in `Rewatch` (L2002), every block that is fully covered again loses its tag.

**Classifying, at the failed collect**
- **Entry point:** `collectWrites`'s outside return (L1752) passes the tracker, under the tracker lock, to `collectFailed` → `countOutside` → `classifyOutside` (L1657).
- **Windows rules, in order:**
  1. **other:** no tracker, empty or overflowing range (L1658). This is the early return at L1717, before the tracker lock.
  2. **never-watched:** the range is not inside the write-watched arena `[base, base+size)` (L1661).
  3. **excluded:** the first 64 KiB block whose part of the range `coverage.Covers` rejects (L1665) is looked up in `taggedCause` (L1643):
     - a `store` tag → **store-unwatched** (O2);
     - an `import` or `import-kept` tag → **import-unwatched**;
     - an `unwatch` tag → **unwatched**;
     - no tag → **excluded-untagged**.
  4. **host-region:** coverage holds but `GuestArenaHostRegionOverlaps` is true (L1667), O3.
  5. **other:** anything else (L1668).
- **Linux rules (not the PC's path, kept sensible):**
  - beyond the tracker's span → never-watched (L1670);
  - a block not covered by `GuestWriteWatchCovers` that has a tag → its tag's cause (L1675);
  - no part registered with the watch → never-watched (L1677);
  - otherwise → other (L1678).

**Printing**
- **Report (L388):** the samples are copied and reset under `collectFailureMutex`, then printed outside it.
- **Caller offset:** `ModuleOffset`, which calls `GetModuleHandleExA` and takes the loader lock, runs only there, never under the tracker lock.

**Switch off**
- `unwatchLocked` and `forgetRestoredTags` add one `MemoryProfiled()` static-bool check each.
- `markWritten` takes one more pointer argument.
- `collectFailed` already returns at once.
- No map is touched and behaviour is unchanged.

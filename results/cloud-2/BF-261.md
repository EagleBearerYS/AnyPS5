## The conflict and its resolution

There was one conflict, in `Graphics/src/Resources.cpp`, `CommandBatch::Submit()`.

- **What main changed:** main's 4bee82086f (`fix(agc): destroy buffers and memory on MoltenVK only while the graphics queue is idle`, via #8888) put `DestroyDeferredAtIdle(context);` right before the `vkQueueSubmit` call.
- **What the commit changed:** bf2cf51b91 wrapped that same `vkQueueSubmit` line in a `CommitterTimed(CommitterPart::Submit)` scope.
- **Resolution:** main's line stays where it is, and the timed scope follows it:
  1. `DestroyDeferredAtIdle(context);`
  2. `{ CommitterTimed Submit; vkQueueSubmit }`
  3. `Check(submitResult, ...)`

  So the "submit" part still times `vkQueueSubmit` only.
- **Not timed:** `DestroyDeferredAtIdle` can itself call `vkQueueWaitIdle`, but only when `deferDestruction` is on. That is `VK_DRIVER_ID_MOLTENVK` and no `APS5_NO_DEFERRED_DESTRUCTION` (`VulkanDevice.cpp:1304`), so on the PC it returns at once. I did not add a GpuWait timer around it, since that would add a timer the old commit never had. `Recorder::Submit` calls it in the same place, also untimed.

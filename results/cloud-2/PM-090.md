## Rules applied

- **Code moves:** each function moves from `PendingExports.cpp` to `Export.cpp`, as #9089 and #8354 do. The block goes after `sceSystemServiceGetStatus`, away from where those two add theirs.
- **Twins share one implementation:** each public `sceSystemService*` twin forwards to its `sceShellCoreUtil*`/`sceLncUtil*` target, which is the direction of the direct aliases the library's debt file records. The twins are:
  - RemotePlay status, live-streaming OnAir, ScreenSaver, ShellUiFg, EyeToEye and the two suspend notifications.
  - The test checks each twin returns the same answer as its target.
- **Null outputs:** a null output pointer returns `SYSTEM_SERVICE_ERROR_PARAMETER`, as the library's implemented neighbours do (`sceSystemServiceGetNoticeScreenSkipFlag(bool*)`, `GetStatus`, `GetDisplaySafeAreaInfo`).
- **Outputs are only `bool*` and `uint8_t*`.** No status struct is filled, and every signature is already in the tree. The debt file confirms the boolean outputs, the remote-play and UI status aliases, the disc and shell-shutdown booleans, and that "eye-distance adjustment writes one byte".
- **Cases whose console answer is unknown throw** instead of guessing:
  - a null `reason` to Block/Unblock;
  - an Unblock with no block left;
  - an eye-to-eye query for a user other than the one logged-in user (`USER_SERVICE_INITIAL_USER_ID`, the only ID in libSceUserService's login list).

  These are listed under Unknown function info in `docs/dev/debt/libSceSystemService.md`.

Answers 25 libSceSystemService queries about features AnyPS5 does not have, from what the tree already reports, instead of throwing:
- suspend: sceLncUtilBlockAppSuspend/UnblockAppSuspend, sceLncUtil/sceSystemService Enable/DisableSuspendNotification.

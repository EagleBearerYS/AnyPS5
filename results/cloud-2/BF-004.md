**`guest_user_service`, rerun alone:**
- **On M (f09505f24d):** 3 of 3 runs `Subprocess aborted`.
- **On upstream main f785b88a62:** I checked main out in the same tree and ran `cmake --build build --target guest_user_service_tests`. Ninja reported "no work to do", because the test and every library it links are the same on M and main. 3 of 3 runs `Subprocess aborted`. **It fails on main too.**
- **Why it aborts.** Under gdb, its first check `sceUserServiceGetEvent(nullptr)` returns `-2137653246` (`USER_SERVICE_ERROR_NOT_INITIALIZED`, 0x80960002), but the test expects `USER_SERVICE_ERROR_INVALID_ARGUMENT` (-2137653243). The result is the same on M and on main.
  - Upstream PR #5233 (merged 19:07 UTC today) made `GetEvent` return NOT_INITIALIZED before `sceUserServiceInitialize`.
  - PR #3507 (merged at 19:36 UTC as 5aa26f694) then added this test, which never initializes the service.
- **The fix.** Open upstream PR #6035 (024409767, "test(libSceUserService): initialize the service before polling its events") initializes the service first. With its diff applied, the test passed here. I found this while doing PM-016 on the same main; see results/cloud-2/PM-016.md.

## What makes the port's behaviour differ from PM-027 on main
1. **No indirect columns** (c794273ab is not on this tree). A T# reached through a pointer stored in a record is not a table column here, before or after the port. The question of selecting such columns, which main's code has to handle, does not arise.
2. **No folded columns** (55eefe9c5 is not on this tree). A descriptor spanning two loads of a record is not a table column here.
   - So a selected record can never be OffsetCarry poison. Main's carry check is left out because it can never fire.
   - Its test is left out.
3. **Disk cache format 34, not 36.** Entries never mix between trees anyway: the cache directory and every key carry `SourceVersion()`, a hash of the recompiler sources (`ShaderCacheVersion.cmake`). So 34 cannot meet main's 34 entries, and the e34-a2e "before" build's format-33 entries are not reused.
4. **Table-entry handling is this tree's own,** for a selected record as for a whole table. Main's later table changes are not here, notably c0e31dd7b ("use the image table marker for the single-level volume bias mode") and the other recompiler work since e34c47921. A selected record's entry therefore behaves like an e34 table entry, as it should for a before/after pair on this tree.

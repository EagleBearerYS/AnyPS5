## Not asked, but it blocks the PR: the merge with current main does not compile
- **The merge is textually clean.** `git merge-tree --write-tree upstream/main 62bbbb5dcc` exits 0 (upstream/main 8cd937e291).
- **The merged file still has one old-name call.** It defines and calls `LargestDeviceLocalHeap` at lines 528, 980, 989 and 1000. Line 994 still calls `largestDeviceLocalHeap(memory)`:

```
std::uint64_t StorageTextureBudget(const VkPhysicalDeviceMemoryProperties& memory, const VkPhysicalDeviceMemoryBudgetPropertiesEXT* reported) {
    const auto heap = largestDeviceLocalHeap(memory);
```

- **Compiled directly:** I ran `git merge --no-commit --no-ff 62bbbb5dcc` on upstream/main 8cd937e29 ("Automatic merge went well"), then built only `ShaderResources.cpp.o` with ninja. It failed with exit 1:
  - `core/libs/prx/libSceAgcDriver/Graphics/src/ShaderResources.cpp:994:23: error: 'largestDeviceLocalHeap' was not declared in this scope; did you mean 'LargestDeviceLocalHeap'?`
  - The merge was aborted afterwards. Nothing was committed.
- **Cause:**
  - The PR renames the file-local `largestDeviceLocalHeap` to `LargestDeviceLocalHeap` and declares it in `ShaderResources.hpp` for `PerformanceOverlay.cpp`. It renames the 4 occurrences its base e34c47921 has.
  - Upstream's 64ffeb8c9 (`fix(agc-driver): size the storage image cache from the device's reported memory budget`, merged as #5483 80ccb9fb1, after e34c47921) added `StorageTextureBudget` with a fifth call, under the old name.
- **The same break** stopped Village's fast-main tree with this PR merged in (GAC-014, 7b04bf9073). There, renaming that one call let the tree build, and the overlay tests passed.
- **Fix:** merge upstream/main into the PR and rename that call to `LargestDeviceLocalHeap(memory)`. It is one word; nothing else is needed for the build.
- **Why the overlap moves did not catch it:** af3bd503cb only moved the declaration in `ShaderResources.hpp`, to after `SampledBudgetReportDue`, and does not touch `ShaderResources.cpp`. The PR's base e34c47921 has no `StorageTextureBudget` at all. So only a build of the merge shows the missing rename.

Only this clause of the entry changes. It follows "… are stored ahead of every address-based build (`StoreDepthExpandWrites`)".
- **Before** (681fcee86): ": recorded into the import when one import holds the whole plane, and through the CPU, after a wait for the expand, when imports hold only parts of it (a write base across two registered ranges imported apart)."
- **After** (c0a8899cd): ": recorded into the import when one import holds the whole plane, into each range's import when every registered range under it has one (a write base across two registered ranges imported apart), and through the CPU, after a wait for the expand, only when part of the plane has no import (an imported range next to a heap-mirrored or copied one)."

### The commit message (third paragraph; the other two are unchanged)
- **Before:** "The plane is now stored when any import overlaps it (HostImportOverlaps). Without an import that holds all of it, the store goes through the CPU after a wait for the expand. A plane one import holds is still recorded into that import, and a plane no import touches still stays pending for the mirror refresh or the copy that reads it, so both cost what they did."
- **After:** "The plane is now stored when any import overlaps it (HostImportOverlaps). The storage image's write-back records it into each range's import when every registered range under it has one, and goes through the CPU, after a wait for the expand, only when part of it has no import. A plane one import holds is still recorded into that import, and a plane no import touches still stays pending for the mirror refresh or the copy that reads it, so both cost what they did."
- **Note:** the doc and the message describe main after ea3a2152d, as asked.
  - On the branch's own base (9f03c4fe0, without ea3a2152d), two imported ranges still go through the CPU (the table below). The PR lands on main, where the wording holds.
  - On main, `importSegments()` also falls back to the CPU when the ranges under the plane differ in their writable or GPU flags, or when a segment would start off a 64 KiB unit with unit shadows on. The test planes don't reach those cases.

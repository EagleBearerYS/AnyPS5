## The error, and which merge it comes from

`core/libs/prx/libSceAgcDriver/Graphics/src/ShaderResources.cpp:994:23: error: 'largestDeviceLocalHeap' was not declared in this scope; did you mean 'LargestDeviceLocalHeap'?`, in `StorageTextureBudget`:

```
std::uint64_t StorageTextureBudget(const VkPhysicalDeviceMemoryProperties& memory, const VkPhysicalDeviceMemoryBudgetPropertiesEXT* reported) {
    const auto heap = largestDeviceLocalHeap(memory);
```

- **#6012** (62bbbb5dcc, based on main e34c47921) renames the file-local helper `largestDeviceLocalHeap` to `LargestDeviceLocalHeap`. It also declares it in `Graphics/include/ShaderResources.hpp`, for `Execution/src/PerformanceOverlay.cpp`, and renames the 4 occurrences that e34c47921 has.
- **Upstream main's 64ffeb8c9** (ee6aba54, `fix(agc-driver): size the storage image cache from the device's reported memory budget`) added `StorageTextureBudget` with a fifth call, under the old name. It reached main in #5483 (80ccb9fb1), after e34c47921. The Village base (ab9a47684) has it.
- **Textually the merge is clean** because the changes are on different lines. So the merged file declares only `LargestDeviceLocalHeap` and still calls `largestDeviceLocalHeap` at line 994.
- **The overlay alone does the same on current main.** `git merge-tree --write-tree upstream/main 62bbbb5dcc` is clean (8cd937e29). The merged `ShaderResources.cpp` has `LargestDeviceLocalHeap` at lines 528, 980, 989 and 1000, and `largestDeviceLocalHeap(memory)` at 994.
  - So #6012 does not compile on main as it stands. It needs main merged in and that one call renamed.
  - PRM-008, open on the board, is a Linux compile of exactly that head.

### The fast proof (`fastRevalidate`, `:3201`)

**The P1 block (`:3214`)** comes right after the `validatedTextures.size()` check, as in P1. It keeps only the collect:
- **Each element:** an invalid record fails `NoRecord`; a depth element is skipped; every other element gets `surface.collected = TimedCollectWrites(...)`, and 0 fails `Collect`.

- It then returns true.

**Today's two parameters are respected:**

- **`withStorage`:** the storage loop runs only when `withStorage` is set.

**#12921's untracked and hint stamps** (`currentUntrackedStamp`, `:3267` and `:3327`, built on `hintedProof` / `untrackedRangeStamp`):

- P1 drops the unchanged-memory checks and keeps "a failed collect still fails it". So in the P1 block a 0 collect fails `Collect` without consulting the stamp, as on P1's own base, which predates #12921.
- **Effect:** such a template takes P1's full walk, which repeats no lookup. It is still accepted, and the report shows `Collect` / `Full` for it rather than `Fast`.

**Records:** as in P1, the block does not move `surface.generation` or `surface.keys`.

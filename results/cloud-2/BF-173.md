## One deviation from the task's rule, and why

**The rule as specified breaks an existing main test.** The task's rule was "on the bind path, compare at most once per present". I built it, and it fails `agc_driver_depth_plane_partial_store` on every run, at "a read of the first unit before a color target stored nothing" (`DepthPlanePartialStore.cpp:203`).

**That test's sequence**, within one present:
1. a CPU write over the stored plane (`Fill(plane, 1.0f)`);
2. a depth-writing draw;
3. a store.

**What goes wrong:**
- The draw's bind skips the comparison, so the CPU write is not synced before the GPU writes over it.
- At the store, the comparison sees memory differ from what the mirror stored and takes the CPU bytes as the newer ones. `ClearStale` drops the GPU's later depth, and nothing is stored.
- **The ambiguity:** after the fact, a store can't tell a CPU write made before the GPU's writes in the present from one made after them.
- **When it matters:** only when the bind that skipped also writes the plane.

**What I built instead:** the bound applies to binds that leave the plane unwritten. A bind with a depth write or an HTILE clear marks the whole plane stale right after the sync (`DepthSurfaceView`, `:2061` on main). That bind compares, as in BF-171.

**What that leaves:**
- Read-only binds, which are where a sampled or depth-tested plane is re-bound across epochs, get the per-present bound. A CPU write they miss can only be followed by GPU reads, so the store's "CPU wins" is right.
- Depth-writing binds keep BF-171's per-epoch cost.

**Shown by mutant M3** (the bound on every bind, as specified): `agc_driver_depth_plane_partial_store` and the new `write-order` case both fail. The bounded head passes both.

## The present serial

- **Used:** `Recorder::Presents()` (`Recorder.cpp:1994`), which reads `presentSerial`.
  - `Recorder::CountPresent()` (`Recorder.cpp:1989`) advances it with a relaxed `fetch_add`.
  - `VulkanDevice::present` calls `CountPresent()` (`VulkanDevice.cpp:3381`) on every present that acquired a swapchain image, with no trace condition.
  - A present dropped at acquire (`VK_NOT_READY`, `VK_TIMEOUT` or out of date, `:3296-3304`) doesn't advance it.
  - The texture cache already uses it as its frame counter.
- **Rejected:** `PerformanceTrace::presentCount` is private and advances only while a trace window is open or a summary interval is set (`PerformanceTrace.cpp:315-337`).
- **Nothing was added.** Tests advance the serial with `Recorder::CountPresent()`, as `SampledCacheBudget.cpp` already does.
- **A harness that never presents** stays at serial 0. Its read-only binds compare at most once, and its stores, retirements and writing binds still compare.

## The rules (`DepthSurface.cpp` on e35998524)

- **Bind path:**
  - `DepthSurfaceView` calls `SyncFromMemory(mirrorResource(target), !depthWritten && !cleared)` (`:2045`), and that calls `WrittenUnits(…, binding)` (`:905`, `:855`).
  - For a plane the tracker doesn't cover, a `binding` lookup compares only if `unwatchedPresent != Recorder::Presents()` (`:863`). Otherwise it returns "nothing written", as main does.
  - Binds that write depth or clear the plane pass `binding = false` and always compare.
- **Store and retire paths, always compared:**
  - `FlushDepthPlanes`' sync before it stores stale units (`SyncFromMemory(resource)`, `:2137`);
  - `retireStoringStale` (`WrittenUnits(resource, generation)`, `:1850`);
  - `OverwrittenInMemory`, the gate into retirement (`:589-595`).
- **One comparison, one memo.**
  - Every path goes through BF-171's `UnwatchedUnits`, `UnwatchedBlocks` and `StorageTexture::CompareUnwatched`, with its `comparedRanges` memo.
  - Any path that actually compared records the present in `unwatchedPresent` (`:863`, `:593`; member `:948`). So a store's, retirement's or writing bind's comparison counts as the present's bind comparison.
  - A lookup that couldn't compare (no mirror yet, or no unit whose stored bytes are saved) records nothing.
- **Nothing else** in BF-171's commit changed.

## Tests (`DepthPlaneBufferMemory.cpp`, ctests `agc_driver_depth_plane_unwatched_*`)

**What changed in the cases:**
- **(a) `draw` changes:** a `Recorder::CountPresent()` sits between the CPU write and the draw.
- **(a2) `same-frame` is new:**
  1. the store;
  2. a present;
  3. a draw writing 0.25, which compares;
  4. the CPU write of 0.125 at the start of unit 0;
  5. a read-only draw in the same present, which skips the comparison;
  6. `FlushDepthPlanes`.
  - Memory must hold the CPU's 0.125 at the 4 floats, 0.5 in the rest of unit 0 and the GPU's 0.25 in unit 1.
- **(a3) `write-order` is new**, and guards the deviation:
  1. the store;
  2. a present;
  3. a read-only draw, which compares;
  4. the CPU write;
  5. a depth-writing draw at 0.25 in the same present;
  6. `FlushDepthPlanes`.
  - Memory must hold the draw's 0.25 everywhere, the 4 floats included.
- **(e) `bind-bound` is new.** Binds are `DepthSurfaceView(…, false)` calls, each in a new collect epoch so the memo hides nothing, counted by `StorageTexture::UntrackedCompares()`:
  1. a store and a present, then 8 binds: must compare **1** time;
  2. 8 more: **0**;
  3. a present, then 8 more: **1**;
  4. a present and a depth-writing draw, then a new present opened by `FlushDepthPlanes`. The store compares, at least once, and the 8 binds after it in that present must compare **0** times.
  - Output: `8 binds per run, each in a new collect epoch: 1, 0 (same present), 1 (next present) comparisons; a store opening a present: 2 comparisons, then 0 in 8 binds`.
  - The store's 2 are the depth sync's comparison plus the mirror write-back's own keep comparison over unwatched units (`writeBackLayers`, main code).
- **(b) `store`, (b2) `retire`, (c) `large`, (d) `unchanged`:** unchanged.

# PM-062: CI's Linux job on five open PR heads (#6243, #6455, #6475, #6470, #6641)

**Worker:** cloud-2. The VM's IPv6 is disabled (`ipv6.disable=1`). Lavapipe.
- Git runs as root. Configure, build and ctest run as the unprivileged user `runner` (uid 1001), with ACLs on the source tree.
- Configure: `-G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DANYPS5_ENABLE_SPIRV_TOOLS=ON`, gcc/g++, ccache.
- Each head: `cmake --build build`, `cmake --build build --target libs`, `python3 tools/check_test_registration.py build`.
- Then, as `runner`: `ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx ctest --test-dir build --output-on-failure --timeout 120 --parallel 4 --output-junit ctest.xml`, and `python3 tools/check_skips.py build/ctest.xml`.
- One CI-configured tree, rebuilt per head in the listed order. Nothing pushed but this file.

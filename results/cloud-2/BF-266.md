### B266-1: libSceFreeTypeOt `ft_mem_*` (8 free rows), built

- **Rows:** the 8 `ft_mem_*` rows in the free table above.
- **Shared pieces:**
  - one guest `FT_MemoryRec` (`user`, `alloc`, `free`, `realloc`, LP64, 32 bytes);
  - the q-variants that the others are built on: `alloc` → `qalloc`, `realloc` → `qrealloc`, `dup` and `strdup` → `qalloc`, `qrealloc` → `free`.
- **What the source says, and what the test checks:** a recording guest allocator whose blocks start filled with 0xAA, so clearing is visible.
  - **qalloc:**
    - size > 0 calls `memory->alloc(memory, size)`;
    - a null result is Out_Of_Memory (0x40);
    - size 0 returns null with no call;
    - size < 0 is Invalid_Argument (0x06);
    - the block is not cleared.
  - **alloc:** the same, and the block is cleared.
  - **free:** a null pointer makes no call; otherwise it calls `memory->free(memory, P)`.
  - **qrealloc:**
    - a negative item_size, cur_count or new_count is 0x06, with the block unchanged and no call;
    - new_count 0 or item_size 0 frees the block and returns null;
    - new_count above `FT_INT_MAX / item_size` is Array_Too_Large (0x0A);
    - at the boundary, `0x3FFFFFFF × 2` is still allocated, as 0x7FFFFFFE bytes;
    - cur_count 0 calls `alloc(new × item)`;
    - otherwise it calls `realloc(cur × item, new × item, block)`;
    - a failed realloc keeps the old block and returns 0x40;
    - the grown tail is not cleared.
  - **realloc:** keeps the old items and clears only the new ones; shrinking clears nothing; errors keep the block unchanged.
  - **dup:**
    - copies every byte, embedded zeros included;
    - size 0 returns null;
    - a null address allocates without copying;
    - a size above FT_Long's range is 0x06.
  - **strdup:** allocates strlen + 1 bytes; null returns null with no allocation; a failed alloc is 0x40.
  - **strcpyn:**
    - copies up to size − 1 characters, terminates the result, and returns 1 when it truncated;
    - size 1 writes only the terminator;
    - size 0 still writes the terminator, as the source does.

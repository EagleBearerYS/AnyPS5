## 2. The new case: it failed, so it is fixed

The `overlay` case is added to `agc_driver_address_dispatch_reuse`.

**What it does:**
- It compiles a one-thread address-based compute program. The program loads a word through the BDA pointer, adds 1 and stores it through a V# into a 16 KiB written element.
- #8104 stages that element as an overlay of its import. The case checks the `APS5_TRACE_STAGING` line for that exact range (`[staging] 0x<element>+0x4000 (16.0 KiB)`).

**What it checks:**
- Dispatch 1 sees 0x100 and leaves 0x101.
- The CPU stores 0x200, then dispatch 2 runs. It must:
  - be counted as `Reused`, with no new build;
  - leave 0x201. A value of 0x102 would mean the copy-in was not repeated; 0x200 would mean the write was not copied back.
- Two more dispatches in one batch must both be reused and leave 0x203. A value of 0x202 would mean the second copy-in did not follow the first copy-back.

One thread is used because lavapipe runs 64 threads as 8 subgroups. With 64 threads, each subgroup's read-increment-write gave 0x108.

### Red on the merge

With the case on 2e1222e19 and no fix, 2 of 2 runs fail:

```
[staging] 0x7f36a05a4000+0x4000 (16.0 KiB)
AGC graphics: address dispatch reuse: the second dispatch of the build with a staged element was not reused (0 reuses, 2 builds)
```

**Cause:**
- `GuestBufferMemory::SpaceRegions()` refuses any region that is neither direct nor a fixed read-only mirror.
- #8104's overlay region is a GPU copy (`gpuCopy`, `deviceLocal`) with no direct pointer.
- So `noteReusable` never marks an address-based build with a staged overlay reusable. Every dispatch of it rebuilds. Copy-in and copy-back were never reached on reuse because there was no reuse.

### The fix

A staged region counts as a space region:

```cpp
const bool staged = region.gpuCopy && region.deviceLocal;
if (region.direct == nullptr && !fixedMirror && !staged) return std::nullopt;
```

Why this is safe:
- On every reuse, `proveBuild` step (3) records the region's copy-in from its import anew (`RecordStagingCopies`). That function also resets `copiedBack`.
- On every use, `MarkGpuWrites` records the copy-back of the written ranges (`RecordCopyBacks`).
- The region's range is held to the serial of the import it lies in, like a direct region (`HostImportSerial` in `noteReusable`, rechecked by `Revalidate`).

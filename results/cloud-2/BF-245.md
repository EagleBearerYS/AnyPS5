## The census

**The gate:** `APS5_MEMORY_CENSUS`, any value but `0`, read once into a function-local static (`Enabled()`). With it unset:
- **Per packet:** one static-bool check, in `PacketTimer::~PacketTimer`.
- **Per owner scope:** one static-bool check (13 sites).
- **Everything else is off:** no `vkGetDeviceProcAddr` wrapper is installed, and no walk, file read or lock runs.

**Cadence:** the first tick after the variable is set starts a 10 s clock. After that, the packet worker whose tick wins a compare-exchange prints one block per 10 s.
- **Where it runs:** the same place and thread as the `[packets]` / `[poll]` summaries, after the packet's own lock scopes have closed.
- **Without `APS5_PROFILE_DRAW`:** it still runs, since it doesn't need draw profiling.
- **Output:** one `ProfilePrint_nid_no_patch` call per block, so the lines stay together.

**Two limits of the tally:**
- **Pool reuse:** memory the buffer pool retains and hands to another owner without a new `vkAllocateMemory` stays with its first owner. The `[bufferpool]` line under `APS5_PROFILE_DRAW` has the pool's retained bytes.
- **Driver-internal memory:** the Vulkan driver's own memory isn't device memory and can't be measured from our side: descriptor pools (counted, not sized), pipelines and shader modules (counted on the `driver` line where counters exist). It shows up in the walk's other-private or shared-view class.

**Pipelines and `APS5_NO_GPL`:**
- **What the block can count:** the store's cached pipelines, GPL library parts, linked pipelines and optimized relinks.
- **What it can't:** live shader modules have no counter on main.
- **What `APS5_NO_GPL=1` changes** (read at `VulkanDevice.cpp:1668`):
  - pipelines are built monolithic: no library parts, links, LTO relinks or LTO-retained shader modules;
  - registration prebuilds nothing.
- **Measuring it:** `parts`/`linked`/`optimized` go to 0, and a pair of runs measures the private difference.

**Unit test:** `agc_memory_census` (`tests/MemoryCensus.cpp`) links only `MemoryCensusParse.cpp`, the pure part, so it can't start a device or break the census at run time. It tests:
- **Classification:** arena overlap, shared/memfd, images, private, edges.
- **Smaps sums:** with malformed lines, an overflowing number, a wrong unit, a field before any header, and hex-letter addresses.
- **`/proc/self/status` parsing.**
- **The remainder arithmetic:** signed, saturating.

The parser never throws: a malformed line is skipped. A `report()` failure is caught and printed as `[mem-census] census failed: …`.

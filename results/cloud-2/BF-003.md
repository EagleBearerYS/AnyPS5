## Machine

- AnyPS5 Cloud 2: a Firecracker VM named `vm`, running Ubuntu 24.04.5 LTS on kernel 6.18.44-fc-v114.
  - The kernel boots with `ipv6.disable=1`, so the VM has no IPv6, not even loopback.
  - There is no `/dev/udmabuf` and no display.
- CPU and memory: 4 vCPU Intel Xeon Processor @ 2.80 GHz (`lscpu`), 1 thread per core, AVX2 and AVX-512F; 15 GiB RAM, no swap.
- Toolchain: gcc/g++ 13.3.0, CMake 3.28.3, Ninja 1.11.1, ccache 4.9.1.
- Vulkan: lavapipe from mesa-vulkan-drivers 25.2.8 (llvmpipe, LLVM 20.1.2) through libvulkan1 1.3.275.
- Write watching works here.
  - `vm.unprivileged_userfaultfd` is 0, so `GuestWriteWatch` opens userfaultfd with `UFFD_USER_MODE_ONLY`. Kernel 6.18 has `UFFD_FEATURE_WP_ASYNC` and `PAGEMAP_SCAN`.
  - `agc_write_tracking` ran in full every time; it never printed "no write watching: skipped".
- Users: git ran as root. Configure, build and every test ran as the unprivileged user `runner` (uid 1001), as on CI's runners. `runner` owns the build tree and has write access to the source tree through ACLs.

## Step 2: red/green on agc_write_tracking

**Red, on the base 276608d2cf with M's `WriteTracking.cpp`:** FAILED (exit 1) with the expected message. It did not print "no write watching: skipped".

```
    Start 172: agc_write_tracking
1/1 Test #172: agc_write_tracking ...............***Failed    0.03 sec
write tracking test failed: a range walked earlier in the epoch is walked again after the rest of a 300-range working set
```

Under `--repeat until-pass:5` it failed 5 of 5, with the same message each time, so the red is deterministic.

**Green, on M:** `--repeat until-fail:20` gave **20 of 20 passed**. Each run printed "write tracking tests passed", took 0.02 s, and none skipped.

This matches the commit message.
- On the base, the 64-entry ring is overwritten by the 299 later ranges, so the first range is walked again. That walk sees the CPU write to `memory[8]`.
- On M, the per-thread exact index still holds the first range for the epoch, so the walk is skipped.
- In both trees, the next epoch's collect sees the write.

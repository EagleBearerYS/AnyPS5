## 3. #10834 only: the `EVP_cleanup` entry, a hand edit beyond keeping both sides

**Before:** #10834's entry said
> Nothing in this module can fill them yet, because `OPENSSL_add_all_algorithms_noconf`, `SSL_library_init`, `CONF_modules_load_file`, `OPENSSL_load_builtin_modules`, `OBJ_create`, `OBJ_cleanup` and `PKCS12_PBE_add` are not implemented, so `EVP_cleanup` returns without doing anything;

**After #13562,** `OBJ_create` and `OBJ_cleanup` are implemented, so that list was false.

**The behaviour is still right.** In LibreSSL 2.5.4 at the commit the entry cites (2e2c612066, `evp/names.c` and `objects/obj_dat.c`, fetched for this check):
- `EVP_cleanup` calls `OBJ_cleanup` only when `obj_cleanup_defer == 2`.
- `obj_cleanup_defer` is armed only by `check_defer`, which only `EVP_add_cipher` and `EVP_add_digest` call, for a NID at or above `NUM_NID`, meaning one made by `OBJ_create`.
- In this module, on main and on the merge, `EVP_add_cipher` and `EVP_add_digest` don't exist, and every registration path (`OPENSSL_add_all_algorithms_noconf`, `SSL_library_init`, `CONF_modules_load_file`, `OPENSSL_load_builtin_modules`, `PKCS12_PBE_add`) still throws. So the deferred `OBJ_cleanup` can never be armed, and an empty `EVP_cleanup` still matches LibreSSL.

**The new text:**
> … because `OPENSSL_add_all_algorithms_noconf`, `SSL_library_init`, `CONF_modules_load_file`, `OPENSSL_load_builtin_modules` and `PKCS12_PBE_add` are not implemented and no cipher or digest can be registered under an `OBJ_create` NID to defer `OBJ_cleanup`, so `EVP_cleanup` returns without doing anything;

- **Length:** the entry grows from 789 to 851 characters, under the 1000 limit; `check_conventions.py` passes.
- **No code change.**
- **The merge body** names it:

```
The EVP_cleanup entry no longer lists OBJ_create and OBJ_cleanup as unimplemented, since #13562 implements both. EVP_cleanup still has nothing to clear: LibreSSL 2.5.4 defers OBJ_cleanup only after EVP_add_cipher or EVP_add_digest registers an OBJ_create NID, and nothing here can register one.
```

## Commit 1: hops after a pointer-keyed record pointer (Gran Turismo 7's shape)

**The fix.** In `TryMakeIndirectColumn` (`Optimization/src/ResourceTracker.cpp:991`), the guard went from `if (!hops.empty() && (buffer || merged)) return false;` to `if (!hops.empty() && buffer) return false;`. **Nothing else had to change.**

**The later steps, checked on a hopped pointer-keyed plan:**
- **`PointerRecordPairs` and the `Precedes` scan** run on `pointer` after the hop loop, the innermost `GetAddressResource` (P1's words), as without hops. `Precedes` compares the record table's handle with the final T# handle, which hops don't move.
- **`plan.parentPointer = pointer`** is P1 (`if (buffer || merged)`).
- **`plan.hopReads`/`plan.hopMemory`** (the planning loop at ~line 1766) mark the hop reads planned: their only uses are `GetAddressResource(P2)`, whose only users are the planned T# reads. P1's record reads stay in the program for the runtime key.
- **`ResourceMaterializer::ReadColumn`** (`ResourceMaterializer.cpp:981-982`) stores `records.pointers[record] = pointer` (P1) before it applies `column.pointerHops`. So the snapshot is keyed by P1 and the T# is read behind the hop.
- **`ShaderDiskCache`** already serializes `pointerHops` and `pointerKeyed` (`ShaderDiskCache.cpp:1092-1100`, read at 1256-1264). Its check at 1305 (`column.pointerKeyed && (!column.indirect || column.buffer || parent)`) doesn't forbid hops. Not exercised: every test run here used `ANYPS5_NO_SHADER_CACHE=1`.
- **The SPIR-V side:** the test below runs on lavapipe and checks colors, faults and relinks.

**Its test, in the same commit.** `RunPointerHopTests`, mode `--pointer-hop`, ctest `agc_driver_pointer_hop_table`. It is listed with its neighbours' `ENVIRONMENT` (`ANYPS5_NO_SHADER_CACHE=1;APS5_NO_PIPELINE_JOURNAL=1`, skip code 77, timeout 30) and on their WIN32 `PATH` line.

**`PointerHopCode`** (60 words, llvm-mc 18, gfx1030 wave64) is built from `PointerBallotCode`:
- a waterfall loop keyed by `v_readfirstlane` → `s_lshl 4` → `s_buffer_load_dwordx2 [record + 0x8]`. That gives P1, record dwords 2-3;
- P1's low word is a Phi of the record word, a constant arm (`0xea`) and a `v_cmp_ne` lane-mask word (`Ballot(LogicalAnd)`);
- then `s_load_dwordx2 P2, [P1 + 0]`, the hop;
- then `s_load_dwordx8 T#, [P2 + 0x340]`, and `image_sample_lz`.

Records 0-2 point at two link blocks, each holding a P2 to a block with a T# at +0x340 (float and other-float images). Four groups use keys {1,2}, {2,1}, {1,1}, {2,2} per lane half.

**Checks:**
- every lane's color;
- the constant arm and the `Ballot` arm each fault "outside the snapshot", with nothing published and the same artifact;
- after record 1's link block is re-pointed to the other T#, the result follows without a recompile.

**Red** (8704f73b79 plus the test, guard unchanged; exit 1): `ShaderRecompiler::Recompile: GetImageResource dword 0 is not a valid runtime value; chain: LoadAddressU32@pc=0x000000b4(GetAddressResource(LoadAddressU32@pc=0x000000a8(GetAddressResource(Phi(Immediate, Phi(ReadConstBuffer@pc=0x00000074(GetBufferResource(ReadConst, ReadConst, ReadConst, ReadConst), ShiftLeftLogical32(ReadFirstLane, Immediate)), CompositeExtractU32x4(Ballot(LogicalAnd), Immediate))), ReadConstBuffer@pc=0x00000074(...` This is GT7's chain shape: two `LoadAddressU32` levels over a Phi of a record read and a `Ballot` word.

**Green:** `pointer table with a pointer hop: a T# read through a pointer loaded from a record pointer whose low word passes Phis with a constant and a Ballot word checked, by the records' values`.

## Disk cache: no bump (FormatVersion stays 46)

- **Old entries are rejected anyway.** `SourceVersion()` hashes the recompiler's sources, and `ResourceTracker.cpp` is in that list (`build/.../shader_recompiler_agc_driver_generated/sources.txt:204`). So every entry written by the old planner sits under another version directory and is rejected on load.
- **Refusals are never stored.** A plan failure is memoized in-process only (`FailureMemo`, `planFailure`, `Recompiler.cpp:509`). `StorePlan` runs only after a plan succeeds (`:512`), and `Store` only after a recompile succeeds (`:1251`).
- **The format is unchanged.** Commit 1 adds no field: hopped pointer-keyed columns use `pointerHops` and `pointerKeyed`, which are already serialized.

## Part 2: the sweep (report only)

**Method:** a scratch script (`sweep.py` in the VM's scratchpad, not in the tree) ran on main 7929303f2f, using `progress.py`'s own parser (`code`, `DEFINITION`, `stub_calls`, `statements`).
- For every function `progress.py` counts as done, it split the body into top-level statements.
- It kept the function when the last statement is a `throw` or a call to a helper in the same file whose body ends in a `throw` and has no `return`. A `throw` followed by an unreachable constant `return` counts too.
- Every earlier statement had to be a declaration, a discard, a guard that throws, or an `if` returning an error-looking value (a named error, a hex code from 0x80000000, or a negative number). There could be no loops and no `switch`.
- **Limits:**
  - a final `else throw` is not matched;
  - an all-throwing `switch` is not matched;
  - a helper defined in another file is not followed.

**Result:** 35 functions. Sources are from the clones above; "stub" means the source logs and returns OK.

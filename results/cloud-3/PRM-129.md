**What `Identity()` mixes now:**
- **Its inputs are the existing `mix` lambda and the same fields, in the same order,** as `BindlessHeap::embeddedSamplerMapping` keys on (`Graphics/src/BindlessHeap.cpp:1110-1118`), plus the element's index and its embedded binding number.
  - The four words and the depth-compare, unnormalized and integer-border bits are all mixed.
  - A missing flag reads false, as in the mapping. A missing word reads 0, though the builder always writes four per element.
- **Stages with no embedded element keep exactly their 73c5187825 identity.** Every new `mix` sits inside `if (samplerEmbedded[element] != NoEmbeddedSampler)`. No count or size is mixed outside that branch, and the per-binding `mix` line is byte-for-byte the old one.

**The coordinates-ignored choice:** I mix **the adjusted word 0**, with bit 15 cleared when `samplerCoordinatesIgnored[element]` is set, exactly as the mapping does at `BindlessHeap.cpp:1114`. I don't mix it as a separate flag bit. So two stages get the same identity exactly when they would build the same embedded sampler key, and not otherwise.

## 3. Caches and the journal: no version bump needed

**The pipeline journal:**
- **Journal files are already invalidated.** Every journal file's header carries `ShaderDiskCache::SourceVersion()`, and a file whose header doesn't match is dropped whole on open and on load (`Graphics/src/PipelineJournal.cpp:674`, `:916`).
- **`Recompiler.hpp` is in the version hash.** `SourceVersion()` (`ShaderDiskCache.cpp:1965`) is the generated SHA-256 over the recompiler sources listed in `sources.txt`, and `core/shader/recompiler/Recompiler.hpp` is a `sources` entry in that list. So this commit changes `SourceVersion()`, and every journal written before it is dropped.
- **Individual stages are checked too.** Independently, each module record re-derives its identity when decoded, and is used only if `result.Identity() == identity` (`PipelineJournal.cpp:944`; the prebuild path is `:1446`). An embedded stage stored under its old identity would fail that check and be dropped, not served.
- **So a stale journal entry can't be read as current.**

**The shader disk cache:**
- It stores no identity at all: `PipelineIdentity` and `Identity()` don't appear in `ShaderDiskCache.cpp`.
- Its entries are also versioned by `SourceVersion()`, both in the header check (`ShaderDiskCache.cpp:1513`) and in the per-version directory (`:1536`).
- `FormatVersion` describes the encoding, which this commit doesn't change.

## 4. The test

**Where it lives:** `agc_driver_heap_embedded_sampler_identity` is an argument variant (`--identity`) of `HeapEmbeddedSampler.cpp`, in the same commit as the fix. `CheckIdentities` does this:
- **Two compiles of #9508's `ConstantSamplerCode`:**
  - as is, with word 1 = `BorderClamp` (0x1b6);
  - as a copy with word 1 = 0 (`WrapSamplerCode`).
- **The target:** both use `device.ComputeTarget(32u)` with `gpuResolvedImages = true`, so the test runs on lavapipe without `VK_EXT_descriptor_heap`.
- **It requires:**
  1. Both stages embed their sampler.
  2. `border.Identity() != wrap.Identity()`.
  3. Flipping the embedded element's integer-border flag changes the identity.
- **The no-embedded-element half,** using `UserSamplerCode` compiled twice:
  - It requires no embedded element, a non-empty identity, and the same identity across the two compiles.
  - It then flips the stage's `samplerDepthCompare`, `samplerUnnormalized`, `samplerIntegerBorder` and `samplerCoordinatesIgnored`, and inverts every `samplerEmbeddedWords` word. The identity must not change. That shows the new mixing reads nothing from a stage with no embedded element.

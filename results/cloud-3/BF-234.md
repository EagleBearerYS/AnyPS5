## Draft PR body

### What
Stacked on #10944, which makes the build fixes: it compiles the Export.cpp stubs of libSceAgc, libSceAgcDriver, libSceAudiodec.native, libSceAvPlayer.native, libSceNgs2.native, libSceNpTrophy2 and libSceNpUniversalDataSystem, and exports libSceNgs2's PendingExports.cpp. This PR adds what #10944 doesn't:

- `tools/check_test_registration.py`, which CI already runs after configure, now also fails when a non-test `.cpp` under `core/libs/prx` defines an `APS5_VABI` function and no target compiles it (or `#include`s it from a compiled source), so a stub file that never ships is caught instead of being counted by `tools/progress.py`. It reads Ninja's compile commands; `tools/tests/test_unbuilt_exports.py` (7 cases, ctest `unbuilt_exports`) covers it. On today's main it lists exactly the seven files #10944 builds plus libScePlayerInvitationDialog's.
- libScePlayerInvitationDialog's `Export.cpp` is removed: it was never built, and its two `return 0` stubs duplicate `scePlayerInvitationDialogTerminate` and `scePlayerInvitationDialogUpdateStatus`, which `libScePlayerInvitationDialog.cpp` implements.
- The debt files of libSceAgcDriver, libSceNgs2.native and libSceNpUniversalDataSystem gain the pending-exports entries the other four libraries already have.
- #10944 checks one export per library; the tests here call every other newly exported stub (34 AgcDriver, 14 Ngs2.native, libSceNgs2's 6, 22 NpTrophy2, 10 NpUniversalDataSystem) and give libSceAudiodec.native (14) and libSceAvPlayer.native (2) their first guest tests.

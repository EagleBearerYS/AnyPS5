# BF-020: BF-018's budget rule now follows #6479

**Done as a follow-up commit.** BF-018 was already pushed, so this is 219da69c32, `perf(agc): keep an evicting refusal remembered while the budget shrinks`, on `perf/agc-remember-evicting-refusals` (now 9c308c739 → 4ee79e522 → 219da69c3).

**The rule.** `evictingRefusalCurrent` now tests `budget <= refusal.budget` instead of `refusal.budget == budget`. A remembered evicting refusal expires only when the budget grows, as #6479's `stillRefused` does.

**Why it is safe.** The refusal holds while the non-evictable bytes outside the run plus the run's bytes exceed the budget. A smaller budget can only keep it refused, and it shrinks the room for a step down too. The debt entry now says "the budget has not grown".

**New test case.** In `evictingRefusalMemoryTests`, the budget is lowered by one 64 KiB piece after the refusal, and the next evicting request must still be answered from memory. The budget is then restored for the rest of the test. The existing "budget raised" case still requires a fresh import.

```
fix(libSceNpManager): follow the measured IdMapper and NpManagerInt request checks

BunnyFl measured firmware 13.42 libSceNpManager.sprx. The IdMapper
account-id lookups take seven arguments: a request id of 0 or less
gives 0x80553085, then user id -1, a null pointer or a value outside
1 to 1000 gives 0x80553083. IdMapper abort and delete refuse a request
id of 0 or less with 0x80553085 as well.

Past those checks every call reaches the NP service, and NpManagerInt
requests sit in a table whose ids and unknown-id answer are not
measured, so these paths throw instead of the signed-out answers and
the shared request pool that were modelled on the public calls.
```

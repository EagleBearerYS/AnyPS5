- **The line at 6407d568ba (`ShaderResources.cpp:2787-2788`):**
  ```
  const bool spaceReusable = drawBuild && usesBda && bdaReadOnly && !htileClear.has_value() && !SpaceReuseDisabled() && ...;
  if (!spaceReusable && (htileClear.has_value() || guestMemory.HasCopiedWrites() || HoldsLease() || usesBda || ...)) return;
  ```
- **PRM-095's line (a497975afd):**
  ```
  const bool spaceReusable = drawBuild && usesBda && bdaReadOnly && !SpaceReuseDisabled() && ...;
  if (htileClear.has_value() || (!spaceReusable && (guestMemory.HasCopiedWrites() || HoldsLease() || usesBda || ...))) return;
  ```
- **They decide the same way in every case:**
  - With an HTILE clear, #9508's `spaceReusable` is false, so `!spaceReusable && (true || ...)` returns. PRM-095's returns on its first term.
  - Without one, both reduce to `!spaceReusable && (...)` with the same `spaceReusable`.
  - After the return, `spaceReusable` is read only on builds without an HTILE clear, where both have the same value.
  - So a build that matched an HTILE mask clear is never reusable, address-space reuse included, as main has it. That is the rule the task asks for.
- **Why I kept #9508's text:** writing PRM-095's line here would put a #7642-side change on a #9508 line and add two lines to #7642's own diff.

## 7. The heap gate at dd7120c648

### 7.1 What it checks now

The gate is `VulkanDevice.cpp:1988-2000` at 6407d568ba: the revision check at :1988-1992 is from 9263a4bdce (Raghav314), and the layer check at :1993-2000 is from fd802c3b42.

1. **Extension revision:**
   ```
   const auto heapExtension = std::find_if(availableExtensions..., VK_EXT_DESCRIPTOR_HEAP_EXTENSION_NAME);
   bool releasedDescriptorHeap = heapExtension != availableExtensions.end() && heapExtension->specVersion >= VK_EXT_DESCRIPTOR_HEAP_SPEC_VERSION;
   ```
   - The minimum is the headers' revision, not a number in the code. In the pinned Vulkan-Headers (5d94bb4dcc, v1.4.335-6), `VK_EXT_DESCRIPTOR_HEAP_SPEC_VERSION` is **1**. So in practice the rule is "revision 1 or newer".
   - Below it, the gate prints "[gpu-heap] the driver's VK_EXT_descriptor_heap is revision %u, older than the released revision %u, so the GPU heap stays off".
   - **The device's Vulkan API version is no longer checked.** The commit message says NVIDIA 595.99.02 reports 1.4.329, ships revision 1, and passes every heap test.
   - **A note on future header bumps:** the threshold follows the headers. If the pin moves to headers with revision 2, a revision-1 driver would turn the heap off.
2. **Validation layer:** unchanged from fd802c3b42. If `ActiveValidationLayerVersion` reports a layer below **1.4.363**, the heap stays off ("predates its descriptor heap rules (1.4.363 is the oldest layer that validates heap push data)"). With no layer, nothing is checked.
3. **The rest** is unchanged: maintenance5, dynamic rendering, depth-stencil resolve and renderpass2; the `descriptorHeap` and `maintenance5` features; and `BindlessHeap::Fits`.

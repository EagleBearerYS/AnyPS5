## Method

- **Five parallel read-only passes**, one per group of libraries, under one guide that restates PM-088's classes with BF-208's C split. Each pass wrote `<library>.tsv` (`function, class, basis`) and `<library>.notes.md`.
  - **Inputs per pass:** each library's todo list with every definition's `path:line` and text, its done names and its debt file.
  - **Line numbers:** my input generator counted lines on `progress.py`'s comment-stripped text, so its numbers were off. All five passes were told to cite only lines read from the files, and the checks below confirm they did.
  - **The guide's rules:**
    - no class without a basis;
    - cite only the tree, links already in the tree, or standards by section;
    - D whenever a public source or in-tree neighbour is missing;
    - C-real only when the console's answer is already in the tree and the declaration can give it.
- **Claims:** BF-208's rules, applied to every changed `.cpp` under `core/libs/prx/`, outside `tests/`, with main's `progress.py` parser.
  - A PR **claims** a row when it implements it (the body no longer throws), changes it (the body still throws), declares it, moves it to another library or removes the stub.
  - **Name search:** every added or removed line of every PR was searched for every row's name, with or without `_nid_postfix`.
    - Hits outside the row's library are counted only for names that can't collide: `sce…`, `_Z…`, VrTracker2 and the libc cursor and facet helpers.
    - 58 PRs mention a row's name. Every PR that mentions one in its library's code without a parsed event was read by hand (25 PR-row pairs):
      - #6731 changes `fscanf`;
      - #10698 declares 9 NpWebApi rows;
      - #9527 (adds `vfscanf_s`), #9641 and #9649 (`()` to `(void)`) and #9753 claim nothing.
  - **Closed PRs** count as claims, marked `claimed (closed #n)`.
  - **Declaration claims don't block a batch.** These are #8747's and #8731's pending-export declarations, the three JpegDec declarations (#6361, #6796, #7235) and **#10698**.
    - #10698 (open, MarcZX10) only changes the parameter lists of 9 NpWebApi stubs that keep throwing.
    - I counted it with #8747 because it implements nothing a batch would duplicate. That frees `GetHttpStatusCode` and `ReadData`.
    - If the PM reads "declares" strictly, those two leave B215-1, which keeps 10 rows.
- **Checks I ran on the output:**

  - **Citations:** all 1,664 `path` and `path:line` citations in the tables and notes were checked against the pinned tree.

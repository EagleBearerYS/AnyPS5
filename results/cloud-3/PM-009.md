## How the frames were rendered

- **Harness.** A local, uncommitted change to `core/libs/prx/libSceAgcDriver/tests/PerformanceOverlay.cpp`, following PRM-004's method; the diff is below. Built with `cmake --build build --target agc_performance_overlay_tests` (CI's configure flags; 66 steps, 112 s) and run as the unprivileged runner user on lavapipe (llvmpipe, Mesa 25.2.8, LLVM 20.1.2):
  ```
  ANYPS5_OVERLAY_SAMPLES=<dir> ANYPS5_REQUIRE_VULKAN=1 GALLIUM_OVERRIDE_CPU_CAPS=avx build/tests/agc_performance_overlay_tests
  ```
- **Production code.** The panel comes from the branch's own `ComposeOverlay(statistics, true, true, details)`, `PerformanceOverlay::Record`, `LayOutOverlay` and the overlay shaders: the same code the presenter runs.
- **Statistics.** `OverlayStatistics` was fed 121 presents, through the new `AddPresent(at, OverlayCounters)` overload:
  - 120 frame intervals of 16.7 ms, except 33.0 ms spikes at intervals 11, 24, 38 and 52. These are older than the last second, so they don't move FPS.
  - GPU and driver totals grow by 9.8 ms and 4.2 ms per frame.
  - Draws grow by 1240 and dispatches by 85 per frame, from 5000 and 70.
  - Pipelines are 1500 up to frame 109 and 1503 from frame 110, which is inside the last second. That gives 3 in the window and 1503 in total.
- **Details.** `OverlayDetails`:
  - vram used 6.1 GiB of a 7.8 GiB budget;
  - ram 3.2 GiB;
  - display 1920x1080;
  - window 2560x1440.
- **The composed lines,** printed by the harness, are exactly the ones listed above, so FPS = 59 intervals over 985.3 ms = 59.88, and the average = (116 x 16.7 + 4 x 33.0) / 120 = 17.24.
- **Format.** `VK_FORMAT_B8G8R8A8_UNORM` with `VK_COLOR_SPACE_SRGB_NONLINEAR_KHR`, the SDR swapchain format, as in PRM-004.
- **Background.** PRM-004's horizontal gradient across the full frame width: from (0.05, 0.10, 0.25) at x = 0 to (0.90, 0.55, 0.20) at the last column, in encoded values rounded to 8 bits, the same on every row.
- **Corners.** Top left for images 1 and 3. For image 2, `AgcDriver::ParseOverlaySettings("1", "br").corner`, the value `ANYPS5_OVERLAY_POS=br` gives.
- **Crops.** The panel plus 48 px on each side, clamped to the frame. The panel sits 8 px from the frame's edges (the 4-unit margin at scale 2), so the clamped sides keep 8 px.
- **Encoding.**
  - Python's standard library only (`zlib`, `struct`, `hashlib`, `base64`).
  - RGB, 8 bits per channel; alpha was 255 in every pixel.
  - Each row uses the PNG filter (None/Sub/Up/Average/Paeth) with the smallest sum of absolute bytes, then zlib level 9.
- **Checks.** Each PNG was decoded again with its CRCs checked, and its pixels compared equal to the readback. `file` reports "PNG image data, 390 x 288, 8-bit/color RGB, non-interlaced" (1280 x 720 for the extra). Base64 is wrapped at 76 characters.

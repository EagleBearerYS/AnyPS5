## The merged `[draws]` format (Graphics/src/Draw.cpp, reportDraw)

The line is built from successive snprintf fragments. These are the fragments the three branches changed, in print order.

1. The head of the line, unchanged from a38c704ea. "render passes … continued one" counts every recorded draw, not just indirect ones; it existed before BF-027 and is not BF-027's field:

   ```
   "[draws] %llu draws over 10 s (%llu recorded avg %.0f us, of them %llu with completion; %llu recorded then waited avg %.0f us; %llu synchronous avg %.0f us; render passes %llu begun, %llu draws continued one; waited or synchronous because:"
   ```

2. The indirect section opens with BF-024's fields:

   ```
   "; indirect: gpu-side %llu (%llu rewritten, %llu draw parameters), cpu-side %llu ("
   ```

3. One `" %s %llu"` per CPU path with a nonzero count. BF-026 adds a fragment right after the `non-vertex path K` entry:

   ```
   " (mesh %llu, tessellation %llu, geometry %llu, rect list %llu, other %llu)"
   ```

4. The section closes with BF-027's pass and barrier counts, printed after "argument reads":

   ```
   "), argument reads %.1f ms; gpu-side passes %llu begun, %llu continued; argument barriers %llu recorded, %llu skipped"
   ```

Put together, the indirect section prints as:

```
; indirect: gpu-side G (R rewritten, D draw parameters), cpu-side C ( ... non-vertex path K (mesh M, tessellation T, geometry Y, rect list L, other O) ...), argument reads X ms; gpu-side passes B begun, N continued; argument barriers A recorded, S skipped
```

The field check passes:
- **Nothing printed twice:** "argument reads" appears once and each pass or barrier count appears once. The "gpu-side passes" pair is BF-027's indirect-only count, separate from the all-draw "render passes" pair in the head.
- **Nothing lost:** BF-024's rewritten and draw-parameter counts, BF-026's non-vertex kinds, BF-027's pass and barrier counts and the argument read time are all printed.
- **Resets:** both new counters are reset after each print (`profile.nonVertex.fill(0)` and `profile.indirectPasses = {}`).

BF-026's other change, the Revalidate time split, prints in the `[rescache] revalidate` line from ShaderResources.cpp. That file in the merge is identical to BF-026's 9ff5a5b2b.

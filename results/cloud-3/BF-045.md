## Broken by design on Linux (source read, not run)

- `GuestMemory::GuardWrites` (his Execution/src/GuestMemory.cpp:2001-2009) calls GuestArenaGuardWrites only under `_WIN32` and returns false everywhere else.
- Residency: `ResidencyGuest::Guard` (Graphics/src/ResidencyGuest.cpp:49-52) returns that value. In Residency.cpp:522-526 an import with `cpuWritable` whose page cannot be guarded is counted `unguardable`, its slot freed, and the page never admitted; at :374-379 a guarded page that cannot be guarded again is demoted. So on Linux no CPU-writable page ever gets a device mirror: the resident path covers only GPU-only memory there, and every CPU-writable page stays on the old path.
- Unit shadows: UnitShadow.cpp:577-591 guards a unit only when GuardWrites succeeds, so `guardedNow` is always empty on Linux and no unit is ever marked guarded.
- tests/WriteGuards.cpp is `#ifdef _WIN32` (lines 4 and 21), so agc_write_guards cannot catch this on Linux.

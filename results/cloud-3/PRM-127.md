## 3. LOD bias on the device image path (report only)

**Do device-path samplers reach main's shader LOD-bias path? Yes.**
- **They are never sampler-table samplers.** A device-table image read through a sampler table fails compilation: `SpirvImageEmitter.cpp:2371`, `samples a device-table image through a sampler table`. So a device-path sampler always has `table == NoTable`.
- **The plan treats them like any direct sampler.** `DescriptorBindingBuilder.cpp:427` skips only table samplers, so a device-path sampler goes through the bias logic:
  - it computes the guest bias from the S# snapshot (:428-429);
  - it refuses a beyond-threshold bias the shader can't apply (:430) or on a cube (:432);
  - it pushes `SamplerLodBiasBase + index` (:434).
- **The emitter takes the same sample path.** A device-table image takes `EmitDeviceTableAccess` (`SpirvImageEmitter.cpp:2654`) and then the same `emitMode`, `EmitSampleOp` (:2040) and `emitBiasedSample` path. That path checks `AppliesLodBiasInShader(samplers.at(mem.sampler))` (:1932-1933) and reads the `SamplerLodBiasBase + mem.sampler` spec constant (:1935).
- **The host sampler matches.** GPU-heap stages take their sampler slots from the stage's `Sampler` objects (`ShaderResources.cpp:7089`, built at :5209/:5376/:5661). `Sampler.cpp:12-19` and :45 set `mipLodBias` to 0 whenever the guest bias is past `SamplerLodBiasShaderThreshold`, which is when the shader adds it instead.

**Does a device-path sampler past the threshold lose its bias? No.** The device image table serves only the image slot (`slots.take(Runtime::FirstImageBinding, ...)`, `DeviceImageTable.cpp:367`). The bias lives in the stage's sampler and the shader, as for direct images.
- `DeviceSamplerClass` (`DescriptorBindingBuilder.cpp:541-549`) encodes no bias, and it doesn't need to: the bias isn't part of the table's key or slot.
- The device table has no cube shape (`shapeOf`, `DeviceImageTable.cpp:69-81`, throws for other dimensions). So :432's cube refusal can't make the device path differ from the direct one.

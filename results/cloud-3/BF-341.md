## How each part was done

**Todo rows.** `python3 tools/progress.py --json` on a `git archive` of main; `libraries.groups[].todo_names` is the row list. Counts per library are in the table at the end.

**Sources.** A row is sourced only when one of these names that function's own behaviour:
- FreeBSD 11.4 sources ([freebsd-src d106002967](https://github.com/freebsd/freebsd-src/tree/d106002967eff712894ab8b5337bbbff106ce5e0)): libkernel, libkernel_sys, libc and libScePosixForWebKit rows whose name is a FreeBSD symbol, or a `sceKernel*`/`scePthread*` name whose snake-case form is one (`freebsd-twin`). The link is to the libc/libthr definition, or to `syscalls.master` for a bare system call. A twin whose FreeBSD function libkernel or libc already implements is class A. Process and system control (`fork`, `exec*`, `mount`, `kld*`, `ptrace`, `reboot`, `profil`, `ktrace` and so on) is B-L and grouped apart as blocked.
- The matching open-source library at the version the port follows, linked at a pinned commit with the defining line:
  - LibreSSL 2.5.4 ([2e2c612066](https://github.com/libressl/openbsd/tree/2e2c612066aa993717528a0249c15c51128d61cb)) for libSceLibreSsl, and 4.0.0 ([ce488b78e0](https://github.com/libressl/openbsd/tree/ce488b78e0bd994780569df718596b9776ff681a)) for libSceLibreSsl3;
  - ICU 78.1 ([049e0d6a42](https://github.com/unicode-org/icu/tree/049e0d6a420629ac7db77256987d083a563287b5));
  - FreeType [37515cf56b](https://github.com/freetype/freetype/tree/37515cf56ba3349656049edbed89ffc6f6466f2d), with libSceFreeTypeOl/Ot names resolved through their NIDs;
  - WebKit 11.x C API ([PS5-WebKit-11.x 80f77e94c6](https://github.com/neonmodder123/PS5-WebKit-11.x/tree/80f77e94c63ee7202eec3d4b5b1a021dd89011ba), a mirror of Sony's published WebKit source; ranked one step below the projects' own repositories for that reason);
  - FreeBSD 11.4 libusb for the nine libSceUsbd event-lock rows, which main's libSceUsbd follows ([debt doc](https://github.com/boykopovar/AnyPS5/blob/73f4f7e06e4f210a8c6570e335fd654dc0a86134/docs/dev/debt/libSceUsbd.md#L5)).
- A published standard or table: ISO/IEC 9899:2011 Annex K for `vfscanf_s`, and the unicode.org mapping files for 12 libSceCesCs code-page profiles and JIS X 0208.
- A firmware reading of that function's todo path, recorded in main through a merged PR. Three read-only agents read every debt doc, implementation and test of the remaining libraries, and kept 15 readings. A reading of a sibling, or of a path that is already done, was not counted.
- Main's offline model, service side only, once the module-side checks are measured: no row qualified (no todo row in an NP or service library has measured argument checks).

Rows sourced only by a sibling's answer, a twin's register shape, a naming convention, another emulator or a guess stay unsourced. They keep PM-088's class (C or D).

**Claims.** Every PR head is fetched from `refs/pull/*/head`. Each PR is scanned as `git diff merge-base..head` over `core`, `docs` and `tools`:
- open PRs: 1,633;
- PRs closed unmerged whose head is dated 10-17 or later: 716;
- older closed PRs (10-10 to 10-16) of the 48 limit authors: 8. A limit author has an open PR and none merged. Those PRs are #2966, #3139, #3157, #3910, #4262, #4278, #4440, #5086, and they claim nothing.

A candidate claim is any of these, in a library's `.cpp/.c/.h` sources:
- an added `APS5_EXPORT(nid, name)` with a real name;
- an added definition with a real body. A `return helper(...)` forwarder counts; `NotImplemented` plus `return 0;` does not;
- a hunk inside the function that removes lines and adds real code;
- any added line naming a sourced row, which catches what the three rules above miss;
- an added definition with a real body of the row's own name in **another** library's sources. This covers a PR that moves a function, as #9293 does when it defines libkernel_sys's `ksem_open` in libkernel. These rows count as in progress, because their own library no longer measures them.

A declaration only (`Unknown_<nid>_nid_no_patch`, a prototype, or a generated stub) is not a claim.

Each (PR or fork branch, library) pair with a candidate was then **re-measured**. Main's `progress.py` ran on main's tree with that library's directory taken from the head, and the libraries it includes taken from main. No contributor code was run. A row is then:
- **claimed, done at head** if it is no longer todo there: 1,569 rows;
- **claimed, in progress** if the head adds a real definition or a real-named export but `progress.py` still finds a `NotImplemented` path in it: 155 rows. For example, #11175 implements `EVP_DigestInit_ex` through a helper that still has an unimplemented branch;
- **not claimed** if its only candidates were a neighbouring hunk, a caller, or a generated stub, and the row stays todo: 566 rows;
- **possible** if the row is absent at the head (renamed, or a library older than the row): 351 rows. These are kept out of the unclaimed table.

## Limits of this pass

- Opened and closed dates come from git:
  - a PR is open while GitHub keeps its `refs/pull/N/merge`;
  - "closed in the last 14 days" uses the head commit's date, because the API's close date is not readable from this session;
  - "opened in the last 7 days" uses the PR number.
- Re-measuring checks the todo status that `progress.py` gives. It does not check that a claimed body is correct.
- A row in a renamed or removed library at the PR head counts as a possible claim, not a verified one.
- Only `.cpp/.c/.h` files under `core/libs/prx/<library>/` count toward a claim or an active author. Tests and docs alone do not.
- Nothing was built and nothing was pushed except this result.

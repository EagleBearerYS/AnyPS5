- **`agc_write_tracking_cpu_write_pin` (#11171)** doesn't exist on Linux in any tree, B and AB included. #11171 registers it inside `if(WIN32)` in `libSceAgcDriver/CMakeLists.txt` (AB line 800). Its body (`CheckCpuWritePin`, `WriteTracking.cpp:1424`) and the `--cpu-write-pin` dispatch both sit inside the file's `#ifdef _WIN32` block (lines 613–1492 and the `#ifdef _WIN32` in `main`). So its test case is built and run only on Windows.
- **#11171's fix is not Windows-only:** `pinStoreRanges`, and `CheckRange` moved into the store callback, in `Execution/src/GuestMemory.cpp`. It is compiled into `agc_write_tracking_tests` and the driver on Linux. The Linux run of `agc_write_tracking` (default mode) exercises `storeOwn`/`StoreOwnBytes` with it, but not the pin case.
- **`agc_driver_graphics` (#11148)** exists on every tree, so the name alone doesn't tell the trees apart. #11148's case `failedJoinWrittenViewTests` (`tests/BdaResources.cpp`, called from `RunBdaResourceTests`, which the default `agc_driver_graphics` mode runs) is in the source of `A` and `AB` and absent from `M` and `B` (`git grep` per SHA). It prints nothing on success, and `agc_driver_graphics` passes on A and AB with it. `agc_driver_graphics_maps_fallback` runs the same default mode with `APS5_NO_PROCMAP_QUERY=1` and passes too.

# libkernel_sys (532 todo: A 21, B-S 113, B-M 15, B-L 11, C 2, D 370)

libkernel_sys is the system-process superset of libkernel: FreeBSD 11 syscall wrappers and libthr `_np` extensions that libkernel does not export, plus Sony system calls for ShellCore, rcmgr, ICC, budgets, debugging and memory pools. 527 todo rows are the parameterless stubs of `Export.Discovery.cpp`; five (`fork`, `fchown`, `symlink`, `readlink`, `readlinkat`) are partial functions in `Export.cpp` that progress.py counts as todo because a branch calls `NotImplemented_nid_no_patch`.

Families and decisions:
- A (21): same NID or the same behaviour already in libkernel. `fstat`/`pwrite` forward to libkernel's `fstat_nid_disambig1`/`pwrite_nid_disambig1` (same NIDs). `lchmod` is FreeBSD's `kern_fchmodat(AT_FDCWD, ..., AT_SYMLINK_NOFOLLOW)`, i.e. the existing `fchmodat`. `sceKernelFlock/Mlockall/Msync` follow libkernel's `sceKernelFtruncate` forwarding pattern; 12 `scePthread*` and 3 POSIX rows are the errno<->SCE twin of an existing libkernel function (`PosixThread::ToErrno` and its inverse).
- B (139): FreeBSD 11 syscalls (aio, cpuset, `*at`/`l*` path calls, ksem, kmq, ktimer, sched_*, sigqueue/sigreturn, statfs/getfsstat, uuidgen, wait3/4, setlogin, revoke) and libthr extensions (suspend/resume, main_np, timedjoin_np, prioceiling, getkind/setkind_np, affinity attrs), sized against libkernel neighbours. SCE event-flag/semaphore open/close, `sceKernelGetCompiledSdkVersion` (process param offset 0x10, as libSceHmd2 reads it) and `sceKernelGetGPO` are getters/setters over kept state. The 18 `sceKernelWrite*Command` rows record the same bytes as their implemented libSceAmpr siblings, using the signature pattern of the two kernel writers already in `Apr.cpp`; confirm against ampr_emu's hook-target header before relying on it.
- B-L means a missing subsystem: a child process (`fork`, `vfork`, `rfork_thread`), cross-platform guest thread suspension (`pthread_suspend_np`), a POSIX message queue store (`kmq_open`), a mount table in the path resolver (`mount`, `unmount`), a guest FS base (`amd64_set_fsbase`), and ktrace/profil/ptrace.
- C (2): `pthread_switch_add_np`/`pthread_switch_delete_np` return ENOTSUP (45), as FreeBSD 11 libthr `thr_switch_np.c` always does. This is real behaviour, not a silent stub.
- D (370): every Sony-private call without a public prototype (ICC, rcmgr/utoken/QAF, app lifecycle, budgets, tool/trace memory, eports, version/hardware queries, debug and event log). Some calls are FreeBSD syscalls but are still D, because the answer is console kernel state rather than semantics: `kld*`, `kenv`, `sched_rr_get_interval`, `reboot`, `swapon`. All `sceKernelIs*`/`Has*` predicates are D, following the tree's no-guessed-constant policy (libkernel debt, `sceKernelGetProcessAbiType`).

Dependencies: none. Everything B builds on host C++20/POSIX/Win32 and existing libkernel code. No crypto is involved, so 3rdparty/mbedtls is not needed.

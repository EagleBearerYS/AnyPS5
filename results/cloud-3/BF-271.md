## What CreateDecoder does and doesn't do

- **Does:**
  - Checks, in shadPS4's order: a null config or output → INVALID_ARGUMENT; decoder type above 8 (`Vdec2Special2`) → INVALID_ARGUMENT; codec type above 4 → INVALID_CODEC_TYPE. A refused call leaves `*decoder` alone.
  - Builds the decoder state: codec type, width/height/DPB with the 1920x1080 and 16-frame defaults, horizontal alignment, and the frame-buffer size that MapMemoryBlock cuts slots with.
  - **Opens the FFmpeg codec context at create time, as shadPS4 does:** `avcodec_find_decoder` (HEVC for codec type 4, H.264 otherwise), `avcodec_alloc_context3`, width and height, `AV_CODEC_FLAG_COPY_OPAQUE`, `avcodec_open2`. It links the tree's `ffmpeg` target, the one libSceVideodec2 already links.
    - **Why:** it matches shadPS4 line for line, so B268-3's decode half only has to add the worker and the packet path. It also makes a codec that can't be opened fail at create, where the game asks for it, not at the first decode.
  - Returns a host-allocated handle and registers it, so Delete, MapMemoryBlock and a test-only `VdecCoreFrameBufferSlots_nid_no_patch` accessor (the `Videodec2Vp9PictureInfo_nid_no_patch` precedent; not an export row) can find it.
- **Doesn't:**
  - **No decode thread.** shadPS4 starts `DecoderWorkerLoop` on a `std::jthread` here (L400) and allocates `decoded_frame`; both belong to B268-3's decode half.
  - **No use of `mem_info` or the compute queue.** shadPS4 ignores both too.
- **Differences from shadPS4 (all in the debt entry):**
  - A codec that's unavailable, or a context that can't be allocated, throws `std::runtime_error`. shadPS4 `ASSERT`s.
  - `avcodec_open2` failing throws. shadPS4 only logs and returns a decoder with an unopened context.
  - A non-null handle that CreateDecoder didn't return throws `std::invalid_argument` in Delete and MapMemoryBlock. shadPS4 dereferences it.
  - MapMemoryBlock skips cutting when the frame-buffer size is 0. It can't be 0 from CreateDecoder; the guard just keeps shadPS4's division from ever dividing by zero.

# BF-365: `agc_driver_pipeline_journal`'s cold run on three upstream main commits, on one machine (cloud-3)

Worker: cloud-3. Only this result was pushed. Nothing went upstream or to any PR branch, and the #15423 hunk was never committed.

**Short answer:** the cold run did not grow on this machine.
- **Medians:** A (10-31) 115.01 s, C (11-01) 118.96 s, B (11-03) 118.40 s. The ranges overlap almost completely.
- **Mesa's work is the same:** every run of every tree leaves the same Mesa shader cache, 60 files and 3068 KiB.
- **Where the time goes:** about 95 of the ~110 s is three GPU batches waiting on llvmpipe's cold shader compiles, in the same places in A and B.

- **Cold runs:** each got a new, empty `MESA_SHADER_CACHE_DIR` (`/home/user/bf365-logs/mesa/cold-<n>-<tree>`, checked empty before the run).
  - The order was A B C, C B A, A B C, C B A, A B C (02:48:55–03:13Z).

## 4. Verdict

- **Is B's cold median at least 20% above A's, with the ranges apart? No.**
  - B's median is 118.40 s against A's 115.01 s, **+2.9%**.
  - The ranges overlap almost completely: B 107.11–121.37 s, A 109.20–119.61 s.
  - Within rounds, B−A is +5.17, −0.06, +6.36, −2.47 and −2.09 s, a mean of +1.4 s.
- **Where does C fall? It can't separate the two halves, because A and B don't differ.**
  - C's median of 118.96 s lies inside both A's and B's ranges.
  - C is slightly slower on average (mean +5.7 s over A), but only from rounds 1–2. In round 4 it was faster than A.
  - That spread is within this machine's run-to-run noise (about ±7%).
- **Is the cold work the same?** Yes, as far as Mesa shows. Every tree leaves the identical cache, 60 files and 3068 KiB, so none compiles more or bigger llvmpipe shaders.
- **What the CI gap is:** the 67.8 s (A) vs 119.72 s (B) gap in the GitHub runs is not reproduced on one machine. It is most likely runner-to-runner variance, like the 106.2 s / 135.91 s pair on one commit. There is no case for bisecting from these numbers.
- **Warm runs:** about 10 s here on all three trees, against 5.1 s (A) and ~8 s (B) on GitHub's runner. This machine is slower than that runner for warm runs too.

# PRM-135: why the arm's two-lane module keeps so many values live, and whether one small change cuts it

Worker: cloud-3. Base: `prm/9969-intel-trace` at `992d97fae8`.

## Verdict

**No variant built and nothing pushed.**

By the SSA liveness proxy, the arm's two-lane module peaks at **35 divergent (per-lane) 32-bit words plus 19 uniform**. The sibling peaks at **33 + 18**. The 2-word gap is exactly the pc 0xa8 result (`v11`, later `v5`), which each half holds until the slot loop's latch.

The arm is about twice as long as the sibling (11,454 vs 5,901 SPIR-V instructions after inlining) but barely higher in pressure.

Nearly all of the peak is state the program carries through the slot loop, for both halves at once:
- the four result registers;
- `v0`, `v1` and `v3`;
- each half's lane flags.

Most of this comes from two things: an IR-level choice to merge every exec-masked write at the loop latch, and the fact that each host invocation holds two guest lanes.

**Candidates.** Three changes cut the proxy peak. None meets the bar of being small, limited to the two-lane path and certain to survive the driver:
- **Rematerialize lane-only values:** 35 → 23. The driver's LICM/GVN would likely hoist these loop-invariant values back out of the loop, and the change is well over 150 lines.
- **Merge exec-masked writes where they are produced:** 35 → 29. This is IR-level and would change every layout.
- **Constant-fold `lane < 32` and `lane & 31` per half:** 35 → 31. This one is small and two-lane-only, but IGC's own InstCombine/GVN almost certainly does half of it already.

The cheapest next step is a measurement, not a branch (see "For mrfelek"):
- Read the **sibling's** two-lane pipeline statistics.
- The proxy says the sibling should spill too. If it does, and still passes, spilling alone does not explain the failure.

## Step 1: what makes the arm's two-lane module heavy

### The module

The module is produced by `RecompileTwoLanes`:
- subgroup 32, spanned waves off, untraced;
- 86,448 bytes, `LocalSize 32 1 1`;
- dumped at `992d97fae8` with a scratch `PRM132_DUMP` patch that was reverted afterwards.

It is byte-identical to PRM-134's `plain-dump/twolane.spv`. The sibling (`--pointer-vsharp-child-key`) is 60,696 bytes. All three modules analysed pass spirv-val (`--target-env vulkan1.3`): arm, sibling, and the arm trace build.

Functions:
- `main`;
- eight `DontInline` helpers: `record_bda_fault`, `get_bda_pointer`, `probe_bda_pointer`, `read_bda_dword_bytes`, `read_bda_dword_bytes_stop`, `load_bda_span`, `read_bda_span`, `read_bda_span_stop`.

The helpers are identical in both modules. `main` has no function-storage variables; the whole of `main` is SSA.

### The guest program and mrfelek's "slot loop"

| 0xb0–0xf0 | second record chain and child key `(s64 >> 16) << 5` |
| **0xfc** | **image_sample `v4..v7`**: T# from table 1, S# from table 2 |

| 0x114–0x130 | restore exec, then `buffer_store` `v4..v7` |

The **slot loop** is that waterfall. In SPIR-V it is a real loop, not unrolled:
- `OpLoopMerge %81 %80` at `%75`;
- 186 of `main`'s 239 blocks and 2,846 of its 3,284 instructions;
- 12 header phis: 8 result registers (4 per half), 2 remaining-lane flags, 2 exec words.

**Is any loop unrolled?**
- None of the seven loops in `main` is unrolled: the slot loop plus six binary-search table lookups.
- The 12 image ops per sample are a 12-way case split over the image bindings, not a loop.
- The only unrolled repetition is that each SMEM dword read through a guest pointer becomes its own `read_bda_span(_stop)` call: a page-table walk with a fault record.
  - Arm: 11 calls (pc 0x90 ×4, 0x9c ×2, 0xc0 ×4, 0xcc ×1), about 640 SPIR-V instructions each after inlining.
  - Sibling: 5 calls.
  - These are wave-uniform (scalar), so they add instructions but no per-lane pressure.

### Per-half duplication

`EmitStructuredBlock` emits every IR instruction twice, half 0 then half 1 (`SpirvFlowEmitter.cpp:775-787`). The only exception is a wave-uniform value in `sharedLaneValues`, which is emitted once. In this module:
- Per-lane work is doubled: 48 image ops (24 in the 8-lane module), and six lookup loops for three lookups.
- The uniform BDA reads and the slot loop's control are shared.
- The two halves are interleaved per IR instruction. An instruction that expands into control flow, such as a lookup and its 12-way sample, finishes half 0's copy before half 1's starts.

### The register-pressure proxy

A Python liveness pass over `spirv-dis --raw-id` output (appendix A):
- Backward dataflow on the CFG built from `OpBranch`, `OpBranchConditional` and `OpSwitch`.
- A phi's operands count as live out of the matching predecessor.
- Values are weighed in 32-bit words: 64-bit = 2, `v4uint` = 4, bool = 1.
- A forward divergence analysis splits values into divergent (D, one value per lane) and uniform (U).
  - Seeds: loads of the invocation-ID builtins; Elect and InverseBallot; shuffles with a divergent lane index.
  - Uniform: ballots, broadcasts, reductions, and shuffles with a uniform lane index (the two-lane `v_readfirstlane`).
  - Control divergence: phis at the merge of a divergent branch, and values leaving a loop through a divergent exit.
- "After inlining" means: at each call, the values live through the call plus the callee's own peak, recursively.

| module | `main` peak D | U | where |
|---|---|---|---|
| arm, untraced | **35** | 19 | `%5541`, pc 0xfc half 1, first case of the 12-way sample |
| sibling | **33** | 18 | `%2622`, pc 0xcc half 1, same spot |
| arm, trace build (`APS5_DIAG_TABLE_TRACE`) | 37 | 28 | `%3116`, pc 0xa8 half 1 |

- The inlined peak equals `main`'s own peak, because the helpers carry no divergent values.
  - The helpers' uniform peaks are 36 words, inside `read_bda_span(_stop)`.
  - They stack on 22 D / 24–32 U in the BDA regions, which is below the peak.
- If the driver did **not** treat the two-lane readfirstlane emulation (ballot, FindILsb, two shuffles, select) as uniform, the record and BDA paths would turn per-lane. The inlined peaks would then be **60** (arm) and **58** (sibling), at a `read_bda_span` call. That is still only two words apart.
- In Gen12 terms (128 GRFs of 32 bytes, so a per-lane 32-bit value at SIMD32 takes 4 GRFs), 35 D is about 140 GRFs before uniforms and payload.
  - So the proxy puts **both** modules over the register file at their peaks, the sibling included.

### What is live across the pc 0xfc lookup, and why

At the entry of half 0's T# lookup (`%4370`), 29 D and 21 U are live.

| D words | values | why they are live |
|---|---|---|
| 8 | slot-loop phis `%1132..%1139`: old `v4`–`v7`, both halves | Exec-masked writes are merged with the old value at the latch: `%5528`, `OpSelect exec ? new : old`. Every result register's old value lives through the whole loop body. This merge is in the IR: the 8-lane module has the same four latch selects (`%3189` in `dispatch0.spv`). |
| 6 | `v0`-derived lane index (`%739`/`%745`), `v1` coordinate (`%1112`/`%1113`), `v3` slot (`%1116`/`%1117`), both halves | These are guest VGPRs computed in the prologue. `v3` is reread at the loop top every iteration, `v1` at both samples, and `v0` after the loop for the store address. Each invocation holds two guest lanes, so every one is a pair. |
| 8 | per half: lane-in-this-iteration (`%1177`/`%1178`), exec bit (`%1215`/`%1216`), `lane < 32` (`%1205`/`%1206`), `lane & 31` (`%1209`/`%1210`) | Computed once at the loop head. Reused by every lookup's fault guard, the latch merge and the code after the loop. In the two-lane layout, `lane < 32` is just "half 0" and `lane & 31` is the host lane. |
| 2 | pc 0xa8 result `v11.x` per half (`%4185`/`%4186`) | The program keeps `v11` across pc 0xfc (`v5 = v11` at 0x108), and the latch merge keeps it until the latch. This is all the arm has over the sibling. |
| 5 | the lookup's inputs: the record-pointer pair `%4208`/`%4209`, key offset `%4357`, the loop's own phis `%4374`/`%4375` | The lookup itself. |

The record, header and descriptor words are uniform (U), because the slot is read-first-lane'd.

At the module peak (half 1's pc 0xfc sample, 35 D):
- the 24 carried words above;
- plus half 0's pc 0xfc result (`v4uint` phi `%4758`, 4 words), which waits for the latch;
- plus half 1's sample in flight (4) and three format-conversion temporaries.

The sibling's peak has the same makeup minus the 2 words of `v11`.

**Does interleaving the two halves cost anything?**
- At the peak, the only value live because of the other half's work is half 0's sample result.
- It is held by the latch merge, not by the interleave. Finishing half 0 first would leave it live just the same.
- So "finish one half before the other" cuts **0** words at the peak by this proxy.

**Trace builds.**
- The 24 row words are stored at the lookup. None is carried.
- The trace keeps four more lane values live through the loop: `%736`/`%743` (the row index) and `%1202`/`%1204` (the lane in the row marker).
- That is +2 D at the peak, which moves it to pc 0xa8 half 1 (37 D / 28 U).

## Step 4: expected-failure fallback (reference only, not built)

### Detecting the failing device at runtime

**Vendor and driver.**
- `VkPhysicalDeviceProperties.vendorID == 0x8086`, and
- `VkPhysicalDeviceDriverProperties.driverID == VK_DRIVER_ID_INTEL_PROPRIETARY_WINDOWS`.
- The driver ID matters because the failure is IGC on Windows. Mesa ANV on Linux uses a different compiler and is untested here.
- The device already reads both:
  - `state->properties` is logged at `VulkanDevice.cpp:1612`;
  - `driverID` is stored as `state->driverId` at `VulkanDevice.cpp:1622-1630`.
- Tests only reach `VulkanDevice::Target()` (`SpirvTarget`), which carries no vendor or driver field. A skip would need a small accessor.

**"Gen12" itself.**
- No Vulkan property names the GPU generation.
- It would mean matching `VkPhysicalDeviceProperties.deviceID` against Intel's PCI ID families (TGL 0x9Axx, RKL 0x4C8x, ADL 0x46xx, DG1 0x490x and others). That list needs upkeep.

**A narrower test.**
- Use the pipeline's own statistics: skip when the arm's two-lane pipeline reports nonzero scratch through `VK_KHR_pipeline_executable_properties`.
- The feature is only enabled when `APS5_PIPELINE_STATS` is set (`VulkanDevice.cpp:2429-2435`), so the test would have to enable it.

### Existing harness patterns

- **Exit 77.** Tests return `VulkanTestSkipped = 77`, and CMake marks them `SKIP_RETURN_CODE 77`. The arm test already has it in `tests/cmake/agc_driver_image_table_tests.cmake:22-23`.
- **`skipped, <reason>` line.** The test prints the reason, e.g. `ImageTable.cpp:818`: "per-wave key case skipped, subgroup size %u does not hold exactly one wave32".
- **`tools/check_skips.py` on Linux.** It accepts a skip only if the reason matches `DEVICE_LIMITATION`:
  - `subgroup`, `the device (has no|reports|lacks|does not|…)`, `no usable Vulkan device`, and so on;
  - a reason like "skipped, the device reports Intel's Windows driver …" would pass.
- **`check_skips.py --job windows`.** It accepts any skipped `agc*` test, because the Windows runner has no Vulkan driver.
- **Driver-specific behaviour.** It is keyed on `VK_DRIVER_ID_*` tables (`FragmentBarycentric.cpp`, `SubgroupBarrier.cpp`, `HostInterpolationPreferred`, `SubgroupControlBarrierUsable`).
- There is **no vendor- or device-ID skip** in the test tree today.

## Appendix A: `pressure.py`

Usage: `python3 pressure.py <module>.raw.dis`, where the input comes from `spirv-dis --raw-id`.

```python
import re
import sys
from collections import defaultdict

TERMINATORS = {"OpBranch", "OpBranchConditional", "OpSwitch", "OpReturn", "OpReturnValue", "OpKill", "OpUnreachable", "OpTerminateInvocation"}
UNIFORMING = {"OpGroupNonUniformBroadcastFirst", "OpGroupNonUniformBroadcast", "OpGroupNonUniformBallot", "OpGroupNonUniformAll", "OpGroupNonUniformAny", "OpGroupNonUniformAllEqual", "OpGroupNonUniformBallotBitCount", "OpGroupNonUniformBallotFindLSB", "OpGroupNonUniformBallotFindMSB"}
REDUCING = {"OpGroupNonUniformIAdd", "OpGroupNonUniformUMin", "OpGroupNonUniformUMax", "OpGroupNonUniformSMin", "OpGroupNonUniformSMax", "OpGroupNonUniformBitwiseAnd", "OpGroupNonUniformBitwiseOr", "OpGroupNonUniformBitwiseXor", "OpGroupNonUniformLogicalAnd", "OpGroupNonUniformLogicalOr", "OpGroupNonUniformFAdd", "OpGroupNonUniformFMin", "OpGroupNonUniformFMax"}
SEEDS = {"OpGroupNonUniformElect", "OpGroupNonUniformInverseBallot", "OpGroupNonUniformShuffle", "OpGroupNonUniformShuffleXor", "OpGroupNonUniformShuffleUp", "OpGroupNonUniformShuffleDown"}


class Module:
    def __init__(self, path):
        self.instrs = []
        self.types = {}
        self.names = {}
        self.builtins = {}
        self.storage = {}
        for line in open(path).read().splitlines():
            t = line.strip()
            if not t or t.startswith(";"):
                continue
            m = re.match(r"(%\S+) = (Op\w+)\s*(.*)$", t)
            if m:
                res, op, rest = m.group(1), m.group(2), m.group(3).split()
            else:
                parts = t.split()
                res, op, rest = None, parts[0], parts[1:]
            self.instrs.append((res, op, rest, t))
            if res and op.startswith("OpType"):
                self.types[res] = (op, rest)
            if op == "OpName":
                self.names[rest[0]] = t.split('"')[1]
            if op == "OpDecorate" and len(rest) >= 3 and rest[1] == "BuiltIn":
                self.builtins[rest[0]] = rest[2]
            if op == "OpVariable" and res:
                self.storage[res] = rest[1]

    def width(self, type_id):
        if type_id not in self.types:
            return 1
        op, rest = self.types[type_id]
        if op in ("OpTypeInt", "OpTypeFloat"):
            return 2 if rest[0] == "64" else 1
        if op == "OpTypeVector":
            return self.width(rest[0]) * int(rest[1])
        if op == "OpTypePointer":
            return 2 if rest[0] == "PhysicalStorageBuffer" else 0
        if op == "OpTypeStruct":
            return sum(self.width(member) for member in rest)
        if op in ("OpTypeImage", "OpTypeSampler", "OpTypeSampledImage"):
            return 0
        return 1

    def functions(self):
        current = None
        for res, op, rest, text in self.instrs:
            if op == "OpFunction":
                current = Function(self, res)
                continue
            if op == "OpFunctionEnd":
                current.finish()
                yield current
                current = None
                continue
            if current is not None:
                current.body.append((res, op, rest, text))


class Function:
    def __init__(self, module, name):
        self.module = module
        self.name = name
        self.body = []
        self.params = []

    def finish(self):
        module = self.module
        self.blocks = []
        self.defined = {}
        self.op_of = {}
        labels = {res for res, op, rest, text in self.body if op == "OpLabel"}
        self.labels = labels
        for res, op, rest, text in self.body:
            if op == "OpLabel":
                self.blocks.append({"label": res, "instrs": [], "succ": [], "merge": None, "loop": None})
                continue
            if op == "OpFunctionParameter":
                self.defined[res] = module.width(rest[0])
                self.params.append(res)
                self.op_of[res] = op
                continue
            block = self.blocks[-1]
            block["instrs"].append((res, op, rest, text))
            if res and rest:
                self.defined[res] = module.width(rest[0])
                self.op_of[res] = op
            if op == "OpSelectionMerge":
                block["merge"] = rest[0]
            if op == "OpLoopMerge":
                block["loop"] = (rest[0], rest[1])
            if op == "OpBranch":
                block["succ"] = [rest[0]]
            elif op == "OpBranchConditional":
                block["succ"] = [rest[1], rest[2]]
            elif op == "OpSwitch":
                block["succ"] = [token for token in rest[1:] if token in labels]
        self.by_label = {block["label"]: block for block in self.blocks}
        self.order = {block["label"]: index for index, block in enumerate(self.blocks)}
        self.pred = defaultdict(list)
        for block in self.blocks:
            for succ in block["succ"]:
                self.pred[succ].append(block["label"])
        self.loops = []
        for block in self.blocks:
            if block["loop"]:
                header = block["label"]
                body = {header}
                stack = [p for p in self.pred[header] if self.order[p] >= self.order[header]]
                while stack:
                    node = stack.pop()
                    if node in body:
                        continue
                    body.add(node)
                    stack.extend(self.pred[node])
                self.loops.append((header, block["loop"][0], body))

    def uses(self, res, op, rest):
        if op in ("OpPhi", "OpLoopMerge", "OpSelectionMerge"):
            return []
        operands = rest[1:] if res else rest
        return [token for token in operands if token in self.defined]

    def divergence(self, divergent_params, callee_results):
        module = self.module
        div = set(p for p in self.params if p in divergent_params)
        changed = True
        while changed:
            changed = False
            for block in self.blocks:
                for res, op, rest, text in block["instrs"]:
                    if res is None or res in div or res not in self.defined:
                        continue
                    operands = rest[1:]
                    d = False
                    if op == "OpLoad" and module.builtins.get(operands[0]) in ("LocalInvocationId", "LocalInvocationIndex", "SubgroupLocalInvocationId", "GlobalInvocationId"):
                        d = True
                    elif op == "OpGroupNonUniformShuffle":
                        d = operands[2] in div
                    elif op in SEEDS:
                        d = True
                    elif op in UNIFORMING:
                        d = False
                    elif op in REDUCING and len(operands) > 1 and operands[1] == "Reduce":
                        d = False
                    elif op == "OpPhi":
                        d = any(value in div for value in operands[0::2])
                    elif op == "OpFunctionCall":
                        callee = operands[0]
                        args = operands[1:]
                        d = callee_results.get(callee, (lambda flags: any(flags)))([a in div for a in args])
                    else:
                        d = any(token in div for token in operands)
                    if d:
                        div.add(res)
                        changed = True
            for block in self.blocks:
                terminator = block["instrs"][-1]
                condition = None
                if terminator[1] == "OpBranchConditional":
                    condition = terminator[2][0]
                elif terminator[1] == "OpSwitch":
                    condition = terminator[2][0]
                if condition is None or condition not in div:
                    continue
                targets = []
                if block["merge"]:
                    targets.append(block["merge"])
                for header, merge, body in self.loops:
                    if block["label"] in body and any(s not in body for s in block["succ"]):
                        targets.append(merge)
                        for inner in body:
                            for res, op, rest, text in self.by_label[inner]["instrs"]:
                                if res in self.defined and res not in div:
                                    for other in self.blocks:
                                        if other["label"] in body:
                                            continue
                                        if any(res in self.uses(r, o, x) for r, o, x, t in other["instrs"]):
                                            div.add(res)
                                            changed = True
                                            break
                for target in targets:
                    for res, op, rest, text in self.by_label[target]["instrs"]:
                        if op == "OpPhi" and res not in div:
                            div.add(res)
                            changed = True
        self.div = div
        return div

    def liveness(self):
        phi_out = defaultdict(set)
        for block in self.blocks:
            for res, op, rest, text in block["instrs"]:
                if op == "OpPhi":
                    pairs = rest[1:]
                    for value, pred in zip(pairs[0::2], pairs[1::2]):
                        if value in self.defined:
                            phi_out[pred].add(value)
        gen, kill = {}, {}
        for block in self.blocks:
            g, k = set(), set()
            for res, op, rest, text in block["instrs"]:
                for value in self.uses(res, op, rest):
                    if value not in k:
                        g.add(value)
                if res in self.defined:
                    k.add(res)
            gen[block["label"]] = g
            kill[block["label"]] = k
        live_in = {block["label"]: set() for block in self.blocks}
        live_out = {block["label"]: set() for block in self.blocks}
        phis = {block["label"]: {res for res, op, rest, text in block["instrs"] if op == "OpPhi"} for block in self.blocks}
        changed = True
        while changed:
            changed = False
            for block in reversed(self.blocks):
                label = block["label"]
                out = set(phi_out[label])
                for succ in block["succ"]:
                    out |= live_in[succ] - phis[succ]
                new_in = gen[label] | (out - kill[label]) | phis[label]
                if out != live_out[label] or new_in != live_in[label]:
                    live_out[label] = out
                    live_in[label] = new_in
                    changed = True
        self.live_in = live_in
        self.live_out = live_out
        self.points = []
        for block in self.blocks:
            live = set(live_out[block["label"]])
            rows = []
            for index in range(len(block["instrs"]) - 1, -1, -1):
                res, op, rest, text = block["instrs"][index]
                after = frozenset(live - {res})
                live.discard(res)
                for value in self.uses(res, op, rest):
                    live.add(value)
                rows.append((block["label"], index, res, op, rest, text, after, frozenset(live)))
            self.points.extend(reversed(rows))

    def weigh(self, values):
        d = sum(self.defined[v] for v in values if v in self.div)
        u = sum(self.defined[v] for v in values if v not in self.div)
        return d, u


def analyse(path, verbose=False):
    module = Module(path)
    funcs = list(module.functions())
    by_name = {f.name: f for f in funcs}
    divergent_params = defaultdict(set)
    for _ in range(4):
        for f in funcs:
            callee_results = {}
            for g in funcs:
                callee_results[g.name] = lambda flags: any(flags)
            f.divergence(divergent_params[f.name], callee_results)
            for block in f.blocks:
                for res, op, rest, text in block["instrs"]:
                    if op == "OpFunctionCall":
                        callee = by_name[rest[1]]
                        for param, arg in zip(callee.params, rest[2:]):
                            if arg in f.div:
                                divergent_params[callee.name].add(param)
    for f in funcs:
        f.liveness()
    inlined = {}

    def peak_of(f):
        if f.name in inlined:
            return inlined[f.name]
        best = (0, 0, None)
        for point in f.points:
            label, index, res, op, rest, text, after, before = point
            d, u = f.weigh(before)
            if (d, u) > best[:2]:
                best = (d, u, point)
            if op == "OpFunctionCall":
                callee = by_name[rest[1]]
                cd, cu, cpoint = peak_of(callee)
                ad, au = f.weigh(after)
                if (ad + cd, au + cu) > best[:2]:
                    best = (ad + cd, au + cu, point)
        inlined[f.name] = best
        return best

    report = {}
    for f in funcs:
        own = max(((f.weigh(p[7]), p) for p in f.points), key=lambda item: item[0], default=((0, 0), None))
        report[f.name] = (own, peak_of(f))
    return module, funcs, by_name, report


def main():
    module, funcs, by_name, report = analyse(sys.argv[1])
    for f in funcs:
        (own, own_point), (d, u, point) = report[f.name]
        name = module.names.get(f.name, f.name)
        print("%-28s blocks %4d values %5d divergent %5d | own peak D %3d U %3d at %s | inlined peak D %3d U %3d at %s %s" % (name, len(f.blocks), len(f.defined), len(f.div), own[0], own[1], own_point[0] if own_point else "-", d, u, point[0] if point else "-", (point[5][:70] if point else "")))


if __name__ == "__main__":
    main()
```

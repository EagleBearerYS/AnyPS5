- **For #1:** 23be5a02b's `GuestMemory.cpp` has the `unwatchSerial` counter, but not the public accessor. Upstream added the accessor in d9e47d1e9 ("feat(agc): implement image and sampler tables indexed at runtime offsets", 2026-10-14), after 23be5a02b:
  - `std::uint64_t UnwatchSerial();` in `Execution/include/GuestMemory.hpp`;
  - `std::uint64_t UnwatchSerial() { return unwatchSerial.load(std::memory_order_acquire); }` in `Execution/src/GuestMemory.cpp`.

Upstream added it with the snapshot-copy cache it clears, in 619be6979 ("perf(agc): share snapshot copies and the BDA table of repeated address-based builds", 2026-10-13), which isn't in 23be5a02b's history. With no such cache on 23be5a02b, both calls have nothing to clear.
